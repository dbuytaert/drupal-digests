## Summary

In the AI Agent Explorer form, changing the "Agent" dropdown now updates the page URL's `agent_id` query parameter. Previously the URL stayed the same, so a link or bookmark could not reproduce the selected agent.

## Impact

No upgrade or configuration changes required.

## Technical details

The fix is a small addition to the explorer's Drupal behavior JavaScript. It adds a `change` handler on `#edit-agent`. The handler builds a `URL` from `window.location.href`, calls `searchParams.set('agent_id', value)` when an agent is selected, and calls `searchParams.delete('agent_id')` when the selection is empty. It then calls `window.history.pushState()`, so no page reload happens, and each change adds a browser history entry.
