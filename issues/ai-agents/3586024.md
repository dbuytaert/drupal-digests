## Summary

Existing AI agent config entities that predate the `max_loops_message` setting (added in [#3547457](https://www.drupal.org/node/3547457)) now get that value set to an empty string by an update, instead of being left as NULL. Run database updates after upgrading.

## Impact

Affects site owners.

- **Config change:** `ai_agent` config entities with a NULL `max_loops_message` are updated to an empty string by `ai_agents_post_update_10003()`.

## Technical details

Adds `ai_agents_post_update_10003()` in the module's post update file. It loads all `ai_agent` config entities, and for each where `max_loops_message` is `NULL`, sets it to `''` and saves the entity. Agents that already have a value are untouched.
