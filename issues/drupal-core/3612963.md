## Summary

For Drupal 12, core's `composer.json` now pins several third-party PHP dependencies to a single, newer major version instead of allowing a range spanning older and newer majors. This tidies up the dependency graph now that Drupal 12 no longer needs to support the older majors for backward compatibility, but it means any site or contributed project that still requires the older major version of one of these libraries will need to update before it can run on Drupal 12.

## Impact

Affects site owners.

- **Requirements:** Drupal 12 core now requires `guzzlehttp/guzzle` ^8.0 (dropping ^7.10), `guzzlehttp/psr7` ^3.0 (dropping ^2.8), `doctrine/lexer` ^3 (dropping ^2), `egulias/email-validator` ^4.0 (dropping ^3.2.1), `sebastian/diff` ^7 (dropping ^4/^5/^6), and `justinrainbow/json-schema` ^6.5.2 (dropping ^5.2).

## Technical details

The change is confined to `composer.json` (and the corresponding `composer.lock`/`composer.json` in `core`). Constraints were narrowed from dual-major ranges to single majors: `doctrine/lexer` from `^2 || ^3` to `^3`, `guzzlehttp/guzzle` from `^7.10 || ^8.0` to `^8.0`, `guzzlehttp/psr7` from `^2.8.0 || ^3.0` to `^3.0`, `egulias/email-validator` from `^3.2.1|^4.0` to `^4.0`, `sebastian/diff` from `^4 || ^5 || ^6 || ^7` to `^7`, and `justinrainbow/json-schema` from `^5.2 || ^6.5.2` to `^6.5.2`. The dev-only `micheh/phpcs-gitlab` requirement was similarly narrowed from `^1.1 || ^2.0` to `^2.0`.

The motivation, per the issue, was that [#3612544](https://www.drupal.org/node/3612544) added Guzzle 8 support while still nominally allowing Guzzle 7, but it wasn't clear the code actually supported both. Rather than audit for true dual-version compatibility, this issue takes the opportunity of the Drupal 12 major release to require a clean, single version of each of these libraries going forward.</technical>
<parameter name="upgrade">Sites and contributed projects targeting Drupal 12 must ensure their `composer.json` allows the newer major versions of these libraries:
```
"doctrine/lexer": "^3",
"guzzlehttp/guzzle": "^8.0",
"guzzlehttp/psr7": "^3.0",
"egulias/email-validator": "^4.0",
"sebastian/diff": "^7",
"justinrainbow/json-schema": "^6.5.2"
```
Code that relied on APIs only present in the dropped major versions (for example Guzzle 7) should be updated to the versions above.
