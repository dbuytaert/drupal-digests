## Summary

The "Convert line breaks into HTML (i.e. `<br>` and `<p>`)" text filter now emits HTML5 style `<br>` for single line breaks instead of the XHTML style `<br />`. Browsers render both the same, but any custom test, snapshot or string match that expects the literal `<br />` from this filter will need updating. It was committed to `main` and backported to 12.0.x, because Drupal 12 should be fully HTML5 and the maintainer judged it low risk.

## Impact

Affects front-end developers.

- **Theme change:** Text run through the "Convert line breaks into HTML" filter (`FilterAutoP`) now contains `<br>` instead of `<br />` in rendered output.

## Technical details

The line-break logic lives in `FilterAutoP::process()` (the former `_filter_autop()`). The "make line breaks" regexes now insert and look for `<br>`: `(?<!<br>)\s*\n` is replaced with `<br>\n`, and the two cleanup regexes around block-level tags and `p|li|div|dl|dd|dt|th|pre|td|ul|ol` match `<br>`. The earlier step that collapses two consecutive breaks into a paragraph break was widened to `<br ?/?>\s*<br ?/?>`, so input that already contains `<br>`, `<br/>` or `<br />` is still collapsed. Only the output side is switched to `<br>`.

The merged change touches `FilterAutoP` and `FilterKernelTest` only. The test expectations in `testLineBreakFilter()` were updated to `<br>`. In `testHtmlCorrectorFilter()` only the assertion message changed: `Html::normalize('<br></br>')` still yields `<br><br>`, which is why the description now says it is transformed into two br tags. Earlier review (catch, wim leers) noted that `Html::normalize()` and the filter system already emit HTML5 serialization since [#2441811](https://www.drupal.org/node/2441811), which is why this filter was one of the remaining places still producing `<br />`. The parent effort is [#1388926](https://www.drupal.org/node/1388926). A reviewer (nod_) asked whether the old `<br />` forms could still occur, for example from CKEditor 4 configuration, which is why the first regex still accepts all three spellings.
