## Summary

The core Toolbar module (the admin toolbar shown at the top of the page for authenticated users with access) is now officially deprecated. This follows the policy decision in [#3476882](https://www.drupal.org/node/3476882) to move Toolbar out of core and into a contributed project. Sites that currently use Toolbar will start seeing deprecation notices, and should begin planning to switch to a contributed replacement before Toolbar is eventually removed from Drupal core. The module still works as before; only its lifecycle status has changed.

## Impact

Affects module maintainers.

- **Deprecation:** The `toolbar` module is now marked `lifecycle: deprecated` in its `.info.yml`, per the approved plan to move it to a contributed project; sites using it will see deprecation notices and should plan to migrate before it is removed from core.

## Technical details

The change adds `lifecycle: deprecated` and `lifecycle_link: https://www.drupal.org/node/3223395#s-toolbar` to `core/modules/toolbar/toolbar.info.yml`, which is how Drupal core's extension lifecycle system flags a module as deprecated (surfacing warnings on the modules page and via `hook_deprecation_message`-style runtime notices per the extension deprecation policy). Every functional, unit, and JavaScript test under `core/modules/toolbar/tests` also received the `#[IgnoreDeprecations]` PHPUnit attribute, so the tests keep passing despite the module now being flagged as deprecated, without needing to fix or suppress each individual deprecation notice.

This is one step in the broader deprecation effort tracked in the meta issue for the Toolbar removal; the remaining cleanup of Toolbar-only code still embedded in other core modules (Announcement, User, Contextual, Workspaces) is handled separately in [#3618746](https://www.drupal.org/node/3618746).

## Upgrade

Sites and contributed/custom modules that depend on the core `toolbar` module should start planning a migration to a contributed replacement. No code changes are required yet: the module's functionality is unchanged, but it now reports as deprecated:

```yaml
# core/modules/toolbar/toolbar.info.yml
lifecycle: deprecated
lifecycle_link: https://www.drupal.org/node/3223395#s-toolbar
```
