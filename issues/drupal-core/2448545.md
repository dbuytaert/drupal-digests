## Summary

The two remaining option helper functions in `form.inc` are deprecated. `form_select_options()` now has a class-based replacement, and `form_get_options()`, which core does not use, is deprecated with no replacement. Both will be removed in Drupal 13. Contrib and custom code that calls either function will emit deprecation notices.

## Impact

Affects module maintainers.

- **Deprecation:** `form_select_options()` deprecated in favour of `\Drupal\Core\Form\FormSelectOptions::process()`; `form_get_options()` deprecated with no replacement, both removed in drupal:13.0.0.
- **New API:** New final class `\Drupal\Core\Form\FormSelectOptions` with static `process()` method.

## Technical details

The logic of `form_select_options()` moved unchanged into the new `final` class `Drupal\Core\Form\FormSelectOptions` as `FormSelectOptions::process(array $element, $choices = NULL): array`. The class has a private constructor and is not meant to be instantiated or extended. The old function now calls `trigger_error()` with `E_USER_DEPRECATED` and delegates to `process()`. Core's own caller, the select preprocess in `ElementInfoManager`-adjacent theme preprocess code (`preprocessSelect()`), now calls `FormSelectOptions::process()` directly. The docblocks were moved as they were, with improvements left to the follow-up [#3548829](https://www.drupal.org/node/3548829).

`form_get_options()` only gets a deprecation notice and trigger, with no replacement. One small difference in the moved code: the empty-option check for multiple selects changed from `$key == '_none'` to `$key === '_none'`. Since `$key` is already cast to a string, behaviour should be the same. Replacing the hard-coded `'_none'` with a constant was split into [#3548830](https://www.drupal.org/node/3548830). The earlier broader approach, which introduced an options constant, was dropped to reduce scope.

## Upgrade

Replace calls to the deprecated function:

```php
// Before.
$options = form_select_options($element);
// After.
use Drupal\Core\Form\FormSelectOptions;
$options = FormSelectOptions::process($element);
```

`form_get_options()` has no replacement; stop using it.
