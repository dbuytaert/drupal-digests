## Summary

The documented rule for plural strings has flipped. The singular form must now contain `@count`, not a literal "1" or "one". In many languages the first plural form is also used for counts other than 1 (for example 21 in Russian or 0 in French), so an untranslated "1 day" singular displays the wrong number. A singular like "1 minute" can also clash with a standalone "1 minute" string in a .po file and break `msgfmt -c`. Core's own plural strings were updated to follow the new rule. Custom and contrib code with singulars like `'1 item'` should switch to `'@count item'`.

## Impact

No upgrade or configuration changes required.

## Technical details

The docs for the `$singular` parameter were rewritten in `TranslationInterface::formatPlural()`, `TranslationManager`, `PluralTranslatableMarkup::__construct()` and `Drupal.formatPlural()` in `drupal.js`. They now say not to put "1" or "one" in the string and to always use `@count`. The old statement that `@count` is replaced "for the plural cases" only was removed, since it is replaced in both forms. Examples in `core/lib/Drupal/Core/Form/form.inc`-style docblocks and the `formatPlural()` examples now use `'@count comment'`.

The patch also converts core singulars from "1 ..." or "One ..." to `@count ...`. This covers the locale import and update messages, `BundleEntityDeleteForm`, `UserLoginForm`, the block and workspace messages, the file field cardinality description, `ByteSizeMarkup`, and the `format_plural_string` value in two shipped views YAML files (`@count` + delimiter + `@count`). Tests and the JS extraction fixture were adjusted, for example "One translation file imported" is now asserted as "1 translation file imported". Because the singular is the msgid of a plural entry in a .po file, these source strings changed, so existing translations of them may no longer match. No runtime check or deprecation was added for singulars lacking `@count`. A coding standards or static analysis check was discussed as a follow-up. Related: [#3631439](https://www.drupal.org/node/3631439), [#1788008](https://www.drupal.org/node/1788008), [#2273889](https://www.drupal.org/node/2273889).

## Upgrade

Use `@count` in the singular string in your own code:

```php
// Before
\Drupal::translation()->formatPlural($count, '1 comment', '@count comments');
// After
\Drupal::translation()->formatPlural($count, '@count comment', '@count comments');
```

```js
Drupal.formatPlural(count, '@count something', '@count somethings');
```
