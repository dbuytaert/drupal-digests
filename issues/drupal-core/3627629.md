## Summary

The default `robots.txt` shipped with Drupal 12 no longer blocks crawlers from search result pages. Those rules were added in 11.4.0 for core Search, which has been removed from Drupal 12. Sites that move to the contributed Search module and want to keep crawlers out of search results must add the rules back to their own `robots.txt`.

## Impact

Affects site owners.

- **Config change:** Default `robots.txt` no longer contains `Disallow` rules for `/search/`, `/search?`, `/index.php/search/` and `/index.php/search?`.

## Technical details

The commit deletes four `Disallow` lines from the default `robots.txt` template: `/search/`, `/search?`, `/index.php/search/` and `/index.php/search?`. The diff has two identical hunks. I did not check which files they apply to. The rules came from [#3550083](https://www.drupal.org/node/3550083) and were already released in 11.4.0, so this is a reversal of a released change. The thread says a change record and a release note snippet were added for it, and the change record is https://www.drupal.org/node/3627873. It was committed to `main` and 12.0.x.

## Upgrade

Existing sites keep their current `robots.txt`, because Drupal does not overwrite it. A site using the contributed Search module should add these lines back to its `robots.txt`:

```
Disallow: /search/
Disallow: /search?
Disallow: /index.php/search/
Disallow: /index.php/search?
```
