## Summary

Node module used to ship three disabled-by-default Views: an Archive view (monthly content listing), a Glossary view (alphabetical content listing), and a "Recent content" block view. These assumed a blog-like site, dated back to early Drupal versions, and were not used anywhere in core, yet they still showed up in the Views UI and were parsed on every request. As of this change, new Drupal installs no longer include these three views at all. Sites that want an archive or glossary style listing will need to build their own view or find one in a contributed or example module. Existing sites are not affected since this only changes what ships with new installs; it does not remove views already present in a site's active configuration.

## Impact

Affects site owners.

- **Config change:** New sites no longer get the disabled-by-default `views.view.archive`, `views.view.glossary` and `views.view.content_recent` views from `node.module`'s `config/optional` directory; existing sites that already have them in active config are unaffected.

## Technical details

The change deletes `core/modules/node/config/optional/views.view.archive.yml`, `views.view.glossary.yml`, and `views.view.content_recent.yml` outright, and updates `core/recipes/standard/recipe.yml` to drop `views.view.archive` and `views.view.glossary` from its `node:` config import list (`views.view.content_recent` remains listed there even though the source config file is gone).

Since core tests exercised these views directly, the same view configs were carried over as test fixtures under new IDs: `test_archive` (added to `views_test_config`'s test views, with a new `ArchiveTest` in `core/modules/views/tests/src/Functional`), `test_glossary` (added to `views_ui_test`'s config, exercised by `GlossaryTest` and views_ui's `DefaultViewsTest`), and `test_content_recent` (added to `node_block_test`, used by `NodeBlockFunctionalTest`). Various other tests that referenced the old `archive`/`glossary`/`content_recent` view or block IDs (`ContextualLinksTest`, `FilterCriteriaTest`, `ModuleTest`, `BlockDependenciesTest`, `ViewsListingTest`, `InstallerExistingConfigSyncDirectoryMultilingualTest`, `StandardRecipeTest`) were updated to use the new test view IDs or to drop assertions tied to the removed views. A related follow-up, [#3592672](https://www.drupal.org/node/3592672), removes the "who's new" and "who's online" views in the same spirit.
