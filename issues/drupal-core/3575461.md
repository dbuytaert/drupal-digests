## Summary

This is a housekeeping task ahead of Drupal 12: it deletes a large batch of already-deprecated core functions, classes, and constructor arguments that carried a "removed from drupal:12.0.0" notice. Nothing here changes behavior for sites using only supported, non-deprecated APIs. But any custom code, theme, or contributed module still calling one of the removed items (deprecated procedural hook implementations, the old `theme-settings.php` discovery mechanism, the `node_search`/`help_search` plugin classes, the legacy `'rest'` CSRF token key, or several constructor arguments that carried BC shims) will now hit a fatal error instead of a deprecation notice, so this code must be updated before running on current Drupal 12.x-dev.

## Impact

Affects module maintainers.

- **API change:** Numerous deprecated functions, classes, and constructor arguments that were marked for removal in Drupal 12.0.0 have been deleted, including `_filter_tips()`, `_field_create_entity_from_ids()`, `field_form_field_config_edit_form_entity_builder()`, `_content_translation_install_field_storage_definitions()`, `language_process_language_select()`, `locale_system_file_system_settings_submit()`, `_media_get_add_url()`, `media_filter_format_edit_form_validate()`, `_menu_ui_node_save()` and several other `menu_ui` form callbacks, the `Drupal\help\Plugin\Search\HelpSearch` and `Drupal\node\Plugin\Search\NodeSearch` plugin classes, `Drupal\Core\Installer\InstallerRouteBuilder`, `Drupal\Core\Runtime\DeprecatedAutoloadAccess`, and the `Drupal\Composer\Generator\Builder\DrupalPinnedDevDependenciesBuilder` metapackage builder.
- **Deprecation:** Deprecated fallback code paths were removed from `RouteBuilder::__construct()`, `ThemeAccessCheck::__construct()`, `CommentAdminOverview::__construct()`, `UserCancelForm::__construct()` (its `$accountCancellation` argument is now required), theme discovery via `theme-settings.php`, the legacy `'rest'` CSRF token key in `CsrfRequestHeaderAccessCheck`, and the `package_manager.settings:executables` config fallback in `ExecutableFinder`.

## Technical details

The diff spans dozens of files and simply strips out the `@trigger_error(... E_USER_DEPRECATED)` shims and the deprecated symbols they guarded, matching each item's original "removed from drupal:12.0.0" notice. Notable removals: the `Drupal\help\Plugin\Search\HelpSearch` and `Drupal\node\Plugin\Search\NodeSearch` plugin classes (superseded by the `search_help`/`search_node` modules), `Drupal\Core\Installer\InstallerRouteBuilder`, `Drupal\Core\Runtime\DeprecatedAutoloadAccess` (and the `$GLOBALS['autoloader']` assignment in `DrupalKernel`/runtime bootstrap that used it), and `DrupalPinnedDevDependenciesBuilder` (`drupal/core-dev-pinned` metapackage generation).

Several constructors lost their deprecated BC branches and now have stricter typed signatures: `RouteBuilder::__construct()` only accepts `CheckProviderInterface` (no more `ModuleHandlerInterface` fallback or deprecated `moduleHandler`/`controllerResolver` service properties), `ThemeAccessCheck::__construct()` requires `array $themes`, `CommentAdminOverview::__construct()` only accepts `PrivateTempStoreFactory`, and `UserCancelForm::__construct()` now requires `AccountCancellation $accountCancellation` instead of treating it as optional. `CsrfRequestHeaderAccessCheck` no longer accepts the legacy `'rest'` CSRF token key. Theme hook discovery via a theme's `theme-settings.php` file was removed from `collectThemeHookImplementations()`, and `package_manager`'s `ExecutableFinder::find()` no longer falls back to `package_manager.settings:executables` config for locating `rsync`/`composer`. A handful of standalone procedural functions (`_filter_tips()`, `_field_create_entity_from_ids()`, `field_form_field_config_edit_form_entity_builder()`, `_content_translation_install_field_storage_definitions()`, `language_process_language_select()`, `locale_system_file_system_settings_submit()`, `_media_get_add_url()`, `media_filter_format_edit_form_validate()`, `_menu_ui_node_save()`, and three other `menu_ui` form callbacks) were deleted outright, most of which already had non-deprecated hook-object replacements (e.g. `ContentTranslationHooks`, `LanguageHooks`, `MediaHooks`, `MenuUiHooks`). The deprecated `form` asset library in `node.libraries.yml` (and its `node.module.css`) was also removed.

The `SYMFONY_DEPRECATION_HELPER` BC layer and the `ajax.js` deprecation notices (still marked "removed from drupal:12.0.0") were deliberately left in place, being handled separately in the postponed [#3574681](https://www.drupal.org/node/3574681) and a still-open follow-up respectively. A further follow-up, [#3623051](https://www.drupal.org/node/3623051), was filed to clean up remaining references to the now-relocated Search plugins.
