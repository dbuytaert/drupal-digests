## Summary

The Olivero theme, one of Drupal's bundled front-end themes since Drupal 9, has been removed from core. It continues to exist as a standalone contrib project for sites that still want to use it. Sites currently running Olivero as their default (or admin) theme need to download and install the contrib version before upgrading to Drupal 12, otherwise the theme and its assets, templates, and configuration will simply disappear.

## Impact

Affects module maintainers.

- **Deprecation:** The `olivero` theme is removed from Drupal core entirely; sites using it as their default or admin theme must install it as a contrib project (https://www.drupal.org/project/olivero) before upgrading to Drupal 12.

## Technical details

The commit deletes the entire `core/themes/olivero` directory (templates, PHP preprocess classes, CSS/PCSS source, fonts, images, config schema, and default block/date-format config that ships with the theme), along with everything in core that referenced it: the `MAINTAINERS.txt` credit section, `core/phpstan-baseline.neon` ignore rules scoped to Olivero classes, the cspell dictionary entries for "olivero"/"olivero's", and the `themes/olivero/fonts/**` exclusion in `.cspell.json`. It also removes the Nightwatch tests in `core/modules/search` that depended on `olivero_test` and on installing Olivero as the default theme, since that test coverage is now maintained in the contrib Search project instead.

This is a pure "task: remove the theme" commit; it does not touch the codebase in a way that changes any public API or theme system hook. Related follow-up work (removing Olivero references from database dump fixtures, tracked in [#3623927](https://www.drupal.org/node/3623927)) was landed just before this commit so the removal wouldn't break other test suites. A later merge request (!17186) was opened right after this commit to add the `olivero` theme to Drupal core's list of formally removed extensions in `system.install`, which triggers a requirements warning for sites still running it after upgrade; that addition was not part of what shipped here.

## Upgrade

Sites whose `system.theme` configuration (or admin theme) is set to `olivero` should, before upgrading to Drupal 12:

1. Download and install the contrib Olivero project: https://www.drupal.org/project/olivero
2. Confirm the site's default/admin theme still resolves correctly after the core removal.

No API changes are involved; this is purely the loss of a bundled theme.
