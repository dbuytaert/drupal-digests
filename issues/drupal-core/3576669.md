## Summary

The Settings Tray module (the off-canvas dialog for quickly editing block settings from the front end) is now formally deprecated in Drupal core, following approval in [#3576315](https://www.drupal.org/node/3576315) to move it to a contributed project. Sites currently using Settings Tray will continue to work for now, but should plan to move to the contributed version of the module once it is available, since the module will eventually be removed from core entirely.

## Impact

Affects module maintainers.

- **Deprecation:** The `settings_tray` module is marked `lifecycle: deprecated` and will be removed from core; sites using it should migrate to the contributed Settings Tray project.

## Technical details

The change adds `lifecycle: deprecated` and a `lifecycle_link` pointing to the core deprecated/obsolete modules documentation page (https://www.drupal.org/node/3223395#s-settings-tray) to `settings_tray.info.yml`. This triggers core's standard deprecated-extension machinery (deprecation notices when the module is installed, listing in the deprecated modules UI, etc.).
