## Summary

Fifty eight unused SVG icon files have been removed from `core/misc/icons`. Thirty of them were only used by the Toolbar module and were copied into that module in the related issue [#3622941](https://www.drupal.org/node/3622941); the other twenty eight had no references left anywhere in core. This is a main branch only (next major version) change: nothing in Drupal core itself changes behavior, but if a custom or contributed theme referenced any of these specific icon files directly (for example via `background-image: url(...)` pointing at `core/misc/icons/...`), that reference will break once sites are on the version built from this branch. A change record was written to flag this for contrib maintainers.

## Impact

No upgrade or configuration changes required.

## Technical details

The core icon set in `core/misc/icons/<color>/<name>.svg` is consumed by core's PostCSS build (`postcss-url`, configured in `core/scripts/css/compile.js`) which inlines referenced SVGs into compiled CSS such as the various `*.icon.theme.pcss.css` files. The removed files had no remaining `url(...)` references in any `.pcss.css` or `.css` file in core after the Toolbar module took its own copies of the 30 icons it needs (per [#3622941](https://www.drupal.org/node/3622941)). The commit is a pure deletion, no CSS or PHP changes; it only removes the 58 now dead SVG assets.

## Upgrade

If a custom or contributed theme or module references any of the deleted paths directly, for example:
```css
background-image: url(../../misc/icons/787878/wrench.svg);
```
copy the needed SVG into your own module/theme before upgrading, since it will no longer exist under `core/misc/icons` on this branch.
