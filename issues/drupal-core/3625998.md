## Summary

Core's bundled CKEditor 5 is updated from 47.6.3 to `47.6.3-drupal.1`, a rebuilt version of the CKSource-maintained Drupal fork that contains bug fixes. It is committed to 11.x, 11.5.x, 11.4.x, 11.3.x and 10.6.x. Sites get the fixes by updating core, and no configuration changes are needed. One commenter asked about a CKEditor bug (ckeditor5 issue 20237). Another commenter said the fork contains the upstream commit that fixes it.

## Technical details

The compiled bundle under `core/assets/vendor/ckeditor5/` was rebuilt from the public fork at github.com/drupal-ckeditor/ckeditor5. It was built using the documented core update steps, with `CKEDITOR_PACKAGES_PATH` pointing at the fork's `release/npm` output. It also used the build script changes from [#3622641](https://www.drupal.org/node/3622641). The only substantive code change was the rebuilt minified DLL file. Per a committer's comment, the first line of that file now carries a dictionary that the older 47.6.3 build was missing. The rest of the file differs by 22 bytes, believed to be a Safari fix.

`core/core.libraries.yml` has the `version` of every CKEditor 5 library, not just `ckeditor5`, set to `"47.6.3-drupal.1"`. The `license.url` values now point at the fork's tag `v47.6.3-drupal.1`. The `ckeditor5.essentials` URL previously used a `github.com/.../blob/` form and was normalised to the same raw URL as the others.

On 11.x and 11.4.x the performance test expectation file was also updated, with `ScriptBytes` rising from 3623909 to 3629587. On 11.3.x and 10.6.x, no performance test change was needed, and the `core.libraries.yml` backport conflict was trivial because those branches have no `ckeditor5.fullscreen` library. A reviewer noted that the version is not based on a public upstream release. That conflicts with derivative packages such as `ckeditor5-markdown-gfm`. Committers acknowledged this and said changing it belongs in a separate issue ([#3588899](https://www.drupal.org/node/3588899), which proposes moving CKEditor to contrib). Related: [#3624195](https://www.drupal.org/node/3624195).
