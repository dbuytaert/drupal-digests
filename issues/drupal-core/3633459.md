## Summary

Drupal core's bundled CKEditor 5 is updated from 48.5.1 to 49.1.0. The upstream release is a security update that the issue says does not affect Drupal core. Editors will see two small visual changes: the editor now stops growing 15px earlier, and balloon tooltips in the Admin theme keep readable text in light mode. Sites with custom CKEditor 5 plugins or CSS that overrides CKEditor variables should retest against v49.

## Impact

Affects front-end developers and site owners.

- **Requirements:** Bundled CKEditor 5 updated from 48.5.1 to 49.1.0 in `core/core.libraries.yml` and `core/package.json`.
- **Theme change:** `default_admin` CKEditor 5 CSS now sets `.ck.ck-balloon-panel` background from `--ck-balloon-panel-background-color`. The editor `max-height` offset changed from 20px to 35px.

## Technical details

The vendored build under `core/assets/vendor/ckeditor5` is regenerated, including all translation files. The `version` and license URL entries in `core/core.libraries.yml` and the `ckeditor5` dependency in `core/package.json` are bumped to 49.1.0. The update was committed to `main` and `12.0.x`. The issue notes that 11.x through 10.6.x stay on a security fork of 47.6 and get no update.

v49 changed how the balloon panel background is resolved. `.ck.ck-balloon-panel` now uses `background: var(--ck-color-panel-background, var(--ck-balloon-panel-background-color))`, and the more specific `.ck.ck-balloon-panel.ck-tooltip` rule that previously set `--ck-color-panel-background` was removed. The `default_admin` theme sets `--ck-color-panel-background` to a light/dark dependent value, so in light mode tooltips rendered white text on a white background. The fix adds `.ck.ck-balloon-panel { background: var(--ck-balloon-panel-background-color); }` to the default_admin CKEditor 5 CSS (both the source `.pcss.css` and the compiled CSS). Tooltips are readable again but do not follow light or dark mode. That is deferred to follow-up [#3634547](https://www.drupal.org/node/3634547).

New CKEditor styles added a top margin that pushed the editor past the viewport in `CKEditor5HeightTest`. The `max-height` rule in the ckeditor5 editor CSS now subtracts `35px` instead of `20px`. The `ckeditor5.types.jsdoc` build output and the performance test script byte counts were also updated.

Two JS tests (`testLinkability` and the media test that edits source) now click `.ck-widget__type-around__button_after` and call `assertBalloonClosed()`. This closes the media balloon that otherwise covers the Source button. One test also presses Source again to return to rich text editing so the source changes reach the CKEditor data model. The thread says this is only needed in the test, not in manual use.

## Upgrade

Sites or contrib themes that override `--ck-color-panel-background` and want it to apply to tooltips should check balloon tooltips against v49. default_admin handled it this way:

```css
.ck.ck-balloon-panel {
  background: var(--ck-balloon-panel-background-color);
}
```
