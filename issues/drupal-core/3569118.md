## Summary

The Shortcut module, which lets users bookmark frequently used admin pages as shortcut links, is now officially deprecated in Drupal core. This follows the earlier policy decision ([#3476880](https://www.drupal.org/node/3476880)) to move Shortcut to a contributed project. Sites currently using Shortcut will start seeing deprecation notices, and the module will be removed entirely once Drupal reaches its next major version (12.0.0). A contrib release of Shortcut is being prepared as the replacement so sites can continue using the functionality after the core module goes away.

## Impact

Affects module maintainers.

- **Deprecation:** The `shortcut` core module is marked `lifecycle: deprecated` and will be removed from core in Drupal 12.0.0; a contrib version is being prepared.

## Technical details

The change follows core's standard extension deprecation process: `core/modules/shortcut/shortcut.info.yml` gains `lifecycle: deprecated` and a `lifecycle_link` pointing to the deprecated and obsolete modules documentation page. Marking a module's info file this way causes Drupal to emit a deprecation notice whenever the module is installed or its configure route is visited.

To keep the test suite green despite that new notice, every PHPUnit test class in and around the `shortcut` module (functional, kernel, JSON:API, REST, and a few in `navigation`, `config_translation`, and `filter` that exercise shortcut entities) was annotated with `#[IgnoreDeprecations]`. A related test-only method, `ModuleConfigureRouteTest::testDeprecatedModuleConfigureRoutes()` in `core/tests/Drupal/KernelTests/Core/Extension/ModuleConfigureRouteTest.php`, was also given `#[IgnoreDeprecations]` since it deliberately installs a deprecated module. Sibling work split shortcut-specific test coverage out of unrelated modules ([#3569152](https://www.drupal.org/node/3569152)) and removed Shortcut from core recipes and the standard profile, so this commit itself only adds the lifecycle metadata and the deprecation-suppressing test attributes, without changing any runtime behavior of the module.

## Upgrade

Sites and modules depending on Shortcut should plan to install the contributed Shortcut module before Drupal 12.0.0, when the core version will be removed. No code changes are required immediately; the only observable effect is a deprecation notice, for example when the module is enabled:

```yaml
# core/modules/shortcut/shortcut.info.yml
lifecycle: deprecated
lifecycle_link: https://www.drupal.org/node/3223395#s-shortcut
```
