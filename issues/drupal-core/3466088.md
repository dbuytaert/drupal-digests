## Summary

This is the master tracking (meta) issue that coordinated Drupal's plan to slim down core ahead of Drupal 12 by removing a batch of modules and themes and moving them to standalone contributed projects instead. Over roughly a year and a half of follow-up, the Ban, Contact, Field Layout, History, Migrate Drupal, Migrate Drupal UI, Search, Settings Tray, Shortcut, and Telephone modules, the Toolbar module, and the Claro, Stable 9, and Olivero themes were all deprecated and had contrib equivalents prepared. Site owners using any of these should start evaluating and installing the contributed replacement before updating to Drupal 12, since the core versions will no longer be available. The underlying code changes (deprecation notices, test coverage moved, contrib packages created) were done in each linked child meta issue rather than in this one.

## Impact

Affects module maintainers.

- **Deprecation:** Ban, Contact, Field Layout, History, Migrate Drupal, Migrate Drupal UI, Search, Settings Tray, Shortcut, Telephone, and Toolbar modules, plus the Claro, Stable 9, and Olivero themes, are deprecated in Drupal 11.x and planned for removal in Drupal 12, with equivalent contributed projects taking their place.

## Technical details

No code changed directly in this issue; it is a coordination hub whose body and comments were kept updated as each module/theme reached deprecation (and in most cases full removal) in core, with checkmarks added as each linked meta issue closed. Each deprecated module or theme follows the same pattern: core marks the extension deprecated in `*.info.yml`/code with `@deprecated` notices, a contributed project is created at drupal.org as the ongoing maintenance home, and once the contrib package is stable the module or theme is removed from core in a later release (several, like Field Layout, Toolbar, and Olivero, were fully removed from core rather than merely deprecated by the time this meta issue closed). Related infrastructure work also tracked here includes dropping jQuery UI dependencies ([#3076171](https://www.drupal.org/node/3076171), [#2158943](https://www.drupal.org/node/2158943)), replacing the Archive_Tar library usage ([#3556706](https://www.drupal.org/node/3556706)), and generating new database fixtures without the deprecated modules for update-path tests ([#3569127](https://www.drupal.org/node/3569127)). See the individual meta issues, including [#3482198](https://www.drupal.org/node/3482198) (Ban), [#3520460](https://www.drupal.org/node/3520460) (Contact), [#3517712](https://www.drupal.org/node/3517712) (Field Layout), and [#3315257](https://www.drupal.org/node/3315257) (Migrate Drupal/Migrate Drupal UI), for the actual code and API details of each deprecation.
