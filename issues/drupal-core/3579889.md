## Summary

Core's remaining `@return void` docblocks were replaced with native `: void` return types, and the now pointless descriptions were dropped. For most sites nothing changes. Custom or contrib code that implements `NodeGrantDatabaseStorageInterface` or extends the diff formatter classes needs matching `: void` declarations on its overrides.

## Impact

Affects module maintainers.

- **API change:** `NodeGrantDatabaseStorageInterface::alterQuery()` and several protected `DiffFormatter` methods now declare a native `: void` return type; `BlockPluginCollection::addInstanceId()` too.

## Technical details

Applied across `core/lib/Drupal/Component/Annotation/Doctrine/*`, `core/lib/Drupal/Component/Diff/DiffFormatter.php` (protected `_block()`, `_start_diff()`, `_start_block()`, `_end_block()`, `_lines()`, `_context()`, `_added()`, `_deleted()`, `_changed()`), a second diff formatter overriding the same protected methods, `BlockPluginCollection::addInstanceId()`, `LocaleProjectRepository`, `NodeGrantDatabaseStorageInterface::alterQuery()` and its implementation, media `OEmbedIframeControllerTest`, `ConfigEntityValidationTestBase`, `InfoWriterTrait`, `PerformanceData`, `PerformanceTestTrait` and `WebAssert`. The only interface method changed is `alterQuery()`; the rest are protected or test helpers. `ResourceTestBase` was deliberately left out of the commit: it would break downstream test classes that extend it, and missing cross-module return types there are already reported to downstream users via the Symfony DebugClassLoader change ([#3486376](https://www.drupal.org/node/3486376)), so that conversion can wait for Drupal 13.

## Upgrade

Overrides of the affected methods must declare the return type, for example:
```php
public function alterQuery($query, array $tables, $operation, AccountInterface $account, $base_table): void {
```
Same for overrides of the protected `DiffFormatter` methods such as `_start_block($header): void`.
