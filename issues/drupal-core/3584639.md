## Summary

The Claro administration theme has been removed from Drupal core. It had been deprecated and is now deleted outright, along with its templates, CSS, JavaScript, config, and block layouts. Sites that still use Claro as their admin theme (or as their default theme) need to install it as a contrib theme before upgrading, or better, migrate to the new Default Admin theme, which is now the standard administrative experience for core. The release notes flag that Default Admin is still in beta stability as of this release, so further changes to it are expected before the 12.0.0 final release.

## Impact

Affects module maintainers.

- **Deprecation:** The `claro` theme and its `Claro` machine name are removed from core entirely, not just deprecated; it is added to `SystemRequirements::DRUPAL_CORE_REMOVED_THEME_LIST` so upgrades from a site still using it are flagged.

## Technical details

The commit deletes the entire `core/themes/claro` directory (its `.info.yml`, `.libraries.yml`, config schema, default block placements, templates, CSS and JS assets) in one pass, roughly 480 files. `SystemRequirements::DRUPAL_CORE_REMOVED_THEME_LIST` in `core/modules/system/src/Install/Requirements/SystemRequirements.php` gains a `'claro' => 'Claro'` entry so the update path can detect and warn sites that still reference the theme, matching how previously removed themes (Bartik, Classy, Seven, Stable) are handled. Leftover references were cleaned up too: the phpstan baseline entries pointing at `themes/claro/src/ClaroPreRender.php` and `ClaroHooks.php` were removed from `core/phpstan-baseline.neon`, and the Claro credits block was dropped from `core/CREDITS.txt`.

## Upgrade


Sites that still rely on Claro must, before upgrading to a Drupal core version without it:

```
composer require drupal/claro
```

and set it explicitly as the admin theme, or migrate to the new Default Admin theme (`core/themes/default_admin`), which is intended as Claro's in-core replacement.
