## Summary

The Olivero theme, Drupal's default front-end theme since 9.4, is now formally marked as deprecated in core. This follows the separate policy decision to remove Olivero from core and move it to a contributed project. Sites currently using Olivero are not affected immediately: the theme still ships and works exactly as before. This issue just flips the deprecation flag and updates its tests accordingly; it does not remove any functionality. Site owners using Olivero should start watching the linked documentation page for the recommended migration path, since the theme will eventually be removed from core in a future release.

## Impact

Affects module maintainers.

- **Deprecation:** The `olivero` theme is now marked `lifecycle: deprecated` in its `.info.yml`, pointing to https://www.drupal.org/node/3223395#s-olivero for migration guidance ahead of its eventual removal from core.

## Technical details

The change adds `lifecycle: deprecated` and `lifecycle_link: https://www.drupal.org/node/3223395#s-olivero` to `core/themes/olivero/olivero.info.yml`, which is how Drupal core formally flags an extension as deprecated per the core deprecation policy (following the approval in the parent policy issue [#3590816](https://www.drupal.org/node/3590816), referenced in the issue body).

Since flagging a theme as deprecated causes PHPUnit to emit deprecation notices when its code paths run, `#[IgnoreDeprecations]` was added to every test class that still exercises Olivero, both tests living inside the theme itself (`OliveroTest`, `OliveroAvoidStorageUsingTest`, `OliveroMessagesTest`, `OliveroHexToHslTest`) and core tests elsewhere that use Olivero as a fixture theme (e.g. `BreadcrumbTest`, `NodeTitleTest`, `AjaxTest`), so the test suite keeps passing without failing on the new deprecation notice. No PHP or Twig behavior in the theme itself was changed.
