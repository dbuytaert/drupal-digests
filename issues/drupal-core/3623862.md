## Summary

The hook for altering the data parsed from module and theme .info.yml files is now called `hook_extension_info_alter()`. The old name, `hook_system_info_alter()`, suggested the System module provides it, which is not the case. The old hook still works but is deprecated and will be removed in Drupal 13.

## Impact

Affects module maintainers.

- **API change:** Alter hook for extension info renamed from `system_info` to `extension_info`; the old hook is still invoked but triggers a deprecation.
- **Deprecation:** `hook_system_info_alter()` is deprecated in drupal:12.1.0 and removed from drupal:13.0.0, in favor of `hook_extension_info_alter()`.
- **New API:** New `hook_extension_info_alter(array &$info, Extension $file, $type)` for altering module and theme .info.yml data.

## Technical details

`ExtensionList::doList()` now calls `$this->moduleHandler->alter('extension_info', ...)` for each extension. It then calls `alterDeprecated()` with the `system_info` hook name and a message pointing to the change record https://www.drupal.org/node/3624723. Existing `hook_system_info_alter()` implementations therefore keep running and emit a deprecation. Both hooks are invoked, the new one first. The thread discussed ordering and concluded it should not matter much, since an implementor who cares can guard with a class property or check the altered values.

In `core.api.php`, `hook_extension_info_alter()` is documented and `hook_system_info_alter()` is marked `@deprecated`. Core's own test module implementations were renamed to `#[Hook('extension_info_alter')]`. Test state keys and the `update_test.settings` config key `system_info` also became `extension_info`, but these are test-only. The `ModuleExtensionList` comment and a `ProjectInfo` comment were updated to the new name.

The issue targeted the new hook at 12.1.0, with removal of the old one in 13.0.0. It was not added to 11.x. The change record explains how to support both versions in the meantime.

## Upgrade

Rename your implementation. In an OOP hook class:

```php
#[Hook('extension_info_alter')]
public function extensionInfoAlter(array &$info, Extension $file, $type): void {
  // ...
}
```

Replace `#[Hook('system_info_alter')]` and `hook_system_info_alter()` implementations before Drupal 13. See the change record https://www.drupal.org/node/3624723 for keeping 11.x support.
