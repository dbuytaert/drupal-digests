## Summary

Drupal 12.0.x and main now ship Symfony 8.2.0-BETA2 (previously BETA1). The Symfony version constraints in core's Composer files were raised from 8.1 to 8.2. The release notes say Symfony will be updated again to stable 8.2.0 before Drupal 12.0.0 is released.

## Impact

Affects site owners.

- **Requirements:** Drupal core's `composer.json` and `core/composer.json` now require Symfony components `^8.2` instead of `^8.1`; the lock file pins 8.2.0-BETA2 packages.

## Technical details

The change is Composer-only: `composer.json`, `core/composer.json` and `composer.lock` were updated. The `^8.1` constraints for `symfony/*` packages (console, dependency-injection, event-dispatcher, filesystem, finder, http-foundation, http-kernel, mailer, mime, process, routing, runtime, serializer, validator, yaml, and dev packages such as browser-kit, css-selector, dom-crawler, error-handler, lock, var-dumper) became `^8.2`. The issue thread says the constraints were bumped here because leaving them at `^8.1` after [#3634655](https://www.drupal.org/node/3634655) (BETA1) caused failures in the Updated Dependencies CI job: `Symfony\Component\Routing\Attribute\Route::__construct()` received `null` for `$alias` when called from `Drupal\Core\Routing\Attribute\Route`. Some Symfony packages (css-selector, dom-crawler, error-handler, event-dispatcher, filesystem, process, psr-http-message-bridge, string, var-exporter) had no BETA2 release at the time. An unrelated Guzzle deprecation found in the same job was handled in [#3638086](https://www.drupal.org/node/3638086).
