## Summary

`DateTimePlus::prepareFormat()` has been a no-op that returns its argument unchanged since the date formatting optimization in [#1844956](https://www.drupal.org/node/1844956). It is removed in Drupal 12 (main and 12.0.x) and deprecated in 11.x and 11.5.x. Custom code that subclasses `DateTimePlus` and overrides or calls this method should stop doing so.

## Impact

Affects module maintainers.

- **API change:** Protected `DateTimePlus::prepareFormat()` is removed from the main branch (12.x); it was deprecated in 11.5 for removal in 12.0.0.

## Technical details

The commit on `main` deletes the `protected function prepareFormat($format)` method from `core/lib/Drupal/Component/Datetime/DateTimePlus.php`. Per the issue, it is unused in core and in contrib. Because the 12.x branch had already had its deprecated code removed before beta, the work was split: the 11.x and 11.5.x commits carry the deprecation (the issue states deprecation in 11.5.0 for removal in 12.0.0, with a change record at node 3619997 linked in the deprecation message), while `main` and 12.0.x get the removal. The 11.x diff was not part of the fetched commit, so the exact deprecation call was not verified.

## Upgrade

If a subclass of `DateTimePlus` overrides or calls `prepareFormat()`, remove that code. The method only returned `$format` unchanged, so pass the format string directly.
