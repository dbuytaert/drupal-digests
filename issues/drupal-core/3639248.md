## Summary

Six core classes no longer carry deprecated service properties that used to be lazily resolved from the container with a deprecation notice. Code that extends these classes or reaches into those properties will no longer get the service and must obtain it another way. The removal was scheduled before the Drupal 12 release candidate.

## Impact

Affects module maintainers.

- **API change:** Deprecated service properties removed: `RouteBuilder::$controllerResolver` and `$moduleHandler`, `Router::$urlGenerator`, `ComponentNegotiator::$moduleExtensionList`, `Permission::$moduleHandler` (views access), `Permissions::$moduleHandler` (views filter), `AdminNegotiator::$entityTypeManager`.

## Technical details

These properties were deprecated through `DeprecatedServicePropertyTrait` and a `$deprecatedProperties` map, so they were missed when removals were found by grepping for deprecation strings. The issue also notes the trait hard-codes 11.0.0 as the removal version for properties, so the messages were wrong (see [#3519400](https://www.drupal.org/node/3519400)).

The commit removes the trait usage and the `$deprecatedProperties` arrays from `Drupal\Core\Routing\RouteBuilder` (`controllerResolver` => `controller_resolver`, `moduleHandler` => `module_handler`), `Drupal\Core\Routing\Router` (`urlGenerator`), `Drupal\Core\Theme\ComponentNegotiator` (`moduleExtensionList`), `Drupal\user\Plugin\views\access\Permission` and `Drupal\user\Plugin\views\filter\Permissions` (`moduleHandler`), and `Drupal\user\Theme\AdminNegotiator` (`entityTypeManager`). Two now-obsolete PHPStan baseline entries for `DependencySerializationTrait` private properties in `Permission` and `Permissions` were dropped. `DirectoryWithMetadataDiscovery` also uses the trait but was left out of scope, as its removal is scheduled for Drupal 13.

## Upgrade

If a subclass or other code relied on these magic properties, inject the service explicitly, for example in a subclass of `AdminNegotiator`:

```php
public function __construct(
  AccountInterface $user,
  protected EntityTypeManagerInterface $entityTypeManager,
  // ...
) {}
```

Same applies to `moduleHandler` on `Permission`/`Permissions`/`RouteBuilder`, `urlGenerator` on `Router`, and `moduleExtensionList` on `ComponentNegotiator`.
