## Summary

The Syndicate block (the RSS feed icon block) was deprecated in Drupal 11.2 with no replacement and its plugin code was removed ahead of Drupal 12. That left orphaned `block.block.*` configuration on any site that still had the block placed. Running database updates to Drupal 12.0.0 now automatically deletes that leftover block configuration, in any theme, not just Olivero where the block originally lived.

## Impact

Affects site owners.

- **Config change:** New `block_post_update_remove_syndicate_blocks()` post update deletes any `block.block.*` configuration using the removed `node_syndicate_block` plugin whose `settings.provider` is `node`, in any theme.

## Technical details

The fix adds `block_post_update_remove_syndicate_blocks()` in `core/modules/block/block.post_update.php`, which loads all `block` config entities with `plugin` set to `node_syndicate_block` and `settings.provider` set to `node`, and deletes them. Restricting the match to `settings.provider: node` (rather than just the plugin ID) means a block config entity that a contrib or custom module has taken over, for example by changing its provider, such as the `stark_custom_syndicate` fixture with `provider: custom_syndicate`, is left alone.

Test coverage was added in `BlockRemoveSyndicateBlocksUpdateTest`, using new fixtures (`block.block.olivero_syndicate.yml`, `block.block.stark_syndicate.yml`, `block.block.stark_custom_syndicate.yml`) loaded via a new `syndicate-block-config.php` update fixture script, verifying that Syndicate blocks in both Olivero and Stark are removed while the provider-overridden block and unrelated blocks survive the update. The related issue [#3518990](https://www.drupal.org/node/3518990) originally deprecated the `SyndicateBlock` plugin before its removal in core.
