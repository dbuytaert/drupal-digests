## Summary

Drupal core has removed the Backbone.js and Underscore.js third-party JavaScript libraries entirely. These were already marked internal-only and deprecated as of Drupal 10 (toolbar was the last core consumer of Backbone, and Underscore was only present as Backbone's dependency). Since Drupal 10 they carried no supported public API, but any contributed module or theme that still attached the `core/internal.backbone` or `core/internal.underscore` libraries, or otherwise relied on the global `Backbone`/`_` objects being present, will now find them missing and must bundle their own copies.

## Impact

Affects module maintainers.

- **Deprecation:** The `internal.backbone` and `internal.underscore` libraries, deprecated for external use since Drupal 10, are fully removed from `core.libraries.yml` and the `core/assets/vendor` directory; nothing in core ships or depends on Backbone.js or Underscore.js anymore.

## Technical details

The change removes the `internal.backbone` and `internal.underscore` library definitions from `core/core.libraries.yml`, deletes the vendored `core/assets/vendor/backbone` and `core/assets/vendor/underscore` directories, and drops the corresponding `COPYRIGHT.txt` entries. It also removes `backbone` and `underscore` from `core/package.json` and `core/yarn.lock`, removes their asset-fetch entries from `core/scripts/js/vendor-update.js` (the script that downloads vendor JS during core releases), and drops the now-unused `Backbone: 'readonly'` global from `core/eslint.config.mjs`.

No core JavaScript referenced these libraries anymore at the time of removal (grepping the codebase before the patch turned up references only in the vendor files and library/config plumbing listed above), confirming the libraries were dead weight left over from the Drupal 10 deprecation.

## Upgrade

Sites, modules, or themes that still declare a library dependency such as:

```yaml
dependencies:
  - core/internal.backbone
  - core/internal.underscore
```

or otherwise expect the global `Backbone` or `_` (Underscore) objects to be available because core loaded them, must now provide their own copies of Backbone.js and/or Underscore.js as third-party dependencies. Core no longer ships or loads these libraries.
