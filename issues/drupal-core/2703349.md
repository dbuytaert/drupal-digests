## Summary

In the Views UI menu settings for a Page display, the *Show as expanded* checkbox now appears only when *Normal menu entry* is selected. Previously it stayed visible for every menu option, including *No menu entry* and the menu tab options, where it had no effect. This matches the other menu settings (title, description, parent, weight, context), which already hid when they did not apply.

## Impact

No upgrade or configuration changes required.

## Technical details

`Drupal\views\Plugin\views\display\Page::buildOptionsForm()` adds a `#states` `visible` condition to the `expanded` element, keyed on `:input[name="menu[type]"]` having the value `normal`. The setting is only read for normal menu links in `PathPluginBase::getMenuLinks()`, so hiding it for other types does not change stored behavior. A FunctionalJavascript test, `testMenuExpandedVisibility()`, was added to the `views_ui` tests. It checks the checkbox is hidden for the initial menu tab type, shown after choosing `normal`, and hidden after choosing `none`.
