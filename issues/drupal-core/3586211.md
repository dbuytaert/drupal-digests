## Summary

The Toolbar module, the classic black admin bar shown across the top of the page for users with access, has been removed from Drupal core entirely. It had already been deprecated ([#3560123](https://www.drupal.org/node/3560123)) since the Navigation module became the default admin toolbar. Sites that still rely on Toolbar (for example those that opted out of Navigation) need to install the Toolbar contrib module before updating, or migrate to Navigation.

## Impact

Affects site owners.

- **Requirements:** Sites with the `toolbar` module enabled will get an update-path error naming it as a removed core module (`SystemRequirements::DRUPAL_CORE_REMOVED_MODULE_LIST`) until it is uninstalled or replaced by the contrib version.

## Technical details

The commit deletes `core/modules/toolbar` in its entirety: the module's PHP (`ToolbarHooks`, `ToolbarController`, `Element/Toolbar`, `Element/ToolbarItem`, link builders for user/announcements/workspaces, etc.), its Twig templates, libraries, permissions, routing, breakpoints, all CSS/PCSS/SVG assets, the `toolbar_test` and `toolbar_disable_user_toolbar` test support modules, and the full functional/unit/Nightwatch test suites, 127 files and roughly 11,800 lines in total.

Outside the module directory, the change is minimal since Toolbar's responsibilities had already been migrated to the Navigation module in prior issues (including [#3618746](https://www.drupal.org/node/3618746), which moved Toolbar-only integration code out of the User, Contextual, and Announcements Feed modules). The only functional addition is in `SystemRequirements::DRUPAL_CORE_REMOVED_MODULE_LIST`, where `'toolbar' => 'Toolbar'` is added so `update.php` flags any site that still has the module enabled. `core/.phpstan-baseline.php` and `core/MAINTAINERS.txt` are trimmed of now-dead references.

## Upgrade

If a site still has the `toolbar` module enabled, running database updates will fail with a removed-module error until the module is uninstalled or replaced. To keep the classic admin bar, install the contrib Toolbar module before updating:
```
composer require drupal/toolbar
```
Otherwise, use the core Navigation module, which is enabled by default and replaces Toolbar's functionality.
