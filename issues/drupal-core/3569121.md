## Upgrade

Sites that use core's Shortcut module must install the contributed `shortcut` project (Composer package `drupal/shortcut`) before upgrading to a core release where the module has been removed (see [#3586214](https://www.drupal.org/node/3586214)), in order to retain shortcut functionality and existing shortcut data.
