## Summary

Several protected helper methods and a property in Drupal core's `PdoTrait` (used by PDO-based database drivers) were found to be dead code, no longer called anywhere in core. They are now formally deprecated and will be removed in Drupal 13. There is no replacement, since nothing in core needs them anymore. Sites and modules are unaffected unless they maintain a custom database driver that extends or calls into these internals.

## Impact

Affects module maintainers.

- **Deprecation:** `PdoTrait::$fetchModeLiterals`, `pdoToFetchAs()`, `clientFetchColumn()`, `clientFetchObject()`, and `clientQueryString()` are deprecated for removal in Drupal 13, with no replacement.

## Technical details

`pdoToFetchAs()` became unused once [#3522561](https://www.drupal.org/node/3522561) fully typed `StatementInterface` method parameters, removing the need to convert legacy `\PDO::FETCH_*` integer constants to the `FetchAs` enum at that call site. `clientFetchColumn()`, `clientFetchObject()`, and `clientQueryString()` were likewise found to have no remaining callers in core. Each now carries an `@deprecated in drupal:11.5.0 and is removed from drupal:13.0.0` docblock and, for the three methods, an `@trigger_error()` call emitting an `E_USER_DEPRECATED` notice pointing to the change record at drupal.org/node/3611848.

The `protected array $fetchModeLiterals` property (used only for building deprecation/error messages, mapping `\PDO::FETCH_*` constants to their literal names) is deprecated too. As discussed in the issue thread, this property had been moved from `FetchModeTrait` into `PdoTrait` five months earlier in [#3525077](https://www.drupal.org/node/3525077), so the deprecation was applied at its current location in `PdoTrait`.

## Upgrade

Custom database drivers or contrib code that override or call `PdoTrait::pdoToFetchAs()`, `clientFetchColumn()`, `clientFetchObject()`, `clientQueryString()`, or read `PdoTrait::$fetchModeLiterals` should remove that usage before Drupal 13, since there is no replacement:

```php
// Deprecated, will be removed in Drupal 13 with no replacement:
protected function pdoToFetchAs(int $mode): FetchAs { ... }
protected function clientFetchColumn(int $column = 0): int|float|string|bool|NULL { ... }
protected function clientFetchObject(?string $class = NULL, array $constructorArguments = []): object|FALSE { ... }
protected function clientQueryString(): string { ... }
```
