## Summary

The `Media` entity's `getRequestTime()` method, previously undocumented beyond a generic `{@inheritdoc}` comment despite not actually overriding anything, is now deprecated with no replacement. The method will be removed in Drupal 13. It is no longer used internally by Drupal core, so most sites are unaffected; only code that explicitly calls `Media::getRequestTime()` needs to change.

## Impact

Affects module maintainers.

- **Deprecation:** `Media::getRequestTime()` is deprecated in drupal:12.1.0 and removed from drupal:13.0.0, with no replacement.

## Technical details

The `created` base field on the `Media` entity used `Media::getRequestTime()` as its `setDefaultValueCallback()`, even though the method simply returned `\Drupal::time()->getRequestTime()`, the same value the `created` field type (`CreatedItem::applyDefaultValue()`) already sets by default. Since the callback was redundant, it was removed from `Media::baseFieldDefinitions()` entirely rather than just documented, and the method itself was marked `@deprecated` with a proper docblock, a return type hint (`: int`), and a `trigger_error()` call pointing to the change record at https://www.drupal.org/node/3624921. The corresponding PHPStan baseline entry for the method's missing return type was also removed since the new return type hint makes it unnecessary.

## Upgrade

Replace any direct calls to the deprecated method:

```php
// Before:
$time = Media::getRequestTime();

// After:
$time = \Drupal::time()->getRequestTime();
```

### Collaboration

What started as a documentation-only fix changed direction after catch pointed out that `getRequestTime()` wasn't needed at all, since `CreatedItem` already defaults the `created` field to the request time without it; this prompted removing the `setDefaultValueCallback()` usage and deprecating the method instead of just documenting it. Later, catch also caught that the deprecation's target version needed updating once Drupal 12.0.x opened, which avpaderno corrected to drupal:12.1.0 after initially targeting the wrong release.
