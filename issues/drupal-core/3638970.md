## Summary

Drupal 12.0.0 ships with refreshed front-end libraries. jQuery goes from 4.0.0 to 4.1.0, htmx from 4.0.1 to 4.0.2, tabbable from 6.5.0 to 6.5.2 and transliteration from 2.6.1 to 2.7.0. The transliteration update fixes the mapping of `Ý`, which now becomes `y` instead of `u` when machine names are generated in the browser. If your custom or contrib JavaScript depends on jQuery or htmx internals, retest it against these versions.

## Impact

Affects front-end developers and site owners.

- **Config change:** Machine name transliteration now maps `Ý` to `y` instead of `u`, so generated machine names for input containing `Ý` differ.
- **Theme change:** Bundled jQuery moves from 4.0.0 to 4.1.0 and htmx from 4.0.1 to 4.0.2; custom JS and themes relying on them should be retested.

## Technical details

The vendored files under `core/assets/vendor/` (`jquery/jquery.min.js`, `htmx/htmx.min.js`, `tabbable/index.umd.min.js`, `transliteration/bundle.umd.min.js`) were rebuilt, and the `version` and license URL entries for `jquery`, `htmx`, `tabbable` and `transliteration` in `core/core.libraries.yml` were updated to match `core/package.json`. The jQuery 4.1.0 diff includes Sizzle selector changes: simple tag and class selectors now go through `querySelectorAll` rather than `getElementsByTagName` and `getElementsByClassName`, and CSS escape handling and `jQuery.uniqueSort` were reworked. The htmx 4.0.2 diff changes how pending delayed or throttled triggers are cleared (scoped to the same `hx-trigger` value), `<title>` lookup in fragments, and the Firefox check for the Navigation API in history handling (now Firefox 159 and later).

Build-time dependencies were also bumped in `core/package.json`, including `chokidar` ^6, `glob` ^14, `jsdom` ^31, `cspell`, `postcss-preset-env`, `prettier`, `webpack` and `webpack-cli`. `eslint`, `eslint-plugin-jsdoc` and `eslint-plugin-yml` were deliberately not updated, and `stylelint` was kept at ^17.16.0 to match the 11.5.0 update ([#3625623](https://www.drupal.org/node/3625623)), with ESLint and PostCSS handled separately. The machine name FunctionalJavascript/Nightwatch test expectation changed from `dnoooooxouuuuuthss` to `dnoooooxouuuuythss` to reflect the `transliteration` fix.
