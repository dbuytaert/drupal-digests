## Summary

The obsolete Single-Directory Components (`sdc`) module has been deleted from core in Drupal 12. It had already been deprecated, marked `lifecycle: obsolete` and hidden from the UI. Sites should have uninstalled it while on 11.x. Code that still depends on the `sdc` module will no longer find it.

## Impact

Affects module maintainers.

- **API change:** The obsolete `sdc` module (`core/modules/sdc`, Single-Directory Components) is removed from core on `main` and `12.0.x`.

## Technical details

The commit removes the `core/modules/sdc` folder. The only part of the diff available to me was the deleted `sdc.info.yml`: it declared `lifecycle: obsolete`, `hidden: true` and a dependency on `drupal:serialization`. No 11.x change was made. A thread comment says the module should already have been uninstalled by `system_post_update_sdc_uninstall()`, so no new update path was added. An 11.x MR (!16760) that copied the `migrate_drupal` uninstall post-update pattern was discussed, then not pursued. The change was committed to `main` (`23a93c7b`) and backported to `12.0.x` (`cedce166`).

## Upgrade

Before upgrading to Drupal 12, make sure the `sdc` module is uninstalled. Per the thread, `system_post_update_sdc_uninstall()` should already have done this on 11.x, so run all pending updates first. Remove any `sdc` entry from custom modules' `dependencies` and from `core.extension` configuration you manage.
