## Summary

Ahead of Drupal 12.0.0-beta1, core's bundled JavaScript build and lint tooling dependencies were refreshed to their latest versions (Yarn packages such as webpack, terser, jsdom, chokidar, glob, cspell, prettier, stylelint, and vendored front-end libraries like floating-ui, sortablejs, tabbable and tua-body-scroll-lock). This is mostly an internal maintenance update with no effect on site configuration or content, but it does include one change that can affect custom JavaScript: the bundled transliteration library used for generating machine names now exposes its transliterate function differently, so code that referenced the old global must be updated.

## Impact

Affects module maintainers.

- **API change:** The bundled `transliteration` vendor library (2.3.5 to 2.6.1) now exposes a `transliteration` object instead of a `transliterate` global function; `core/misc/machine-name.js` was updated to call `transliteration.transliterate`.

## Technical details

The update was produced largely by running `yarn upgrade-interactive` and `yarn vendor-update` and regenerating derived build artifacts. The one behavior-relevant change: the `transliteration` npm package (2.3.5 to 2.6.1) changed its browser bundle from a `transliterate` global function to a `transliteration` object, so `core/misc/machine-name.js` now calls `transliteration.transliterate(...)` instead of `transliterate(...)`, and the ESLint globals list in `eslint.config.mjs` was updated to declare `transliteration` instead of `transliterate`.

Several riskier or larger bumps found during the upgrade were deliberately deferred to follow-up issues to keep this change reviewable: ESLint 10 (blocked on `eslint-plugin-import` lacking a compatible release, tracked in [#3625189](https://www.drupal.org/node/3625189)), `postcss`/`postcss-import` (tracked in [#3625308](https://www.drupal.org/node/3625308), since their whitespace-handling change would have regenerated 121 compiled CSS files), and `eslint-plugin-yml` 3.x (tracked in [#3625576](https://www.drupal.org/node/3625576)). The `stylelint-config-standard` bump to 40.0.0 enables the `property-no-deprecated` rule, which flags 74 existing uses of deprecated CSS properties (`page-break-*`, `word-wrap`, `clip`) in core themes; rather than fixing those here, the rule was set to `null` in `.stylelintrc.json` until [#3625187](https://www.drupal.org/node/3625187) addresses them. `eslint-plugin-no-jquery` was bumped to 6.0.0, which supports flat ESLint config natively, so the `fixupPluginRules()` wrapper and the now-unused `@eslint/compat` dependency were removed from `eslint.config.mjs`. Vendored copies of `@floating-ui/dom`, `sortablejs`, `tabbable` and `tua-body-scroll-lock` under `core/assets/vendor` were regenerated, and the CKEditor 5 plugin builds were regenerated due to newer `webpack`/`terser` output.

## Upgrade

Custom or contrib JavaScript that relies on the `transliterate` global provided by core's `core/transliteration` library must update the call site:

```js
// Before
transliterate(source, options);

// After
transliteration.transliterate(source, options);
```
