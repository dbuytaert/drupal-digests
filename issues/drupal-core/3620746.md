## Summary

This task removes a batch of Drupal core methods, one function, and one admin route that had been marked deprecated in the 11.x cycle for removal in Drupal 12.0.0. None of these had replacements except where noted below, so code relying on them will fatal error once sites run on Drupal 12. Site owners using the "compact mode" admin toggle (`/admin/compact/on` or `/admin/compact/off`) will find that page gone entirely, as it had no replacement.

## Impact

Affects module maintainers.

- **API change:** Removed `SqlContentEntityStorage::loadFromSharedTables()`, `RouteBuilder::getRouteDefinitions()`, `BlockListBuilder::systemRegionList()`, `BlockController::getVisibleRegionNames()`, `BlockDeleteForm::systemRegionList()`, `SystemController::compactPage()` (and its route `system.admin_compact_page`), `UserController::validatePathParameters()`, `ViewsData::cacheGet()`/`cacheSet()`, and `ServerCommand::getOneTimeLoginUrl()`.
- **Deprecation:** Several methods and one route (`admin/compact/{mode}`) that were deprecated in 11.x for removal in 12.0.0 have now been deleted from core, with no replacement in most cases.

## Technical details

The removals span several subsystems: `Drupal\Core\Entity\Sql\SqlContentEntityStorage::loadFromSharedTables()` (no replacement), `Drupal\Core\Routing\RouteBuilder::getRouteDefinitions()` (functionality moved to `Drupal\Core\Routing\YamlRouteDiscovery`), `Drupal\Core\Command\ServerCommand::getOneTimeLoginUrl()` (no replacement), `Drupal\system\Controller\SystemController::compactPage()` along with its route `system.admin_compact_page` (no replacement, and its functional test `testCompactMode()` in `AdminTest.php` was deleted too), `Drupal\user\Controller\UserController::validatePathParameters()` (replaced by `Drupal\user\OneTimeAuthentication::verifyHmac()`), and `Drupal\views\ViewsData::cacheGet()`/`cacheSet()` (no replacement).

Three copies of a `systemRegionList()` wrapper around the removed `system_region_list()` function, in `Drupal\block\BlockListBuilder`, `Drupal\block\Controller\BlockController` (as `getVisibleRegionNames()`), and `Drupal\block\Form\BlockDeleteForm`, were also deleted; callers should use `$this->themeHandler->getTheme()->listAllRegions()` or `listVisibleRegions()` directly. `core/.phpstan-baseline.php` was updated to drop now-obsolete ignore entries for the removed methods. A maintainer noted in the issue thread that a regex search for the standard `is removed from drupal:12.0.0` deprecation message found no further methods, though some classes still pending removal remain for follow-up issues.

## Upgrade

Replace any calls to the removed APIs before upgrading to Drupal 12.0.0:

```php
// Before:
$route_builder->getRouteDefinitions();
// After: use YamlRouteDiscovery directly, or rely on the route rebuild
// machinery which already does this internally.

// Before:
$this->systemRegionList($theme, 'all');
// After:
$this->themeHandler->getTheme($theme)->listAllRegions();
// or
$this->themeHandler->getTheme($theme)->listVisibleRegions();

// Before:
$this->validatePathParameters($user, $timestamp, $hash, $timeout);
// After:
$this->oneTimeAuthentication->verifyHmac($user, $timestamp, $hash, $timeout);
```

The `/admin/compact/{mode}` route and its `system.admin_compact_page` route name no longer exist; remove any links or code that reference them. `ViewsData::cacheGet()`/`cacheSet()` and `SqlContentEntityStorage::loadFromSharedTables()` have no replacement; remove any overrides or calls.</upgrade>
