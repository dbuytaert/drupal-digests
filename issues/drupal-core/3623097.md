## Summary

This is a follow-up cleanup of Drupal core's new, still-experimental "Default Admin" theme (forked from Gin/Claro), removing leftover references to the old "Gin" and "Claro" project names. The theme's "Focus color" setting previously stored the values `gin` and `claro` for its default and legacy-green presets; these are now named `default` and `legacy_green`. Existing sites with a saved focus color preference are updated automatically, no manual action is required for the common case, but the underlying stored value and the HTML attribute it produces have changed names. Several leftover icon files and a stale README that were copied from Claro's source tree were also removed from core, since the theme now either shares images with other components or no longer needs them.

## Impact

Affects front-end developers and site owners.

- **Config change:** Default Admin theme's `preset_focus_color` setting values renamed: `gin` to `default`, `claro` to `legacy_green`; existing stored config and per-user overrides are migrated automatically by a new post_update hook.
- **Theme change:** The `data-admin-focus` HTML attribute now uses `default`/`legacy_green` instead of `gin`/`claro`, so custom CSS targeting the old attribute values or `[data-admin-focus="claro"]`/`[data-admin-focus="gin"]` selectors must be updated.

## Technical details

The `Settings::getSettingsForm()` select options for `preset_focus_color` were renamed from `gin`/`claro` to `default`/`legacy_green`, and the CSS selectors in `accent.css`/`accent.pcss.css` were updated from `[data-admin-focus="claro"]` to `[data-admin-focus="legacy_green"]` (the `gin` value already mapped to the default preset and needed no selector change). A new `default_admin.post_update.php` adds `default_admin_post_update_rename_focus_color_presets()`, which rewrites the `default_admin.settings` config and any per-user overrides stored via `user.data` (in both the newer `settings` array format and the older flat key format) from the old `gin`/`claro` values to `default`/`legacy_green`. Coverage for this migration lives in the new `FocusColorPresetUpdateTest` kernel test.

Separately, several SVG icons and a README under `images/core/` that were copied from Claro's source tree (and marked for removal once Claro moved into core) were deleted: one required-field icon moved into `images/icons/` and is referenced from the compiled `accent.pcss.css`, and the remaining icons were dropped because equivalent images already exist elsewhere or are unused. The `tests/fixtures/implementation-name-allowlist.json` allowlist used by `ImplementationNameTest` was updated to drop entries for the removed `claro` references and add entries for the new post-update and test files, which still legitimately reference the old preset key names for migration purposes.

## Upgrade

Custom subthemes or CSS overriding the focus color attribute should update selectors:

```css
/* before */
[data-admin-focus="claro"] { ... }

/* after */
[data-admin-focus="legacy_green"] { ... }
```

Any custom code reading or setting the `default_admin.settings:preset_focus_color` config value or a user's `default_admin` user data directly should use `default` instead of `gin` and `legacy_green` instead of `claro`. Existing stored values are migrated automatically by `default_admin_post_update_rename_focus_color_presets()`.
