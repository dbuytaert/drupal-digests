## Summary

The `navigation_top_bar` module has been removed entirely from Drupal core. This module was a placeholder with no functionality of its own: its features were folded into the main Navigation module back in Drupal 11.3, and an update hook already uninstalled it on any site that had it enabled. Because that uninstall step has been required since around Drupal 11.2, there is nothing for site owners to do; sites upgrading through 11.x to 12 will not be affected.

## Impact

Affects module maintainers.

- **Deprecation:** The obsolete `navigation_top_bar` module (a feature flag with no code, merged into Navigation in 11.3) has been deleted from Drupal core; it no longer exists as of 12.0.x.

## Technical details

The module consisted of a single `navigation_top_bar.info.yml` file marked `lifecycle: obsolete`, with no PHP, templates, or config of its own; it depended on `navigation:navigation` and served only as a feature flag during the transition period. The commit deletes `core/modules/navigation/modules/navigation_top_bar` outright, which also removes the now-empty `core/modules/navigation/modules` directory.

Safety of the removal relies on `navigation_post_update_uninstall_navigation_top_bar()`, added in 11.3, which uninstalls the module on any site where it's still enabled, and on the entry for that post-update already being listed in `navigation_removed_post_updates()` on main as removed as of 12.0.0. Since Drupal's update path requires running all pending update hooks before a major version upgrade, and `ModuleInstaller` rejects installing obsolete modules, sites cannot reach 12.x with `navigation_top_bar` still installed. A grep of core confirmed no other code references the module's name aside from the removed post-update function itself.</technical>
