## Summary

Drupal core had the same logic for pulling uploaded files out of the current HTTP request duplicated in several places: the procedural `file_save_upload()` and `file_managed_file_save_upload()` functions, and `ConfigImportForm::validateForm()`. This issue consolidates that logic into a single reusable service. There is no behavior change for site owners or end users; file uploads via forms, the managed file element, and configuration import all continue to work exactly as before.

## Impact

Affects module maintainers.

- **New API:** New `Drupal\Core\File\UploadedFilesExtractor::extractUploadedFiles()` service method for retrieving uploaded files for a given form element name from the current request.

## Technical details

A new `Drupal\Core\File\UploadedFilesExtractor` service (autowired in `core.services.yml`) exposes `extractUploadedFiles(string $name): UploadedFile[]`, which reads `$this->requestStack->getCurrentRequest()->files->get('files', [])`, looks up the given form element name, and normalizes the result to always return an array (wrapping single uploads). `file_save_upload()` and `file_managed_file_save_upload()` in `file.module` now call this service via `\Drupal::service(UploadedFilesExtractor::class)` instead of inlining the request lookup and array-normalization logic. `ConfigImportForm` was also converted to constructor-based dependency injection using `AutowireTrait` and PHP attributes, and its `validateForm()` now calls the injected `UploadedFilesExtractor` and uses `reset($uploaded_files)` to get the single tarball upload.

The fourth duplicate identified in the issue, `Drupal\Core\Render\Element\File::valueCallback()`, was deliberately left untouched: its handling casts the uploaded file object to an array, which the issue authors considered "different and strange" and out of scope for this cleanup (an early attempt to convert it was reverted during review).

```php
use Drupal\Core\File\UploadedFilesExtractor;

// Via dependency injection:
public function __construct(
  protected UploadedFilesExtractor $uploadedFilesExtractor,
```
