## Summary

A `type: array` component prop with object items, linked to a multi-valued entity field in a content template, now receives a list of objects (one per field item). Before, it got a single object whose keys each held a list, so for example an image gallery with two images printed four empty `<img>` elements. No update path is needed, since only the expression is stored, not its evaluated value. Single-cardinality fields and expressions with an explicit delta evaluate as before.

## Impact

Affects module maintainers.

- **New API:** `withDelta(int $delta): static` added to `EntityFieldBasedPropExpressionInterface` and implemented by `FieldPropExpression`, `FieldObjectPropsExpression` and `ReferenceFieldPropExpression`.

## Technical details

`Evaluator::doEvaluate()` evaluated each key of a `FieldObjectPropsExpression` over the whole field item list. Validation did not catch it, because core's `ComponentMetadata` added `object` to the `type` of every prop (per the issue; core 11.5 no longer does, see [#3591948](https://www.drupal.org/node/3591948)). `StaticPropSource` with `FieldTypeObjectPropsExpression` already evaluated once per field item.

Now, when the expression is a `FieldObjectPropsExpression`, the field cardinality is not 1 and `getDelta()` is `NULL`, `doEvaluate()` loops over the field items and re-evaluates `$expr->withDelta($delta)` for each. The results are merged into one `EvaluationResult` so cacheability and attachments of every object are kept, including objects that are then dropped. Empty objects (for instance when every object prop needs a referenced entity that was deleted) are filtered out and the list is reindexed with `array_values()`, so the `type: array` prop gets no gaps.

`withDelta()` is a new method on `EntityFieldBasedPropExpressionInterface`. `FieldPropExpression` sets the delta, `FieldObjectPropsExpression` sets it on itself and on every object prop expression, and `ReferenceFieldPropExpression` sets it only on the referencer, since the referenced expression targets another entity's field. Tests added: a multi-valued `daterange` case in `EntityFieldPropSourceTest`, rendering `image-gallery` with an unlimited image field in `NodeTemplatesTest`, broken-reference cases, and `PropExpressionTest::testWithDelta()`.

## Upgrade

Any custom class implementing `EntityFieldBasedPropExpressionInterface` must now implement `public function withDelta(int $delta): static`.
