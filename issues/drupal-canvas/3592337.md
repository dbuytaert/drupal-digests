## Summary

With Canvas headless, opening an unpublished node or Canvas page at its normal Drupal URL used to show an empty content area instead of the configured headless frontend, even for editors who could view the entity and had `access canvas headless preview`. The frontend is now embedded on unpublished canonical pages too, for users who already pass Drupal's access check and have that permission.

## Impact

No upgrade or configuration changes required.

## Technical details

`EmbeddedPreviewSubscriber` in `canvas_headless` previously skipped embedding when a non-preview canonical route's entity was an unpublished `EntityPublishedInterface`. That condition is removed. Route access has already decided whether the user may view the entity, and the embedded preview renders the same saved default revision with the user's own permissions. Authenticated-user and `access canvas headless preview` checks remain, so other visitors still get Drupal's normal rendering (or a 403 if access is denied).

The README section is renamed from 'Published route previews' to 'Canonical route previews' and notes two caveats: a canonical route renders the saved default revision without Canvas auto-saves, and the iframe replaces Drupal's rendered entity, including controls rendered as part of it such as Content Moderation's state form. Moderation state should be changed from the edit form. Kernel tests cover unpublished pages, nodes and translations, cache metadata, and HTTP-kernel access cases (200 embedded, 200 not embedded, 403).
