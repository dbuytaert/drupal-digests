# #3592052: Site template installation fails with Canvas 1.11

## Summary

Installing a Drupal CMS site template (`drush si recipes/drupal_cms_starter`) failed with Canvas 1.11.0, with the error "You have requested a synthetic service ("kernel"). The DIC does not know how to construct this service." The reporter found that downgrading to Canvas 1.10.1 made the install work again. The issue is marked fixed. A related fix to the site template install path is in Canvas 1.12.0, but the issue thread does not confirm that it is the fix for this report.

## Impact

No upgrade or configuration changes required.

## Technical details

The issue has no comments and no linked merge request, so the cause and fix are not stated there. I inferred a likely fix from the repository. Commit 64c59639 ([#3591996](https://www.drupal.org/node/3591996), first tagged in v1.12.0) changes `RecipeSubscriber` so that site template page variant migration runs in a new `migrateSiteTemplate()` handler. That handler is registered on `RecipeAppliedEvent` at priority `PHP_INT_MIN`, so it runs after all other applied subscribers. Its docblock says installing the page template component module rebuilds the container, and that running last stops later subscribers from using the invalidated container. That matches the symptom, since a rebuilt container can fail on the synthetic `kernel` service. No commit references [#3592052](https://www.drupal.org/node/3592052) directly, so treat the link as likely, not confirmed.
