# #3592123: Canvas AI: removeMediaFields() drops arrays of media IDs for multi-value media props

- **Project:** Drupal Canvas
- **Type:** Normal unknown (0)
- **Status:** Fixed

## Summary

When you ask the Canvas AI agent to place a component that has a multi-value image prop and name several media items, for example "Use media images 1 to 5", those media are now kept. Before, the list was dropped and the component showed its example images. A single media ID already worked.

## Impact

No upgrade or configuration changes required.

## Technical details

`removeMediaFields()` in `ui/src/components/aiExtension/placementUtils.ts` strips values a media-bound prop cannot store, so the component falls back to its example image. It previously kept only a single media ID (`isMediaId()`). The fix adds an exported `isMediaIdList()` helper and `removeMediaFields()` now also keeps a value when `isMediaIdList(value)` is true.

`isMediaIdList()` returns true only for a non-empty array where every item passes `isMediaId()`, so numbers and digit-only strings are accepted. Empty arrays and arrays mixing IDs with URLs or `{ src, alt }` objects are still dropped. Tests in `placementUtils.test.tsx` cover these cases.
