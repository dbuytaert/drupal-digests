# #3592120: Canvas AI: Give the Canvas Agent editor-facing knowledge about Drupal Canvas

## Summary

The Drupal Canvas Agent in the `canvas_dev_ai` module used to know only which Tool to select for a task and where the documentation lives. It could not answer questions like "How do I translate a page?" or "What is a page template?". Its prompt now includes editor-facing facts about the Canvas interface: pages, building a page, patterns, saving and publishing, page and content templates, translations, code components, and missing theme components. It is told to answer from those facts using the exact interface labels. When a question is not covered, it says so and points to https://project.pages.drupalcode.org/canvas/ instead of inventing an answer.

## Impact

Affects site owners.

- **Config change:** `modules/canvas_dev_ai/config/install/ai_agents.ai_agent.canvas_agent.yml` has a rewritten `system_prompt` with editor-facing facts about Canvas.

## Technical details

The change is confined to the `system_prompt` in `modules/canvas_dev_ai/config/install/ai_agents.ai_agent.canvas_agent.yml`. The prompt is restructured around two cases. Case A is a question, the default, answered only from a "Facts" section at the end of the prompt. Case B is a request to do the work, which the agent redirects to a Tool using the `[canvas_dev_ai:available_tools]` placeholder, with the existing Tool selection behaviour kept. Guardrails say never to add steps, labels, permissions, features or URLs that are not in the facts, to give only URLs that appear in the prompt, and to treat other Drupal or Canvas knowledge as unknown. Personalization, headless frontends, notifications and conflict resolution are explicitly declared out of scope, so the agent says so and gives the docs link. The facts were drafted by scanning the `docs/` folder and the UI code with Claude, per the issue body, and then verified against the UI.

## Upgrade

The prompt lives in `config/install`, so it applies on fresh installs of `canvas_dev_ai`. The issue says no update hook is added, so existing sites keep their stored `canvas_agent` config until it is reimported or re-saved.
