## Summary

Canvas AI now ships a skill for coding agents such as Claude Code or Codex. You build a few pages by hand in Canvas and give the skill their IDs. It studies them and writes a page guideline: which component trees serve each kind of section, typical section order, and which backgrounds, text and button styles go together. Saved as an AI Context item, the guideline helps the Canvas page agent build new pages that match the rest of the site. It also has a refine step for when a generated page comes out wrong.

## Impact

Affects module maintainers.

- **New API:** New agent skill `canvas-ai-page-context-generation` under `modules/canvas_ai/.agents/skills/` that generates a page guideline Markdown file for the Canvas page agent.

## Technical details

The skill lives in `modules/canvas_ai/.agents/skills/canvas-ai-page-context-generation/` as `SKILL.md`, a `README.md`, `references/output-format.md` and `references/refine.md`. It only reads the site through Drush. For page structure it loads the `Page` entity (using the auto-save entity when there are unpublished changes) and dumps each component's inputs as YAML. For what the page agent sees it calls `canvas_ai.component_context_helper` (`getComponentCatalog()` and `getComponentDetails()`), so every component ID, prop, enum value and slot written into the guideline is checked against what the agent receives. Components on pages but missing from the catalog are reported rather than written into trees.

The output is a file in `canvas-page-guidelines/` (default `site.md`) with front matter (`label`, `description`, `purpose`) and one YAML block. The YAML covers `structure`, `rules`, `colors`, `spacing`, `rich_text`, `typography`, `copy`, an `index` of patterns by content purpose, and `patterns` with `look`, `vary`, `repeat` ranges and component `tree`s. The document is limited to about 10,000 tokens. The skill offers, step by step and only with the user's agreement, to check the `canvas_ai_context` recipe consumer config, create or update an `ai_context_item`, and raise `ai_context.settings` `max_tokens`. It does not change the site otherwise.

## Upgrade

To use it, copy the skill into your coding agent's skills directory in the project root (for Claude Code):

```bash
mkdir -p .claude/skills
cp -R web/modules/contrib/canvas/modules/canvas_ai/.agents/skills/canvas-ai-page-context-generation .claude/skills/
```

Using the guideline needs the AI Context module connected to the page agent via the `canvas_ai_context` recipe, and roles using Canvas AI need the `access published ai context` permission.
