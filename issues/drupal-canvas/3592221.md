## Summary

In the Canvas AI dev chat (behind `aiDevMode`), selecting a single component now shows a chip at the top of the chat input box with the component's icon and name. Previously the agent received the selection but the chat gave no sign of it. A × button on the chip clears the selection. While an agent turn runs, the chip stays locked on the component that was selected when the message was sent, and its × is disabled. The live `AiWizard.tsx` is unchanged.

## Impact

No upgrade or configuration changes required.

## Technical details

The chip is a new React component, `SelectedComponentChip`, rendered as a sibling of `MemoDeepChat` inside a `position: relative` `Flex` wrapper (`.aiWizardChat`). Deep-chat has no slot at the top of its input box, and passing selection state through deep-chat props would re-render it and wipe the live progress message. The chip reuses the preview's `NameTag.module.css` `.nameTag` class and `Component1Icon`. It subscribes to the selection itself via `selectSelectedComponentUuid` and selects only the node with `findComponentByUuid`, so layout edits during a turn do not re-render it. The × calls `getDrupalSettings().canvas.componentSelectionUtils.unsetSelectedComponent()` at click time, because that object is replaced on every render.

To keep the typed text below the chip, the chip toggles a `data-has-selection` attribute on the `<deep-chat>` host. A new `:host([data-has-selection]) #text-input` rule in `DEEP_CHAT_AUXILIARY_STYLE` then sets the top padding with `!important`, since deep-chat applies text padding inline. Input box size and chip offsets live in the new `chatInputLayout.ts`, so the two cannot drift apart. The chip stays on the box when the window is short.

In `AiWizardDev.tsx`, the `isTurnInProgress` boolean state became `turnScope` state (`{ componentUuid }`). It is set when the message is sent, using `selectSelectedComponentUuid` so only a single selection counts as scope. It is cleared when the turn ends. The `activeComponentUuid` sent to the backend is that same value, or `''`. The Playwright test `Page builder agent turns` was extended to cover the hidden, shown, locked and deselect states. The test id is `canvas-ai-selected-component`.
