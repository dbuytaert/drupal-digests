## Summary

Code components that receive a `content-entity-reference` prop (for example a list of related news items) can now link to each referenced entity. Every entity object handed to the component carries a `__url` key with the entity's canonical URL, so no field pick is needed. Previously the only option was the URL alias pick, which is empty for any entity without an alias, such as taxonomy terms on a fresh site.

## Impact

Affects module maintainers and front-end developers.

- **Theme change:** Code components that linked via the `path␞␟alias` pick should switch to `__url`.
- **New API:** Every resolved `content-entity-reference` payload object now includes `__url`, the canonical URL of the entity or `null`.

## Technical details

`JsComponent::buildReferencePayload()` now builds the payload as `['__type' => $entity->bundle(), '__url' => $url]`. This applies to nested referenced entities too, since they go through the same method. The URL is generated only when `!$entity->isNew() && $entity->hasLinkTemplate('canonical')`, using `toUrl('canonical')->toString(TRUE)`. The code does not call `toUrl()` without a relationship because `EntityBase::toUrl()` falls back to `edit-form`, which must not be exposed as a link to a referenced entity. Entity types with no `canonical` link template, such as `file`, get `__url` of `null`. The `GeneratedUrl` cacheability (for example path alias dependencies) is added to the payload's cacheability alongside the entity and negotiated language.

This is direction A from the issue's options table. The picker, expression syntax and `entityFields` are unchanged, and a `__url` is generated for every referenced entity whether or not the component uses it. The agent documentation now describes `__type` and `__url`. The test component `canvas_test_code_components_news_list` uses `__url` instead of the `path␞␟alias` pick.

## Upgrade

Code components that linked to referenced entities through the alias pick can read `__url` instead and drop the pick from `dataDependencies.entityFields`:

```js
const { label, __url: url } = featuredNews ?? {};
// ...
<a href={url}>{label}</a>
```

Remove `'ℹ︎␜entity:node:news_item␝path␞␟alias'` from the prop's expressions.
