# #3592132: Allow modules to add operations to the Canvas content list

- **Project:** Drupal Canvas
- **Type:** Normal feature request
- **Status:** Fixed
- **Discussion:** [#3592132](https://git.drupalcode.org/project/canvas/-/work_items/3592132) · 1 contributor · 5 comments

## Summary

Modules can now add their own operations (for example "Translate") to each page in the Canvas pages panel and the page navigation menu. Previously the operations were a fixed set and contrib had no way to extend them. Operations only appear for users who have access to the operation's URL.

## Impact

Affects module maintainers.

- **API change:** Content API entities gain an optional `linkLabels` property (link relation type to label), documented in `openapi.yml`; responses without module operations are unchanged.
- **New API:** New `hook_canvas_content_operation(EntityInterface $entity): array`, the Canvas counterpart of `hook_entity_operation()`.

## Technical details

A module implements `hook_canvas_content_operation(EntityInterface $entity)` and returns an array keyed by a unique, module-prefixed name. Each item has `title`, `url` (a `Url` object) and an optional `weight` (default 0), the same shape as `hook_entity_operation()`. The key becomes the link relation type.

`ApiContentControllers::getEntityOperations()` now invokes the hook through the injected `ModuleHandlerInterface` (a new constructor argument). It checks `access()` on each `Url` for the current user. Accessible operations are added to the content entity's links as `CanvasResourceLink` items whose target attributes carry `label` and `weight`. Inaccessible ones only contribute cacheability, and the `languages:language_interface` cache context is added because labels are translatable.

Because the link collection is sorted by key, the response builder derives an ordered `linkLabels` map (relation type to label, sorted by weight) and emits it only when non-empty. On the frontend, the `PageList.tsx` and `Navigation.tsx` menus render these links between Canvas's own operations and "Delete page", using a new helper in `ui/src/utils/contentOperations.ts` and the `linkLabels` field in `ui/src/types/Content.ts`. Tests are a kernel test in `ApiContentControllersListTest` using a test hook in `canvas_test_page`, and a unit test for the UI helper.

## Upgrade

A module that wants to add an operation implements the new hook (example from `canvas.api.php`):

```php
function hook_canvas_content_operation(EntityInterface $entity): array {
  return [
    'my_module_translate' => [
      'title' => new TranslatableMarkup('Translate'),
      'url' => Url::fromUri('base:my-translation-ui/' . $entity->id()),
      'weight' => 50,
    ],
  ];
}
```
