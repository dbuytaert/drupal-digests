## Summary

The Canvas editor's side menu now has a "Pages" button that opens a panel listing pages. Editors can search the list, create a new page, switch to a page, duplicate it, set it as the homepage, or delete it, depending on their permissions. The homepage is shown with a home icon. The panel sits next to the Templates entry and gives pages the same kind of navigation. A follow-up commit tightened the click handling in the page and other context menus.

## Impact

No upgrade or configuration changes required.

## Technical details

The side menu gets a new `pages` button in `SideMenu`, and `PrimaryPanel` renders a new `Pages` container when `activePanel === 'pages'`. `Pages` (`components/sidePanel/Pages.tsx`) holds the data and logic: it uses `useGetContentListQuery` for `canvas_page` entities with a debounced search term, `useCreateContentMutation` for both new and duplicated pages, `useDeleteContentMutation`, and `useSetStagedConfigMutation` for "Set as homepage". The staged config uses id `canvas_set_homepage` and a `simpleConfigUpdate` action on `system.site` `page.front`. A new presentational `PageList` component (with Storybook stories) is built on `SidebarNode`. Each action only appears if the matching link is on the `ContentStub`: `edit-form`, `delete-form`, and the `link-rel-duplicate` and `link-rel-set-as-homepage` link relations. The "New" button is shown only if `canvasSettings.contentEntityCreateOperations.canvas_page.canvas_page` is set. `SidebarNode` gained a `homepage` variant with `HomeIcon`, styled like the page and template variants.

After a delete, `handleDeletePage` navigates to the homepage if one is found, otherwise to the first remaining page, otherwise out of Canvas to the base URL. It also removes the deleted page's `Canvas.collapsedLayers.canvas_page.<id>` localStorage entry. The second commit moved the `onClick={(e) => e.stopPropagation()}` into `UnifiedMenu.Content` itself, so it applies to both context and dropdown menus. It removed the per-call-site copies in the component, pattern, template, code-component, page, region and layer menus. That stops clicks in menu content bubbling to the underlying sidebar node, and the second commit's title ties it to the delete-navigation bug. The diff also changes the `#previewBackgroundUpdate` private field in `ComponentPreviewUpdateEvent` to a TypeScript `private previewBackgroundUpdate`.
