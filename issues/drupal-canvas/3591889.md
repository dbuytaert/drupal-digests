# #3591889: Canvas Editor: Component collapses and becomes un-clickable on the canvas when all media props are removed

## Summary

In the Canvas editor, if you removed every image from a component's media props through the Settings panel, the component rendered as blank on the canvas. It then had no size, so you could not click it to select it or reopen its settings. The issue is marked fixed. Its stated expected behavior is that the component returns to its default empty state, with placeholders or blank image boxes as when first added, and stays clickable.
