## Summary

Dragging a component in the Canvas editor preview now drops where the cursor is. Previously only a thin band at each component's top and bottom edge accepted drops, and a miss fell back to the drag label's rectangle, which sits 20px right of the cursor. Now every position over the previewed page shows an insertion indicator relative to the cursor. Releasing over the gray area outside the page no longer adds or moves a component. Layers panel drags are unchanged.

## Impact

No upgrade or configuration changes required.

## Technical details

`customCollisionDetectionAlgorithm` in the editor root now short-circuits for drags with origin `overlay` or `library` while the pointer is over the `[data-canvas-editor-pane="true"]` element. If the pointer is inside the `.canvas--viewport-overlay`, it calls the new `findPreviewDropZoneId()` in `previewDropTarget.ts` and returns the matching droppable as the only collision. Outside the page it returns no collisions, so a drop cancels. Other origins keep the existing `rectIntersection` or pointer-based logic.

`findPreviewDropZoneId()` reads the overlay DOM, not the drop zone rects. Starting at the root region, it descends into the child component under the pointer and then into that component's slot, until no slot is under the pointer. It stops descending when the pointer is within 12px of the component's edge, capped at a quarter of its size. That keeps it possible to drop beside a container whose slot fills it. In the chosen container it picks the nearest child and the before or after gap by the midpoint, along the stack direction. It maps the result to the existing drop zone ids (`<uuid>_top`, `_bottom`, `_left`, `_right`, or the slot or region id for an empty container), so the drop handling is untouched. It returns `null` when the drop would not move the dragged component.

To support this, the overlay components now emit data attributes: `data-canvas-drop-item` on `ComponentOverlay`, `data-canvas-drop-container` on `RegionOverlay` and `SlotOverlay`, and `data-canvas-stack-direction` on `SlotOverlay`. Unit tests cover the resolver.
