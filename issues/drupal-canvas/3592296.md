## Summary

In the `canvas_dev_ai` chat, an agent sometimes calls a tool without writing any text, so the progress message stayed unchanged and the user saw nothing happening. The progress message now gets a fallback line for each such tool call, for example "Adding Hero and Card" or "Editing Hero". Responses that include text still show only that text.

## Impact

Affects module maintainers.

- **New API:** New `Drupal\canvas_ai\Utility\ToolProgressHelper` with static helpers for building tool-call progress lines.

## Technical details

`CanvasDevAiBuilder::getAiProgress()` now reads `TextGenerated` and `ToolSelected` status items. `ToolSelected` is added to the tracked types in `setDetailedProgressTracking()`. Items belong to one model response when they share the same time and agent runner ID. A response with non-blank text contributes only that text. A response with tool calls and no non-blank text contributes one fallback line per call, built by `getToolFallbackLine()`.

Fallback lines by tool name: `place_components` gives "Adding A", "Adding A and B" or "Adding A, B and other components". `edit_components` gives the same with "Editing". `get_component_details` gives "Checking available components". Any other tool gives its configured feedback message, or `Using tool: {tool name}` when none is set. For `place_components`, the `components` YAML of each operation is parsed and walked in tree order (a component, then its slots, then the next component). Component IDs are deduplicated and cut to two, and labels come from the `Component` config entities. For `edit_components`, each `component_uuid` is resolved against the stored current layout via `getComponentsByUuid()`, and UUIDs not on the page are skipped. If the YAML does not parse, a component entity is missing, or no edited UUID is on the page, no line is added. This YAML and tree logic lives in the new `ToolProgressHelper`.

A fallback line identical to the previous fallback line is not repeated. The previous line gets a count instead, e.g. "Using tool: set_page_value (2)". A narrated response resets this. Coverage is `CanvasAiDevControllerTest::testFallbackProgress()`.
