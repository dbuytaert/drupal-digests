## Summary

Link props (SDC props with `format: uri` or `uri-reference`) can now link to Canvas pages as well as nodes. Previously the autocomplete only matched nodes, and any selection was stored as `entity:node/<id>`, so picking a Canvas page could silently link to an unrelated node with the same ID. The link autocomplete now returns both nodes and Canvas pages in one list, each row showing the entity's type, and the path on hover.

## Impact

Affects module maintainers.

- **New API:** New `canvas.api.ui.link_autocomplete` route (`/canvas/api/v0/ui/link-autocomplete`) served by `ApiLinkAutocompleteController`, returning `{value, label}` with the entity type encoded in `value`.

## Technical details

Core's `LinkWidget` hardcodes `#target_type` to `node` (core [#2423093](https://www.drupal.org/node/2423093)), and the issue rejected making it configurable to a single alternative, so Canvas now handles multi-type matching itself.

A new `ApiLinkAutocompleteController` queries the `default` selection handler for each of `node` and `canvas_page` (exact, `STARTS_WITH`, then `CONTAINS`, to avoid weaker matches crowding out better ones), drops entities the user cannot `view`, ranks results across types (exact, prefix, word prefix, contains, then label), and caps at 10. Each suggestion's `value` is `Label (entity_type_id/entity_id)` via `encodeValue()` (using `Tags::encode()`, so labels with commas get quoted). The `label` is markup with a label, path and type pill, styled in `css/autocomplete.extend.css`.

In `ReduxIntegratedFieldWidgetsHooks::fieldWidgetSingleElementLinkDefaultWidgetFormAlter()`, when the form is a Canvas static prop source, a `processLinkAutocompleteRoute` process callback is inserted after `EntityAutocomplete::processEntityAutocomplete()` to point the element at the new route. Stored `entity:` URIs are also converted to the same `Label (type/id)` format for the default value. Other link fields keep core's autocomplete.

On the client, `resolveEntityUri()` in `ui/src/utils/transforms.ts` now produces `entity:<type>/<id>` when the selection has the `type/id` form, and falls back to `entity:node/<id>` for core-style `Label (id)` input typed manually. `ENTITY_AUTOCOMPLETE_MATCH` accepts a trailing quote. `TextFieldAutocomplete.tsx` now clears the previous keystroke's timeout so a stale store update does not close the suggestion list.
