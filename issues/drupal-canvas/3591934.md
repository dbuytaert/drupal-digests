# #3591934: Add component label to settings form

- **Project:** Drupal Canvas

## Summary

In Drupal Canvas's editing UI, the settings panel used to edit a selected component's props did not show which component it belonged to. If the selection changed unexpectedly, such as when the canvas scrolled or the UI lagged after a quick action, it was easy to lose track of what you were actually editing. The settings form now displays the component's name in bold at the top of the panel, so it is always clear which component's settings are being edited.

## Impact

No upgrade or configuration changes required.

## Technical details

The fix is in `ComponentInstanceFormRenderer` (`ui/src/components/ComponentInstanceForm.tsx`). It derives `selectedComponentName` from `components?.[selectedComponentType]?.name` and, when non-empty, renders it in a bold `Text` inside a `Box` immediately above the `TransformsContext.Provider` that wraps the generated JSX props form. A corresponding Cypress test asserts that the element with `data-testid="selected-component-name"` shows the expected label (e.g. `'All props'`) when that test component's form is open.
