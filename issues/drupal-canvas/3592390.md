## Summary

Canvas OAuth now ships a recipe, `cli_setup`, that does most of the Canvas CLI OAuth setup for you. It installs `canvas_oauth` and `media`, creates a "Canvas CLI" user and a `cli` OAuth consumer with all Canvas scopes, and creates the media scopes for existing media types. The README now lists this as the recommended route, with the previous manual steps kept as an alternative.

## Impact

Affects module maintainers.

- **New API:** New `createOAuthScope` config action (plugin `CreateOAuthScope`) for `media_type` config entities; `MediaScopesHelper::ensureMediaScopes()` now accepts an optional list of media type IDs.

## Technical details

The recipe lives in `modules/canvas_oauth/recipes/cli_setup`. It imports `canvas_oauth` config and ships two default content entities with hard-coded UUIDs: a user (`72810686-42f1-43cf-80fa-8a35a7cb5a08`) and a consumer (`9a1724a1-6a79-4819-87e3-871542db531b`) that depends on that user. The consumer uses the `client_credentials` grant, is confidential, and lists the 13 Canvas scopes (page, media, brand kit, JS component and so on). Applying the recipe again should not duplicate them, because the UUIDs are fixed. Both are content entities, so they have to be shipped as recipe content rather than config.

Media scopes depend on which media types exist, so they cannot be listed statically. The recipe instead runs a new `createOAuthScope` config action against `media.type.*`. The action is implemented by `Drupal\canvas_oauth\Plugin\ConfigAction\CreateOAuthScope`, which calls `MediaScopesHelper::ensureMediaScopes()`. That method gained an optional `?array $media_types` parameter, so the action can create scopes for one media type at a time. With `NULL` it still processes all media types. `CliSetupRecipeTest` checks that image and document types get scopes, that a media type with a non-file source (`test`) does not, and that the consumer ends up with every `canvas_` scope.

## Upgrade

Apply the recipe from the command line:
```shell
dr recipe modules/contrib/canvas/modules/canvas_oauth/recipes/cli_setup
```
