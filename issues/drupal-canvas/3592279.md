## Summary

When the Canvas editor opens a page, it now reliably scrolls so the top of the preview, including the site header, is visible with a small gap above it. Before, some pages opened scrolled too far down, hiding the header, and short pages could open at the bottom.

## Impact

No upgrade or configuration changes required.

## Technical details

The initial scroll position in `EditorFrame.tsx` was computed as `(pane.scrollHeight - previewHeight) / 2 - 50`. That assumes `scrollHeight` equals the frame padding plus the preview height. While the preview loads, content can briefly overflow the frame, so `scrollHeight` is inflated. In the issue's example at 1440×900, `scrollHeight` was 3026 px at computation time against 2409 px after load, so the editor scrolled to 979 px instead of 670 px.

The fix measures the preview's actual offset in the pane: `scalingContainerRef` top minus `editorPaneRef` top plus `editorPaneRef.current.scrollTop`. It then subtracts the 50 px gap. The horizontal position still comes from `getHalfwayScrollPosition`.
