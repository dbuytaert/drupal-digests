# #3594801: Show the workflow run on the results page, and small dashboard fixes

- **Project:** Drupal AI
- **Type:** Normal feature request

## Summary

The AI Eval results page now shows a collapsed "Workflow run" panel for each question that has a stored workflow record. It gives a summary (engine, workflow, status, time, model calls, tokens), one line per model call with the requested model and, when recorded and different, the model that answered, and the steps as a tree with status, time, error and collapsed input and output previews. This lets you see why an answer scored low without reading the database. Smaller fixes: the retrieval response header no longer shows the index as `index%20content_vector`, a running test no longer makes the targets dashboard scroll sideways, opening a Run URL directly redirects to the target's workflow page instead of returning a 405 error, and a target that never ran shows "No runs yet" once per dashboard row instead of five times.

## Impact

No upgrade or configuration changes required.

## Technical details

Based on the issue description only, since no diff was available. The panel uses Drupal's `details` element so the admin theme styles it. A direct Run URL redirects to the target's workflow page without starting a run, and it requires the same permission as running a test. The "No runs yet" duplication was in the dashboard row built in `EvalTargetListBuilder`. The issue's "Proposed resolution" is the source for these details, and the merged code was not read.
