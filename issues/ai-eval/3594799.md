# #3594799: Grade taxonomy automators with auto-create without saving terms

- **Project:** Drupal AI

## Summary

The AI Eval field automator target ([#3594787](https://www.drupal.org/node/3594787)) used to refuse taxonomy rules whose field has auto-create on, because running them saves a new term for every label that has no match. That left tagging automators on such sites untested. They can now be graded. The run captures the labels the rule would store and grades those, without saving any terms. It also records which labels match existing terms and which would be new.

## Impact

No upgrade or configuration changes required.

## Technical details

The rule runs as usual. The labels it produced are taken just before storage, and the rule is stopped from storing them, so no term is saved. The labels the field would have received are graded, with each one recorded as matching an existing term or as a would-be new term. A separate guard blocks term saves for the whole run. The run fails rather than storing anything when the labels cannot be taken safely. This is a child of [#3594785](https://www.drupal.org/node/3594785).
