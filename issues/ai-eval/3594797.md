## Summary

ai_eval gets a new submodule for evaluating stored prompts from drupal/ai 1.2. Editing a stored prompt changes output wherever it is used, for example in the CKEditor AI tools. With this runner you can test a prompt against a dataset before a change goes live. The model is chosen on the eval target. Replies are graded like any other response, and the run records which prompt version was used. Prompts that need values ai_eval cannot supply are refused.
