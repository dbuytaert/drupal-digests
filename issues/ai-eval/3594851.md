## Summary

In AI Eval, the guided test form and the classic test target form now say so when the AI module lists no chat models. Before, both showed a bare "Provider / Model" text box. The format only appeared in an error after submit. Now a warning says no chat models are available and that one possible cause is a missing provider or key. Users with the `administer ai providers` permission get a link to the AI provider settings. Other users are told to ask an administrator. The text field stays as a fallback, with a description that says to type `provider__model`, for example `openai__gpt-4o-mini`. When models are listed, the select and its description are unchanged. The same commit also bundles several unrelated fixes, such as singular and plural wording, named row buttons, and Enter no longer saving a rubric.

## Impact

Affects module maintainers.

- **New API:** `ProviderModelOptionsTrait` gains `noChatModelsNotice()` and `manualModelDescription()`, now also used by `GuidedTestForm` and `EvalTargetForm`.

## Technical details

`GuidedTestForm` and `EvalTargetForm` now use `ProviderModelOptionsTrait::providerModelOptions()` in place of their own try/catch blocks. Because of this, the guided form now reports a load failure as a warning with the exception message and a log entry, as the classic form already did. The trait tracks `providerModelLoadFailed`. `noChatModelsNotice()` returns a render element that is hidden (`#access`) when the failure message was already shown, so the user does not see two warnings. It checks `administer ai providers` to decide whether to render a `Link` to `ai.admin_providers`. It adds the `user.permissions` cache context. `manualModelDescription()` supplies the text field description. The classic form keeps its original select description only when options exist. The `provider__model` validation after submit is unchanged.

New tests are `NoChatModelsTest`, which covers the link with and without the permission and the format error on submit, and `ChatModelsAvailableTest`, which uses the `ai_test` provider to check that the select and old description are kept.
