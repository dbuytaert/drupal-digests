# #3594775: Workflow error-analysis counts are site-wide on a per-test page

- **Project:** Drupal AI
- **Type:** Normal bug report
- **Status:** Fixed
- **Discussion:** [#3594775](https://git.drupalcode.org/project/ai_eval/-/work_items/3594775) · 1 contributor · 2 comments

## Summary

On a test's Workflow page (tab B, error analysis), the counts no longer mix in data from the rest of the site. "Group into failure modes" now counts only failure modes used by annotations on this test's results, so a mode defined on the site but unused by this test no longer marks the step done. Conversations reviewed on imported traces have no link to a test, so they are now labelled "reviewed on this site" and are no longer added to this test's annotation progress. Badges use proper singular and plural forms ("1 failure mode used", "1 case") instead of "1 modes".

## Impact

No upgrade or configuration changes required.

## Technical details

In `WorkflowStateService::stepsB()`, the labeled count is now `annotationCount($target)` alone; the old sum of annotations plus `reviewedConversationCount()` is gone. The site-wide `failureModeCount()` was replaced by a new private `failureModesUsed(EvalTarget $target)`. It joins `ai_eval_annotation` to `ai_eval_result` on `result_id`, filters by `r.target_id`, and counts distinct non-empty `a.failure_mode` values. That count drives the grouping and failure-rate steps.

The issue offered two options: count per test, or label the count as site-wide. The fix does both, depending on the data. `reviewedConversationCount()` and `hasImportedTraces()` are unchanged and still site-wide, because imported traces carry no test link. Their badge and description now say so ("N reviewed on this site"). The Annotate step description names the reviewed conversations without counting them, and uses `formatPlural` for the singular and plural forms. The fix landed as part of the larger Sprint 7 commit "workflow and forms" (dcbcdf0) and is noted in `CHANGELOG.md` under [#3594775](https://www.drupal.org/node/3594775).
