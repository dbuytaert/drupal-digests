## Summary

AI Eval gets a new submodule, `ai_eval_ai_answers`, for evaluating answers through AI Answers. AI Answers wraps an agent for visitors. It forces a search, renders references, and returns a no-answer message when no sources are found. Agent-mode evaluation tests only the inner agent, so its scores can differ from what visitors see. The new runner grades the answer text the visitor reads. Sources can optionally be appended to the graded response, either as a list or with card excerpts for groundedness checks. Streaming and multi-turn conversations are out of scope.

## Impact

Affects module maintainers.

- **New API:** New submodule `ai_eval_ai_answers` with a workflow runner over the AI Answers service.

## Technical details

This is based on the issue description only. The merged code was not in the cloned `main` branch, so I could not check it against a diff. The issue describes a workflow runner over the AI Answers service. It makes single-question, non-streaming calls as the question's caller. It records the tool calls the top-level agent chose. It records the forced search as a separate step, marked complete only when references arrive before the agent's first tool call. It marks the no-answer case. By default it deletes the conversation record. The issue is a child of [#3594785](https://www.drupal.org/node/3594785).
