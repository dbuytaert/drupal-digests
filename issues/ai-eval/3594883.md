## Summary

The question editor in AI Eval now has a **Follows question** select. It lists the other questions in the dataset, so you can make a question the next turn of an earlier question's conversation without editing YAML. Saving refuses a choice the run would skip: the question itself, a question that isn't in the dataset, a later question, or a question that another question already follows. The question list shows "follows q1" next to a follow-up. The results page shows "Follows q1, turn 2" under the question ID.

## Impact

No upgrade or configuration changes required.

## Technical details

The field reads and writes the existing `metadata.follow_up_of` key from [#3594881](https://www.drupal.org/node/3594881). `DatasetQuestionEditor` gives it its own `follow_up_of` value. `valuesFromStored()` removes the key from the generic metadata rows, and `assemble()` rewrites it only from the field, so an empty field clears it and other metadata is kept. `isEditable()` returns FALSE when a stored `follow_up_of` is not a string, so saving cannot silently drop it. The select options come from the new `ReferenceOptions::datasetQuestionIds()`, ordered by `weight` then `qid`. The select leaves out the question being edited and keeps a stored value whose question no longer exists.

Validation runs on save in a new private `followUpError()` method in the question controller. It applies the rules the runner uses: no self-reference, the target must exist, the target must be earlier in the list (a new question counts as last), and no other question may already follow the same target. A chain, where the third question follows the second, is allowed. The select is only rendered when the dataset has other questions.

The list row in `DatasetQuestionList` shows the "follows @id" caption. `EvalResultsController` renders the question ID cell with a caption, "Follows @id, turn @turn". When the stored row has no `turn`, as with a skipped follow-up, it shows "Follows @id" only. New kernel tests cover the controller save and refusal paths and the result caption. New unit tests cover the editor round-trip.
