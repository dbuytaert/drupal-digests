# #3594788: Validate a judge only on answers it scored

- **Project:** Drupal AI
- **Type:** Normal bug report
- **Status:** Fixed
- **Discussion:** [#3594788](https://git.drupalcode.org/project/ai_eval/-/work_items/3594788) · 1 contributor · 2 comments

## Summary

Validating a judge that has no dimension (decision rubric, content review) in the browser used to read every pass or fail given on any results page, whatever the judge. A review now counts for a judge only when that judge scored that answer in that result: a score was recorded without an error, and a zero counts. Reviews from another test, or on answers the judge failed to score, are left out. The validation report and the calibration page now say that reviews are whole-answer verdicts while a judge may check only some rules. Per-judge verdicts are a follow-up ([#3594789](https://www.drupal.org/node/3594789)).

## Impact

Affects module maintainers.

- **API change:** `HumanLabelSourceInterface` gains `unattributedAnnotationCount()`; any class implementing the interface must add it.
- **New API:** `HumanLabelSourceInterface::unattributedAnnotationCount()` returns how many results-page reviews cannot be attributed to any judge.

## Technical details

`HumanLabelSource::forGrader()` previously ignored `$graderId`. It now passes it to `fromAnnotations()`, which calls `hydrateFromResult()` and keeps an annotation only if the grader id appears among the entries in that question's `grader_scores` in the stored `ai_eval_result.scores_json` with a numeric `score` and no `error`. Errored entries and entries with a NULL score (not applicable) do not count. Annotations are still merged only on the holistic path, when both `$domainTags` and `$dimension` are NULL. Review labels from `ai_eval_review_label` (dimension-scoped) are unchanged.

A result stored without `grader_scores` cannot say which judges scored it, so its annotations count for no judge. The new `unattributedAnnotationCount()` counts those, one per (result, question), and the validation page shows the number for judges without a dimension. The docs entry JUDGE-L13 in `docs/semantic/tech/JUDGE_01_JudgeValidation.md` was updated to match.

## Upgrade

Reviews on results stored before AI Eval recorded which judges scored each answer no longer count for any judge's validation. They are kept, not deleted, and the judge's validation page says how many were left out. Run the test again and review the new results.

Custom classes implementing `HumanLabelSourceInterface` must add:

```php
public function unattributedAnnotationCount(): int;
```
