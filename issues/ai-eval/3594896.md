## Summary

The AI Eval admin pages, menus, Drush output and user docs now use one name for each concept. What was shown as an eval target is now a test, dataset examples and cases are questions, a saved fit or curve is a calibration, callers are decision automators, the model a test runs is the model under test, and the envelope import is EEE results. Route titles move to sentence case without the 'Eval' prefix (for example Results, Run detail, Compare runs, Prompt optimization). The Label traces tab is now Gold labeling, Compare two judges is Judge against judge, and Promote is shown as Add to dataset. The glossary notes the older names so people with old screenshots can still find them.
