## Summary

AI Eval's admin screens and Drush output now use correct singular wording when a count is 1 (for example "1 test: Name", "1 labeled answer", "1 question", "1 pair"). Entity types and bundles show their labels (for example "Content / Article") in place of machine names like `node`, and the trace review notices say "AI Observability" and note that the 1024 character limit applies "unless the site changed it". The same commit also shipped several related form fixes. Pressing Enter in a rubric text field no longer saves the rubric. Rubric phrases are added with an "Add phrase" button. Question row buttons have accessible names that include the question id. The gate threshold follows the selected metric. A new note explains the manual provider__model entry when no chat models are listed. The "stopped at N answers" notice no longer shows when recording went past the limit.

## Impact

Affects module maintainers.

- **New API:** New `Drupal\ai_eval\Render\EntityLabels` helper (`type()`, `bundle()`), new `GateMetric::browserSettings()`, and new route `ai_eval.rubric.phrase_row`.

## Technical details

Plurals use `formatPlural()` or `PluralTranslatableMarkup` in `EvalDatasetListBuilder`, `JudgeTrustReason`, `ConfusionMatrix`, `JudgeComparisonView`, `LengthCheck`, `StabilityCheck`, `TelemetryText`, `PowerAdvisory`, `ResolutionCheck`, `ResultSummaryBand`, `CalibrationSaveTrait` and `JudgeComparisonForm`. Drush and report strings built with `sprintf` (`EvalRunCommand`, `EvalImportEnvelopeCommand`, `EvalValidateJudgeCommand`, `JudgeValidationReport`, `TraceImporter`) choose the singular format inline with a ternary.

A new `Render\EntityLabels` helper resolves the entity type label and bundle label through `EntityTypeManagerInterface`. It falls back to the stored id when the definition no longer exists. It is used in `DecisionAutomatorOptionsTrait`, `RecordedAnswerTrait` and `AiAutomatorsWorkflowRunner::listWorkflows()`. In `DecisionReviewForm`, the "stopped at" paragraph is now rendered only when `$recorded === $limit`.

Other changes in the same commit: `js/gate-threshold.js` is attached through the `admin` library. It uses `drupalSettings.aiEval.gateMetrics` from the new `GateMetric::browserSettings()`. When the metric changes, it resets the threshold if the field is empty, equals the previous metric's default, or exceeds the new metric's maximum. For rubrics, a capture-phase keydown handler stops Enter from submitting. In a phrase input, Enter clicks the new "Add phrase" button and focuses the added input. The button fetches a blank input from the new `RubricController::phraseRow()` route `ai_eval.rubric.phrase_row`. In `DatasetQuestionList`, the move, edit, delete, enable and disable buttons get `aria-label` and `title` values containing the question id. `ProviderModelOptionsTrait` gains `noChatModelsNotice()` and `manualModelDescription()`, now used by both `EvalTargetForm` and `GuidedTestForm`. The notice links to `ai.admin_providers` only for users with `administer ai providers`.

The 1024 character wording is changed in `TraceReviewFragment` and `docs/user/usage/traces.md`. The text still says 1024 and does not read the real configured limit.
