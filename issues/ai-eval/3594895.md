## Summary

Five display problems on the decision calibration admin pages are fixed. The Reviewed decisions table no longer shows a raw machine id when the calibration that corrected an answer has since been replaced, and the table scrolls inside the page instead of cutting off the Reviewed column. The Callers tab intro now matches the carry-over behavior for newer model versions. The breadcrumb on a group's review page no longer repeats "Review decisions", and the "answers" suffix on the Record decisions Stop after field stays on one line. The "Brier score" wording in the UI and docs is replaced with "overall error".

## Impact

No upgrade or configuration changes required.

## Technical details

`ReviewedDecisionsController` now shows "(a calibration that no longer exists)" when the `ai_eval_calibration` entity for the stored `calibration_id` fails to load, instead of falling back to the id. The `answers` table is wrapped in a `div.ai-eval-table-scroll` (`overflow-x: auto` in the admin CSS) rather than dropping the Field column.

The `ai_eval_decision_calibration.review_group` route now uses `_title_callback` pointing to the new `DecisionReviewForm::title()`. It returns the automator label when the group tag starts with `ai_automator:id:` and the automator loads, otherwise the tag itself, or "Review decisions" when the group is unknown. This differs from the issue's proposal to rename the reviewed route: the group review page is titled after its caller, so the breadcrumb no longer repeats the list title.

`RecordSettingsForm` attaches the `ai_eval/admin` library and gives the stop-after number field `#size` 6 and a `ai-eval-inline-suffix` wrapper class, styled as a nowrap flex row. `CallersForm` intro text now says provider and question wording must match, and that answers from a newer model version also use the calibration while the automator asks for the same model. Brier score references in `CallersForm` and the docs are reworded to "overall error". `DecisionReviewFormTest` is updated to expect the new text.
