## Summary

Six small admin text and display fixes in AI Eval. The results list column that counted runs passing the gate is now called "Gate pass rate" (with a toggletip), so it is no longer confused with "Pass rate" elsewhere, which counts measured questions. Grader checkboxes on the test forms show a plain scale such as "(0-1)" instead of "binary, 0-1", since scales like Recall at k are not binary. Answers on the result detail page are now rendered as Markdown. Issue numbers and a drupal/ai MR reference no longer appear in dashboard tooltips or in the decision rubric error. The `drush ai-eval:run` margin hint points to the real settings page. A workflow test shows "Edit test" instead of a guided editor link that led nowhere.

## Impact

Affects front-end developers.

- **Theme change:** Result detail now attaches `ai_eval/markdown` and renders the answer cell as Markdown-derived markup.

## Technical details

The results list header in `EvalResultsController` uses `Toggletip::term('gate-pass-rate', ...)`, backed by a new "Gate pass rate" glossary entry. The two duplicated `graderCheckboxLabel()` methods in `EvalTargetForm` and `GuidedTestForm` are replaced by one `GraderCheckboxLabel::build()` in `src/Render/GraderCheckboxLabel.php`, which formats `@label (@min-@max)`. The docs example in the grader guide changed to "Read-only run (0-1)".

Result detail wraps the response in `Markup::create(TraceReviewFragment::markdownMarkup($rawResponse))` and attaches `ai_eval/markdown`, the same path trace review uses. Only the helper's already-escaped output is marked safe, to avoid double escaping.

`EvalRunCommand` builds the settings path with `Url::fromRoute('ai_eval.settings')->toString()`. `TargetDashboardController` checks `EvalTarget::MODE_WORKFLOW` and links to `$ai_eval_target->toUrl('edit-form')` with the label "Edit test", otherwise keeps the guided link. The `DecisionRubricGrader` error text is now "this AI module has no Decision operation; update the AI module to a version that has it", and the `(#3594721)` and `(#3594716)` references are removed from the `EvalTargetListBuilder` tooltips.
