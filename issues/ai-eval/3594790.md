# #3594790: Show how many questions were measured next to the pass rate

- **Project:** Drupal AI

## Summary

When some questions error out or can't be scored, the pass rate is calculated only over the questions that were measured. The drush run summary and the result detail page now say so next to the pass rate, for example "9 of 12 measured", so a "100%" is no longer easy to read as 100% of all 12 questions. The text appears only when fewer than all questions were measured.

## Impact

No upgrade or configuration changes required.

## Technical details

In `EvalRunCommand`, the target result line now carries the count inside the parentheses after the pass rate, such as `(pass_rate: 100% [70.1%–100%], 9 of 12 measured: 3 errors) [PASS] 34s`. The reasons for missing questions (`N errors`, `N unscored`) are listed after the count. This replaces the old trailing `(3 errors)` / `(3 unscored)` suffix after the duration. The measured count uses `valid_count` from the result, falling back to total questions minus errors minus unscored. The same value is reused by the existing insufficient-coverage warning.

In `EvalResultsController`, the pass-rate cell on the result detail page computes `$measuredCount` once (`question_count - error_count - unscored`) and uses it for the existing `(passed / total)` figure. It appends `, N of M measured` when `$measuredCount` is below `question_count`.
