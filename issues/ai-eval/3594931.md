## Summary

Validating a judge that has a dimension, such as `fact_match_grader`, from the admin UI previously found no usable examples, so the judge skipped every item and could never become trusted. Whole-answer annotations now count for such a judge when it was the only judge that attempted the annotated answer. Matching trace review labels still take precedence over annotations.

## Impact

No upgrade or configuration changes required.

## Technical details

`HumanLabelSource::forGrader()` previously merged annotation examples only when both `$domainTags` and `$dimension` were NULL. It now merges them whenever `$domainTags` is NULL. When a dimension is set, `fromAnnotations()` is called in sole-judge mode and keeps an annotated answer only if `attempted_graders` (graders that scored or errored) has exactly one entry. Results stored without `grader_scores` stay excluded as before. Domain-tagged validations still get no annotations, since annotations carry no trace tags.

The two sources are de-duplicated by a new private `answerKey()`, a `CanonicalHasher` hash of input and response. A bare single user message and its `user: `-prefixed trace form hash the same, while multi-turn transcripts keep their roles. Trace review examples are collected first, and an annotation on the same answer is skipped, so validation counts the answer once. Annotation examples fill only the remaining `$limit`.

`JudgeValidateController` no longer hides the unattributed annotation hint for dimension judges, and shows the whole-answer notice when the run's recorded examples (`runner->scoredExamples($run)`) include result-based ones.

The same commit also ships [#3594929](https://www.drupal.org/node/3594929) (file or config datasets with `caller_uid` now error in `EvalRunner::runQuestionBody()` unless the run starter has `run ai eval as another user`) and [#3594886](https://www.drupal.org/node/3594886) (with `refuse_unvalidated_judges` on, `applyJudgeTrustPolicy()` rescoring without untrusted judges; the pass stands only if the recalculated gate passes and at least half of the original questions remain measured, otherwise `trust_refused` is set, and a standing pass records `trust_note`).
