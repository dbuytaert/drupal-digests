# #3594769: Pass-rate wording: a range "above and below" 0% or 100%, and a last-run card that mixes scopes

- **Project:** Drupal AI
- **Type:** Normal bug report
- **Status:** Fixed
- **Discussion:** [#3594769](https://git.drupalcode.org/project/ai_eval/-/work_items/3594769) · 1 contributor · 2 comments

## Summary

The AI Eval small-sample advisory no longer says a pass rate's range "extends about X% above and below" the reported rate. That wording was wrong at 0% and 100% (it implied values past the edges) and for the Wilson interval, which is not symmetric. It now states the actual bounds, for example a range between 0% and 39%. The Results list card previously labelled "Last Eval Run" mixed two scopes. It is now labelled "Latest result per test", and the passing, test, question and duration figures all come from the same rows.

## Impact

No upgrade or configuration changes required.

## Technical details

The change landed inside the combined Sprint 7 commit `dcbcdf0` in the ai_eval repository. It was not a separate commit for this issue.

In `src/Render/PowerAdvisory.php` the `@half` argument is dropped. When per-question counts are available, the advisory calls `wilsonInterval()` on the sample size service at the configured confidence. Otherwise it uses the stored `$ciLow` and `$ciHigh`. The bounds are shown in whole percents, or with up to three decimals when needed so the displayed range is wider than the displayed margin of error. Counted verdicts produce "At N% confidence the true rate is likely between X and Y…". Without counts the text says "The run reports a likely range of X to Y…", since those bounds come from the producer. `@confidence` now reports `supportedConfidence()`, the level the arithmetic actually used.

In `EvalResultsController`, the question and duration totals are now summed over `$targetHealth`, the latest result per test. This is the same set that feeds the passing and test counts. The old loop summed any rows within 300 seconds of the newest result. The latest-results query adds `orderBy('id', 'ASC')` so that two results from the same second resolve to the newest row. The card label becomes "Latest result per test", and the counts use `formatPlural()` ("N tests", "N questions"). The stored pass-rate range in the results table also gets a tooltip saying it is stored at 95% confidence on this site. A functional test, `ResultsLastRunCardTest`, covers the card.
