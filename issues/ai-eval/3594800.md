# #3594800: Admin forms drop stored settings on save

- **Project:** Drupal AI
- **Type:** Normal bug report
- **Status:** Fixed

## Summary

Saving several AI Eval admin forms no longer wipes settings that were defined in config or YAML but not shown on the form. Workflow targets keep their mode, engine, workflow, question port and fixed inputs. Rubrics keep `scoring.weights`, other scoring and top-level settings, and `case_sensitive` on checks. Selects keep a saved model or agent that is no longer listed. Copying a dataset with a `splits` rule now warns when the rule cannot be kept. The question editor and settings form also gain fields that previously had no UI, and a target's Run history now includes runs started from Drush. Run the database updates after upgrading.

## Impact

Affects site owners.

- **Database update:** Update 10049 adds the `judge_trust_stale_days` default where it is missing.
- **Config change:** The settings form gains `judge_trust_stale_days`, `gold_target_n` and `export_envelope_on_complete`, previously config only.
