## Summary

The `ai_best_practices` project has a new skill, `drupal-ckeditor5-plugins`, for AI coding agents that customize CKEditor 5 in Drupal. It targets three recurring agent mistakes: reading the `latest` CKEditor docs instead of the version bundled in the site's core, shipping raw ES modules where Drupal 10.3 to 11 needs a webpack DLL bundle, and mixing the DLL method with the new-builds (UMD) method used from Drupal 12 and CKEditor 5 v48. It also tells agents to look for an existing plugin in core, the CKEditor 5 Plugin Pack or Premium Features before writing a custom one. The Drupal 12 guidance is flagged as beta.

## Impact

Affects module maintainers.

- **New API:** New `drupal-ckeditor5-plugins` skill under `skills/` with five reference files and an eval set under `evals/drupal-ckeditor5-plugins/`.

## Technical details

`SKILL.md` makes the version check a required Step 0. The agent reads the `version:` under `ckeditor5:` in `core/core.libraries.yml` and uses it to pin all CKEditor docs lookups. It then routes to reference files through a task table. Detailed content sits in `references/`: `version-matrix.md`, `custom-plugins-dll.md`, `drupal-12-outlook.md`, `plugin-pack-premium-features.md` and `agent-docs.md`. This follows the progressive-disclosure pattern of the `drupal-gitlab` skill.

`version-matrix.md` deliberately gives a derivation procedure instead of a static table. The bundled CKEditor version can change between patch releases of one core minor, and it may carry a `-drupal.A` fork suffix. The docs URL is derived by truncating to `<major>.<minor>.0`, because exact-patch URLs return 404.

`SKILL.md` also lists cross-cutting rules. Check for existing plugins even when the user explicitly asks for a custom one. Bundling is mandatory on Drupal 10 and 11. The DLL and new-builds methods are mutually exclusive per Drupal major. The plugin key chain across `<module>.ckeditor5.yml`, the webpack `library: ['CKEditor5', '<namespace>']` output and `<module>.libraries.yml` must match exactly. Plugin source must import only from `ckeditor5/src/*`.

The issue states that evals are added under `evals/drupal-ckeditor5-plugins/`, with static checks plus five behavioral cases. The directory contains `static-checks.json`, `dataset.yaml`, `rubrics.yaml` and `README.md`. The issue says a refresh of `references/drupal-12-outlook.md` is a follow-up once the 2.x Plugin Pack and Premium Features modules ship their 2.0.0-beta.
