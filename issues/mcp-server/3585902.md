## Summary

The MCP Server module (2.x) now declares compatibility with Drupal 12. The minimum supported core moves from 10.0 to 10.1. The README requirements and the Composer dev dependency on Coder are updated to match. The change came from the Project Update Bot's automated Drupal 12 issue.

## Impact

Affects site owners.

- **Requirements:** `core_version_requirement` changed from `^10 || ^11` to `^10.1 || ^11 || ^12`, so Drupal 10.0 is no longer supported and Drupal 12 is.

## Technical details

The change is mostly metadata. `mcp_server.info.yml` and the two test modules' info files (instructions test and test fixtures) now use `core_version_requirement: ^10.1 || ^11 || ^12`. `composer.json` allows `drupal/coder` as `^8 || ^9` in `require-dev`. The README requirements line is updated.

Two tests were adjusted for newer core and Drush APIs. `McpServerFunctionalTest` no longer calls `user_role_grant_permissions()`. It loads the anonymous `Role` and uses `$this->grantPermissions()`. `McpServerCommandsTest` no longer builds a `DrushStyle` and calling `restoreState()`. It calls `setInput()` and `setOutput()` on the command instead. No runtime module code changed in this diff.
