# #3585924: Drop mcp/sdk ^0.6 and require 0.7.1

## Summary

The mcp_server module's dependency on the `mcp/sdk` package is tightened to require version 0.7.1 or newer. The previous constraint still allowed `^0.6` and `0.7.0`, both of which are covered by security advisory CVE-2026-53965. Sites that run `composer update` will now be prevented from installing (or keeping) a vulnerable `mcp/sdk` release, and sites that had disabled Composer's advisory check were previously left exposed. There is no code change in the module itself.

## Impact

Affects site owners.

- **Security:** The `mcp/sdk` composer constraint now requires `^0.7.1 || ^0.8`, excluding the `^0.6` line and the `0.7.0` release, both covered by CVE-2026-53965.

## Technical details

A prior fix ([#3585916](https://www.drupal.org/node/3585916)) had temporarily widened the constraint to `^0.6 || ^0.7` to unblock fresh installs from Composer's advisory blocking, but `0.6.0` (the only 0.6 release) and `0.7.0` are both within the Packagist advisory range `>=0.5.0,<0.7.1`. This issue removes `^0.6` entirely and raises the 0.7 floor to `0.7.1`, the first release outside the advisory range. The change is a one-line edit to the `require.mcp/sdk` constraint in `composer.json`; the module has no 0.6-specific code paths, so no PHP code was touched.

## Upgrade

Run `composer update drupal/mcp_server mcp/sdk` to pick up the new constraint. Confirm the installed `mcp/sdk` version satisfies:
```
"mcp/sdk": "^0.7.1 || ^0.8"
```
If your project's lock file still resolves to `0.6.0` or `0.7.0`, update it to clear CVE-2026-53965.
