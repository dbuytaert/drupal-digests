## Summary

The MCP Server module can now send a short block of "instructions" text to every connecting AI client (claude.ai, Claude Code, IDE plugins) as part of the MCP protocol's initialize handshake. Previously the module never populated this field, so clients had no server-level hint about when or how to use the site's exposed tools and resources, only the per-tool descriptions. Site builders can now set this guidance via a new `server_instructions` configuration value, and other modules can adjust or generate it dynamically.

## Impact

Affects module maintainers and site owners.

- **Config change:** New `server_instructions` key in `mcp_server.settings`, empty by default, surfaced to MCP clients in the initialize handshake when non-empty.
- **New API:** New `hook_mcp_server_instructions_alter()` lets modules set or refine the MCP handshake instructions programmatically.

## Technical details

`McpServerFactory::build()` now calls a new private `buildInstructions()` helper before constructing the SDK's `Server::builder()`, and passes the result to `setInstructions()`. The helper reads `server_instructions` from `mcp_server.settings` (added to `config/schema/mcp_server.schema.yml` and defaulted to an empty string in `config/install/mcp_server.settings.yml`), then invokes the new `hook_mcp_server_instructions_alter()` (declared in `mcp_server.api.php`) via the injected `ModuleHandlerInterface`, letting other modules override or seed the value, for example to point agents at a companion module's tools. A `NULL` or empty/whitespace-only result after the hook runs causes the `instructions` field to be omitted from `InitializeResult` entirely, matching prior behavior when nothing is configured. The module handler was added as a new constructor dependency on `McpServerFactory`, wired in `mcp_server.services.yml`. No admin UI textarea was added for this setting; it's configuration-only for now.

## Upgrade

Set the instructions directly in config, or implement the alter hook for dynamic values:

```yaml
# config/install/mysite.settings.yml or via config import
server_instructions: 'Consult the MCP server before writing code.'
```

```php
/**
 * Implements hook_mcp_server_instructions_alter().
 */
function mymodule_mcp_server_instructions_alter(?string &$instructions): void {
  if ($instructions === NULL || $instructions === '') {
    $instructions = 'Introspect this Drupal site before writing code.';
  }
}
```
