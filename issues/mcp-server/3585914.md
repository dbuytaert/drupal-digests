# #3585914: Plugin subdirectory collides with Tool API on case-insensitive filesystems

- **Project:** Drupal AI
- **Type:** Normal unknown (0)
- **Status:** Fixed
- **Discussion:** [#3585914](https://git.drupalcode.org/project/mcp_server/-/work_items/3585914) · 1 contributor · 14 comments

## Summary

MCP Server previously discovered its Tool plugins under a `src/Plugin/Tool/` directory. That path collides with the separate Tool API module's `src/Plugin/tool/Tool/` directory on case-insensitive filesystems (macOS, Windows), since those filesystems treat `Tool` and `tool` as the same folder. A module wanting to provide both an MCP Server tool and a Tool API tool could not create both directories. To fix this, MCP Server moved all five of its plugin manager subdirectories under a module-namespaced `Plugin/mcp_server/...` path, following the same convention Tool API already uses.

## Impact

Affects module maintainers.

- **API change:** MCP Server plugin discovery subdirectories renamed from `Plugin/Tool`, `Plugin/ArgumentCompletionProvider`, `Plugin/Notification`, `Plugin/ResourceProvider`, and `Plugin/ResourceTemplateProvider` to `Plugin/mcp_server/Tool`, `Plugin/mcp_server/ArgumentCompletionProvider`, `Plugin/mcp_server/Notification`, `Plugin/mcp_server/ResourceProvider`, and `Plugin/mcp_server/ResourceTemplateProvider` respectively, with matching namespace changes.

## Technical details

The fix updates the `parent::__construct()` call in each of the five plugin manager classes (`ToolPluginManager`, `ArgumentCompletionProviderManager`, `NotificationProviderManager`, `ResourceProviderManager`, `ResourceTemplateProviderManager` in `src/Plugin/`) to pass a new subdirectory argument prefixed with `mcp_server`, e.g. `'Plugin/Tool'` becomes `'Plugin/mcp_server/Tool'`. Existing plugin classes shipped in the module's own test fixtures were moved accordingly (for example `tests/modules/mcp_server_test/src/Plugin/Tool/EchoTool.php` moved to `.../Plugin/mcp_server/Tool/EchoTool.php`), and their namespace declarations were updated to match. The README's tool-authoring documentation was updated to reflect the new `src/Plugin/mcp_server/Tool/` location and `Drupal\my_module\Plugin\mcp_server\Tool` namespace.

## Upgrade

Any custom or contrib module providing plugins for MCP Server must move its plugin classes into the new subdirectories and update their namespaces:

```php
// Before: my_module/src/Plugin/Tool/SendEmail.php
namespace Drupal\my_module\Plugin\Tool;

// After: my_module/src/Plugin/mcp_server/Tool/SendEmail.php
namespace Drupal\my_module\Plugin\mcp_server\Tool;
```

The same rename applies to `Plugin/ArgumentCompletionProvider` to `Plugin/mcp_server/ArgumentCompletionProvider`, `Plugin/Notification` to `Plugin/mcp_server/Notification`, `Plugin/ResourceProvider` to `Plugin/mcp_server/ResourceProvider`, and `Plugin/ResourceTemplateProvider` to `Plugin/mcp_server/ResourceTemplateProvider`. Plugins left in the old locations will no longer be discovered.
