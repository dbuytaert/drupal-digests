# #3601394: ensure_ddev refuses any distro outside Debian/RHEL, even when Docker and DDEV are already installed

## Summary

The one_line_installer script used to abort immediately on any Linux distribution outside the Debian/Ubuntu or Fedora/RHEL families, even if Docker and DDEV were already installed and working on that machine. Now the distro check no longer blocks the whole install: it only matters if Docker Engine actually needs to be installed. If Docker is already present and running, the installer proceeds normally regardless of distro. If Docker is missing and the distro is unrecognized, the installer now fails with a clear message telling the user to install Docker manually, rather than an opaque "unsupported distribution" error at the very first step.

## Impact

No upgrade or configuration changes required.

## Technical details

The distro detection in `linux_detect_distro` (in `src/lib/platform/linux_detect_distro.sh`, mirrored in the compiled `drupalaibp` script) previously called `die` for any `ID`/`ID_LIKE` outside the debian/ubuntu/fedora/rhel/centos set, setting the `PKG` variable used to select `apt` or `dnf`. Since `PKG` is only consumed by `linux_ensure_docker` when it needs to install Docker Engine, and `linux_ensure_docker` returns early whenever `docker info` already succeeds, the distro check was failing installs that never needed `PKG` at all.

The fix leaves `PKG` empty (with a `warn` instead of `die`) for unmapped distros and lets `linux_detect_distro` return successfully. The actual failure is moved into `linux_ensure_docker`'s install branch: only when Docker is not found (`command -v docker` fails) does it now check `[[ -n "${PKG:-}" ]]`, dying with a Docker-specific message pointing to `docs.docker.com` if `PKG` is empty. Debian/RHEL behavior is unchanged since `PKG` is still populated for those families. Corresponding bats tests in `tests/bats/lib/platform/linux_detect_distro.bats` and `linux_ensure_docker.bats` were updated to assert the new no-die/empty-`PKG` behavior and the deferred failure message.
