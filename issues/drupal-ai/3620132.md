## Summary

This recipe sets up a chunked, AI-searchable vector index for content. Previously, applying the recipe configured the index to use Search API's generic default tracker for bookkeeping which entities need (re)indexing. Now it configures the index to use the `ai_search_tracker` ("AI Search Chunked Tracker") that the `ai_search` module provides specifically for tracking per-chunk indexing state. Sites that apply this recipe going forward get the tracker built for chunked indexing rather than the generic one.

## Impact

Affects site owners.

- **Config change:** The `search_api.index.content_vector` index's `tracker_settings` now default to `ai_search_tracker` (the AI Search module's chunked tracker) instead of Search API's plain `default` tracker.

## Technical details

The recipe's `content.recipe.yml` (or equivalent config action) that builds the `search_api.index.content_vector` index previously hardcoded `tracker_settings: default:`. The fix changes this to `tracker_settings: ai_search_tracker:`, keeping the same `indexing_order: lifo` option under the new tracker key. The `composer.json` requirements were also tightened: `drupal/search_api` is bumped to `^1.40` (from `^1.39`) and `drupal/ai_search` to `>=1.3.0-alpha3 <2.0.0-alpha1` (from `^1.3@alpha`), to ensure the required tracker plugin and Search API version are available when the recipe is applied.
