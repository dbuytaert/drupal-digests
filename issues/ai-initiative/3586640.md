## Summary

This is the meta plan for a new standalone module, `ai_disclosure`, which helps sites meet Article 50 of the EU AI Act (applicable since 2 August 2026). It lets editors record how AI was involved in each piece of content, works out whether a visible label is legally required, and shows readers an EU-icon disclosure. It also outputs machine-readable markers and adds a compliance report at `/admin/reports/ai-disclosure`. At the time of the last update, the foundation, field, widget, formatter, marking, recorder API, report and multilingual child issues are checked off. The documentation issue and the companion integrations for other AI modules are still open.

## Impact

Affects module maintainers.

- **New API:** Planned public `DisclosureRecorder` API with `suggest()` and `apply()` methods, plus a `DisclosureResolver` service, in the new `ai_disclosure` module.

## Technical details

The plan describes an `ai_disclosure` field type added per bundle, one disclosure per entity translation. Its modes are `inherit` (uses the bundle default and stores no data), `none`, `profile` and `custom`.

Grades are config entities with stable machine names: `human_only`, `ai_metadata`, `ai_rated`, `ai_translated`, `ai_summarized`, `ai_partly_assisted`, `ai_assisted_hitl`, `ai_generated_autonomous` and `ai_deepfake`. Each carries severity, EU icon mapping, a label-required flag, a review-exemptible flag, a disclosure sentence and an IPTC `digitalSourceType` URI. Disclosure profiles are also config entities. They hold a grade, a human-review flag, editorial responsibility and a shared markdown description that all inheriting content uses.

The `DisclosureResolver` service decides whether a label is required with `grade.label_required && !(human_review && grade.review_exemptible)`. The human-review exemption applies to text only, so deep-fake grades cannot be exempted by review. The formatter renders the EU icon, the per-grade sentence and an expandable "How was AI used?" section. A site policy setting chooses between labelling only when required and always disclosing. JSON-LD and meta output carry the IPTC `digitalSourceType`.

The public `DisclosureRecorder` API is the integration surface. AI tools call `suggest()`, which shows the editor an Accept/Dismiss callout, or `apply()` for headless pipelines. The dependency direction is deliberately inverted, so `ai_disclosure` knows nothing about specific AI tools. Out of scope for 1.0: Art. 50(1) chatbot notices, C2PA or watermark file embedding, AI-content detection, and retroactive labelling of content published before 2026-08-02.
