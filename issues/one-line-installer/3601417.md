## Summary

Unattended installs run with `--yolo` no longer stop at "Starting DDEV..." waiting for an answer to DDEV's "May we send anonymous DDEV usage statistics?" question. That question appears on the first `ddev start` after DDEV is installed or upgraded, so it always appeared on a fresh machine. Under `--yolo` the prompt is now skipped and no usage data is sent. Interactive runs are unchanged.

## Impact

No upgrade or configuration changes required.

## Technical details

`setup_site_command.sh` (and its generated copy) now exports `DDEV_NO_INSTRUMENTATION=true` right after `ASK_UNATTENDED` is set from `YOLO`, before `run_install` runs any DDEV command. The condition is `ASK_UNATTENDED -eq 1`, so any unattended run triggers it, including config-driven runs, not only `--yolo`. The export uses `${DDEV_NO_INSTRUMENTATION:-true}`, so a value the user already set (for example `false`) is kept. DDEV's global configuration is not modified.

The `--yolo` help text was updated in the CLI spec, usage output, man page and docs, and bats tests cover the three cases: exported under `--yolo`, unset for interactive runs, and a user-set value preserved.
