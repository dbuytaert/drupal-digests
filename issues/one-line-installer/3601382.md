# #3601382: Default Option- Picks a name for the project if it already exists.

## Summary

The one_line_installer's setup-site script picks a directory/name for the new Drupal project when you don't pass `--name`. Previously, if the default name (`my-drupalcms-site`) was already taken, it would silently fall back to auto-suffixed names like `my-drupalcms-site_1`, `my-drupalcms-site_2`, etc. Now there is no silent suffixing: if the default is taken, you must type a name yourself (a `--yolo` run in that situation now errors out with guidance instead of guessing). Additionally, if you launch the installer from a directory that is already empty and whose name is usable as a DDEV project name, the installer now offers to build the project directly in that directory (pressing Enter accepts this) instead of always nesting a new subdirectory inside it. Typing a name still creates a new subdirectory as before.

## Impact

No upgrade or configuration changes required.

## Technical details

The change is in `step_create_project_dir` in `src/lib/steps/create_project_dir.sh`. The old suffix-loop that appended `_1` through `_10` to `$PROJECT_DIR` when it already existed has been removed entirely; there is now no auto-suffix fallback.

A new helper `_launch_dir_is_free` determines whether the current working directory can become the project directory in place: it must be empty (checked via `ls -A`, treating an unreadable directory as not free) and must not be `$HOME` or `/` (compared with `-ef`, which uses device/inode so it's robust to trailing slashes and symlinked home paths). If free, its basename is also checked against DDEV's naming pattern (`^[A-Za-z0-9]([A-Za-z0-9-]*[A-Za-z0-9])?$`) since DDEV derives both the project name and the `https://<name>.ddev.site` URL from the directory name. When both conditions hold, `--yolo` builds in place silently; interactively, Enter builds in place while a typed name still creates a new subdirectory. When in-place building isn't applicable, the suggested default is the base name only if free; if it's taken there is no default at all, forcing the user to type a name (re-prompting on empty input). Terminal input reading was extracted into `_project_name_read` (reads from `/dev/tty`) so the bats test suite can stub prompt responses instead of feeding real keystrokes.
