# #3591474: canvas_translate dependency in Drupal CMS 1.2 prevents auto updates

- **Project:** Drupal CMS
- **Type:** Normal unknown (0)

## Summary

New sites built from Drupal CMS 1.2's Starter template showed a long composer warning whenever an automatic update was attempted, because the `canvas_translate` module (needed by the Multilingual recipe) was being pulled in only as an indirect dependency at an unstable (alpha) release, which Composer flags. The fix adds `canvas_translate` explicitly to the project's `composer.json` so its alpha stability is declared up front, and automatic updates proceed cleanly on new installs.

## Impact

No upgrade or configuration changes required.

## Technical details

The `Multilingual` recipe (`recipes/drupal_cms_multilingual/recipe.yml`) installs the `canvas_translate` module, but `project_template/composer.json` never listed it as a top-level requirement, so Composer had to resolve it transitively. Since `drupal/canvas_translate` currently has no stable release, and the project sets `"minimum-stability": "dev"` with `"prefer-stable": true`, an unpinned transitive dependency at alpha stability produced the stability/update warning users saw when Drupal CMS's automatic update tooling ran `composer` under the hood.

The fix is a one-line addition to `project_template/composer.json`'s `require` section: `"drupal/canvas_translate": "@alpha"`. Declaring the package explicitly with its stability flag lets Composer resolve it deterministically without flagging the ambiguity, so sites scaffolded from the template (including via the graphical installer with the Starter recipe) no longer hit the warning on update.</technical>
