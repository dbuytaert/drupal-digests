# #3591500: Add some new admin page events to benchmark

## Summary

Drupal CMS's opt-in telemetry now also records visits to five routine admin pages: the menu list, the content list, the Canvas pages list, the views list and the status report. These are used as a baseline for comparing against the admin pages telemetry already tracks, such as the SEO checklist and the webform list. The event records only which page was visited. The updated telemetry docs say it does not record who visited, how, or when.

## Impact

No upgrade or configuration changes required.

## Technical details

`TelemetrySubscriber` in `drupal_cms_helper` keeps a list of route names that trigger the `Telemetry::AdminPage` event, and the event's `page` value is the route name. The change adds `entity.canvas_page.collection` (`/admin/content/pages`), `entity.menu.collection` (`/admin/structure/menu`), `entity.view.collection` (`/admin/structure/views`), `system.admin_content` (`/admin/content`) and `system.status` (`/admin/reports/status`). `TelemetryHooksTest::testAdminPages` is extended to cover the new routes and now asserts a 200 response. `docs/src/updates/telemetry.md` now lists every tracked path in a table.
