## Summary

Drupal CMS's installer now lists "Educare" as a selectable site template, alongside the existing options. Educare is aimed at schools, universities, academies and e-learning providers, and ships pages for programs, admissions, research, student life, events, news and contact, built with Drupal Canvas and the Vartheme BS5 Educare theme. Anyone installing Drupal CMS can now pick this template directly from the installer's list, complete with its screenshot, description, "Learn more" and "Demo" links, and a "Created by Vardot" credit.

## Impact

No upgrade or configuration changes required.

## Technical details

The change is a pure data addition: one new `educare` entry appended to `drupal_cms_installer/site-templates.yml`, pointing at the `drupal/educare` package on Packagist (no `repository` or `authorization` overrides needed). No installer code changes were required since the installer already drives its template list off this YAML file.

The entry landed together with several other Vardot-authored templates (`varbase_starter`, `rightup`, `educare`, `horizonaid`) in a single combined commit for issue [#3591478](https://www.drupal.org/node/3591478), rather than as a standalone commit for this issue.
