# #3591420: Add Summit site template to site-templates.yml

- **Project:** Drupal CMS

## Summary

Drupal CMS's installer lets you start a new site from a curated list of site templates. This change adds Summit, a template built for organizing a conference or similar event: it handles user-submitted sessions (with moderation and scheduling), and includes sections for events, sessions, articles, sponsorships, birds-of-a-feather (BOF) sessions, job listings, personal schedules, and webforms. It was converted from the earlier "Event Platform Starter" recipe and is maintained by the Event Organizers Working Group. Anyone installing Drupal CMS can now pick Summit from the template list instead of building an event site from scratch.

## Impact

No upgrade or configuration changes required.

## Technical details

The change is a straightforward entry added to `drupal_cms_installer/site-templates.yml`, the curated list read by the installer (see `\Drupal\drupal_cms_installer\SiteTemplate`). The new `summit` key follows the file's standard schema: `name`, `description`, `screenshot`, `package` (`drupal/summit`), a `links` list pointing to the template's `new.drupal.org` listing page, and `creator` (Event Organizers Working Group). No installer code changed; the `SiteTemplate` value object already supports this shape, so adding the template is purely a data addition to the list that the installer surfaces.
