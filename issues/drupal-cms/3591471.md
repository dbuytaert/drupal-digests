# #3591471: Add the Hourglass Corporate and Goodwell site templates to the installer

- **Project:** Drupal CMS
- **Type:** Normal unknown (0)
- **Status:** Fixed
- **Discussion:** [#3591471](https://git.drupalcode.org/project/drupal_cms/-/work_items/3591471) · 1 contributor · 4 comments

## Summary

Two new site templates built by OpenSense Labs, Hourglass Corporate (for B2B and SaaS companies) and Goodwell (for insurance businesses), are now selectable when installing Drupal CMS. Previously only the templates listed in the installer's configuration were shown, so these otherwise-ready templates were invisible to anyone running the installer.

## Impact

No upgrade or configuration changes required.

## Technical details

The fix adds two entries, `hourglass_inc` and `goodwell`, to `drupal_cms_installer/site-templates.yml`, each pointing to the corresponding Composer package (`drupal/hourglass_inc`, `drupal/goodwell`) already published on Packagist. Each entry follows the existing schema used by other templates such as CareSphere and Convene: `name`, `description`, `screenshot` (pulled from the project's `1.0.x` branch), `package`, a `links` list with a "Learn more" URL, and `creator`. Both templates are Site recipes built with Drupal Canvas that pass the starter kit's `RequirementsTest` (no custom code, no pinned dependencies, no patches), so no other code changes were needed to make them available in the installer.
