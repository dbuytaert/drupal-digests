## Summary

The Drupal CMS installer now offers the Saplings site template. It targets independent local businesses and uses a garden nursery as demonstration content, with services, workshops with sign-up forms, a filterable catalog, staff profiles and articles. It is built with Canvas and needs no custom PHP.

## Impact

Affects site owners.

- **Config change:** New `saplings` entry in `drupal_cms_installer/site-templates.yml`.

## Technical details

The change is one new `saplings` entry in `drupal_cms_installer/site-templates.yml`. It sets `name`, `description`, a `screenshot` URL pointing at the Saplings project's `4.x` branch, `package: 'drupal/saplings'`, a `Learn more` link to the project page, and `creator: Kanopi Studios`. The issue body says the template ships stable releases (`drupal/saplings` 4.0.0, which uses `drupal/arboretum` 2.0.0), passes its tag pipeline and the site template `RequirementsTest`, and has security advisory coverage. The Arboretum theme is new and still in the waiting period for opting in to coverage.
