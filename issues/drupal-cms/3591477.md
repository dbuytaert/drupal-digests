## Summary

Drupal CMS's installer now lists "Educare" as a selectable site template, alongside the existing options. Educare is aimed at schools, universities, academies, and e-learning providers, and ships home, programs, admissions, research, student life, events, news, and contact pages, plus ready-made Canvas patterns, built on the Vartheme BS5 Educare theme. Anyone running the Drupal CMS installer will now see it in the template picker with its screenshot, description, "Learn more" and "Demo" links, and a "Created by Vardot" credit; no other installer behavior changes.

## Impact

No upgrade or configuration changes required.

## Technical details

The fix adds a single new entry, `educare`, to `drupal_cms_installer/site-templates.yml`, the file the installer reads to populate its site-template picker. No installer code changes were needed; the template mechanism already supports arbitrary Composer-installable recipes that meet the site template `RequirementsTest` rules (a Site recipe, no bundled modules or themes, no pinned dependencies or patches, GPL-2.0-or-later, and no `uuid`/`_core` keys in shipped config).

The entry follows the same shape as other templates: `name` and `description` for the picker UI, `screenshot` pointing at the project's `screenshot.webp` on its `1.0.x` branch, `package` set to `drupal/educare` (resolved from Packagist, so no `repository` or `authorization` overrides), a `links` list ("Learn more" to the drupal.org project page, "Demo" to Vardot's hosted demo, "Documentation" to Varbase's docs), and `creator: Vardot`.</technical>
