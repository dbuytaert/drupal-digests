## Summary

The Cafe site template is now offered in the Drupal CMS installer. It is aimed at independent cafes and includes demonstration content (a menu with prices, opening hours, visit information, stories, staff profiles, site search and a catering inquiry form), built with Canvas and the Coffeehouse theme.

## Impact

No upgrade or configuration changes required.

## Technical details

The entry is a new `cafe` key in `drupal_cms_installer/site-templates.yml` with name, description, screenshot URL, `package: 'drupal/cafe'`, a Learn more link and `creator: Kanopi Studios`. The same commit also adjusts development tooling: `drupal/site_template_helper` is added to the `source` install list in the dev composer file, and the temporary `twig/twig` 3.30.0 pin is removed. In its place a core patch `patches/core/twig-3.31-new-parameter.patch` ([#3641104](https://www.drupal.org/node/3641104)) is applied, adding an optional `$check = TRUE` argument to `Drupal\Core\Template\Loader\FilesystemLoader::addPath()`.
