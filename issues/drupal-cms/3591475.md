## Summary

Drupal CMS's installer now offers "Horizon Aid" as a selectable site template alongside the existing options. Horizon Aid is built for NGOs, nonprofits, charities and humanitarian aid organizations, and ships with home, about, programs, countries, events, resources, impact and donate pages plus a blog and newsletter sign-up. Its listings are Views rendered through card view modes, so adding or unpublishing content updates the site without editing a page. It uses the Vartheme BS5 Horizon Aid theme built with Drupal Canvas. Anyone running the Drupal CMS installer will now see it in the list of templates, with its screenshot, description, "Learn more" and "Demo" links, and a "Created by Vardot" credit.

## Impact

No upgrade or configuration changes required.

## Technical details

The change adds a single entry, keyed `horizonaid`, to `drupal_cms_installer/site-templates.yml`, pointing at the `drupal/horizonaid` package on Packagist (currently 1.0.5). No installer code changes were needed since the installer already reads this file to build its list of choices. The entry follows the same shape as other site templates: `name`, `description`, `screenshot` (pulled from the project's `1.0.x` branch), `package`, a `links` list ("Learn more" to the drupal.org project page, "Demo" to a Vardot-hosted demo, "Documentation" to Varbase's docs), and `creator: Vardot`. The template itself was verified against the site template `RequirementsTest` rules: it is a Site recipe with no bundled modules or themes, no pinned dependencies or patches, a GPL-2.0-or-later license, and no `uuid` or `_core` keys in shipped config.</technical>
