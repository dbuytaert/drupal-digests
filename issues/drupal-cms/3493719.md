## Summary

Drupal CMS now adds a "Recommended" tab to the Extend section (`/admin/modules`), next to the existing Project Browser tabs. It links to the standalone local recipes page at `/admin/modules/browse/recipes`. This is a first increment: the Extend menu item does not yet default to this page, and the tab's active state is not yet correct. Both were left to follow-ups.

## Impact

Affects site owners.

- **Requirements:** The Drupal CMS recipe now requires `drupal/eca` ^2.1.0-beta1, `drupal/bpmn_io` ^2.0.2 and `drupal/token` ^1.
- **Config change:** New `eca.eca.recipe_local_task` and `eca.model.recipe_local_task` config; the recipe now installs `eca_base`, `eca_render` and `token`.

## Technical details

Project Browser can already expose the recipes source at its own page, but it provides no local task for it. Local tasks cannot ship as content entities, so the tab is added with an ECA model. The new config `eca.eca.recipe_local_task` (plus its `eca.model.recipe_local_task` BPMN model for the bpmn_io modeller) listens to the `eca_render:local_tasks` event. When `[current-page:url:path]` equals `/admin/modules` or begins with `/admin/modules/`, it runs an `eca_render_link` action. That action prepends a link titled "Recommended" pointing to `/admin/modules/browse/recipes`.

The recipe's `composer.json` gains `drupal/eca`, `drupal/bpmn_io` and `drupal/token`. The recipe's `install` list gains `eca_base`, `eca_render` and `token`. `ComponentValidationTest` now logs in a user with `administer modules`, loads `/admin/modules/browse/recipes`, and asserts a "Recommended" link in the primary tabs. The merged link is titled "Recommended" rather than "Recipes" and is placed first.

Known gaps noted in the thread: the Extend menu link does not default to this page, and both "Recommended" and "Browse" tabs get `is-active` on the recipes page. A related follow-up, [#3495142](https://www.drupal.org/node/3495142), reported that the Project Browser UI for contrib modules was not reachable from the Recommended tab. It was later closed as outdated.
