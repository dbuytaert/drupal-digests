## Summary

Drupal CMS's installer now offers "The Rightup" as a site template option, alongside the existing choices like Byte, Haven, and Varbase. The Rightup is built by Vardot for newsrooms, magazines, publishers, and editorial teams, and includes news and podcast listings, article and episode pages, section landing pages, filterable search, a newsletter, and a home page feed ticker that editors curate from an entity queue (falling back to the newest published content). It uses the Vartheme BS5 Rightup theme and is built with Drupal Canvas. Anyone running the Drupal CMS installer will now see it listed with its screenshot, description, and links to learn more or try a live demo.

## Impact

No upgrade or configuration changes required.

## Technical details

The change is a single new entry added to `drupal_cms_installer/site-templates.yml`, the curated list the installer reads to populate its site template chooser. No code changes were needed since the file already supports everything the entry requires: `name`, `description`, `screenshot`, `package` (resolved from Packagist as `drupal/rightup`), `links` (Learn more, Demo, Documentation), and `creator` (Vardot). The entry follows the same shape used by other Vardot-supplied templates already in the file, such as `varbase_starter`, `educare`, and `horizonaid`.
