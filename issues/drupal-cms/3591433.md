# #3591433: Add a drupal_cms_multilingual recipe with content translation features

## Summary

Drupal CMS now offers a "Multilingual" recipe (`drupal_cms_multilingual`) that site owners can apply to add multi-language support to their site. Applying it installs Drupal core's Language, Content Translation, Interface Translation and Configuration Translation modules, along with the contributed Better Content Language Settings, Canvas Translate and Language Checklist modules. After applying the recipe, the site gains a "Multilingual setup checklist" page (under Administration » Configuration » Regional and language) that walks the owner through adding languages, choosing how the site detects a visitor's language, marking which content types and fields are translatable, and translating content, configuration and the admin interface.

## Impact

Affects module maintainers.

- **New API:** New `drupal_cms_multilingual` recipe installs Language, Content Translation, Interface Translation, Configuration Translation plus the Better Content Language Settings, Canvas Translate and Language Checklist contributed modules.

## Technical details

The recipe lives at `recipes/drupal_cms_multilingual` and is a plain `recipe.yml` that lists the modules to install (`better_content_language_settings`, `canvas_translate`, `config_translation`, `content_translation`, `language`, `language_checklist`, `locale`) and imports the `language.entity.und` and `language.entity.zxx` config entities, which are needed so that adding a language on the Languages page does not crash (recipes do not automatically bring in the config entities of the modules they install). It also declares a Project Browser task pointing at the `checklistapi.checklists.language_checklist` route, so the checklist shows up as a "Finish multilingual setup" follow-up action.

The recipe is wired into `drupal_cms_starter`'s `recommended.yml` as a suggested add-on and into the `project_template/composer.json` as a `^2` dependency, so new Drupal CMS installs can pick it up as one of the recommended recipes. Its functional test, `ComponentValidationTest`, applies the recipe against sites installed in English or Hungarian, with and without Config Language Lock, and verifies it is idempotent, preserves the install language as the default, and that its follow-up Project Browser task resolves to a working page.
