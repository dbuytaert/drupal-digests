## Summary

The Drupal CMS installer's list of site templates now includes Varbase Starter, a general-purpose starting point built by Vardot that combines the Drupal CMS and Varbase base recipes with a Canvas home page, a blog, demo content, search, and an editorial workflow. Anyone running the Drupal CMS installer will now see this template as a selectable option, alongside its screenshot, description, "Learn more" and "Demo" links, and "Created by Vardot" attribution.

## Impact

No upgrade or configuration changes required.

## Technical details

The change adds a single new entry, `varbase_starter`, to `drupal_cms_installer/site-templates.yml`, following the same structure as existing entries: `name`, `description`, `screenshot`, `package` (`drupal/varbase_starter`, resolved from Packagist), a `links` list ("Learn more", "Demo", "Storybook", "Documentation"), and `creator` (Vardot). No installer code changes were needed since the installer already reads this YAML file to populate the template chooser.

The template itself is a Site recipe distributed as `drupal/varbase_starter`, which the issue notes conforms to the site template `RequirementsTest` rules used for entries in this list (no bundled modules or themes, no pinned dependencies or patches, GPL-2.0-or-later license, no `uuid` or `_core` keys in shipped config).
