## Summary

A Tool module output typed as a datetime but without a `DateTime` or `DateOnly` marker used to advertise a `date` schema while returning the raw stored value, such as `2026-08-01T12:35:07`. That value matched neither `date` nor `date-time`. Now the schema says the value is either an RFC 3339 date-time or a plain date. Values go out to match: a stored datetime gets a UTC offset, and a bare date stays a date. Tools that want one fixed format should still declare a marker.

## Impact

Affects module maintainers.

- **API change:** An unmarked `datetime_iso8601` output now advertises `anyOf` `date-time` or `date`, and a storage-format value is sent as RFC 3339.

## Technical details

The issue offered two options: treat unmarked like `DateTime`, or advertise no format. The fix is a hybrid. `OutputTypeCoercionSubscriber` now converts a `datetime_iso8601` string in the UTC storage format to RFC 3339 (`2026-08-01T12:35:07+00:00`) unless the output carries `DateOnly`. Previously it did this only when `DateTime` was present. A bare date, or a value that already has an offset, is returned unchanged. A bare date is not promoted to midnight UTC.

In `InputOutputDefinitionNormalizer`, the branch that was limited to inputs now applies to outputs too. An unmarked datetime gets `anyOf: [{format: date-time}, {format: date}]` and the description note "An RFC 3339 date-time, or a date alone as YYYY-MM-DD." This matches the input side from [#3583005](https://www.drupal.org/node/3583005). `DateTime` and `DateOnly` outputs keep their single `format`. For a nullable output, the `anyOf` branches still allow `null`, and a test covers that.

Tests: `timestamp_output_tool` gained unmarked `updated_at` and `due_on` outputs, so the schema conformance sweep now covers this case. `OutputCoercionMatrixTest` gained marked, unmarked, bare date, offset and `DateOnly` cases. The docs text on output markers was also updated.

## Upgrade

Tool authors who return an unmarked `datetime_iso8601` value in storage format will now see it sent with a `+00:00` offset. To pin a single format, declare a marker on the output:

```php
constraints: ['DateTime' => []],  // advertised as date-time
constraints: ['DateOnly' => []],  // advertised as date, value left as returned
```
