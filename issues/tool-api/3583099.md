## Summary

Code outside a tool call can now get the schema of a value object whose members are marked with `#[ToolProperty]`. A new `tool.value_object_describer` service returns the same definition a tool output of that class would get. You can turn it into JSON Schema with the serializer. For example, a Single Directory Component can take its props from the schema the tools publish instead of copying descriptions into its YAML.

## Impact

Affects module maintainers.

- **New API:** New public service `tool.value_object_describer` (`Drupal\tool\Tool\Method\ValueObjectDescriber::describe(string $class, array $members = [])`) returns an `OutputDefinitionInterface` for a value object class.

## Technical details

The new `final` class `Drupal\tool\Tool\Method\ValueObjectDescriber` is registered as `tool.value_object_describer`, with a class-name alias for injection. It builds an `@internal` `TypedMethodDescriber` and calls a new `describeValueObject()` on it. That method reuses the private `valueObjectOutput()` that tool outputs go through, so the schemas match (kernel tests compare against real tool outputs). It reflects the class only, so it needs no instance and calls no getters.

The optional `$members` argument takes the same selection syntax as `#[ToolOutput(members: ...)]`: names, named `ToolProperty` refinements, and names keyed to nested lists. An explicit selection can also include unmarked public properties and getters. The result is a required, non-nullable map labelled with the humanized short class name.

Errors: with no tool ID, `valueObjectOutput()` now rethrows member mismatches as `\InvalidArgumentException`. A new `selectionContext()` helper leaves the `(tool "...")` suffix out of messages when there is no tool. `describeValueObject()` throws `\InvalidArgumentException` naming the class for opaque classes such as `\DateTimeImmutable`, a class with no marked members and no selection, and invalid selections. `docs/developers/tool-methods.md` documents the service.

## Upgrade

```php
$describer = \Drupal::service('tool.value_object_describer');
$definition = $describer->describe(Image::class);
$schema = \Drupal::service('serializer')->normalize($definition, 'json_schema');
```
