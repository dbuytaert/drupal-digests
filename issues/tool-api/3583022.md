## Summary

The Tool module needs Drupal core's Serialization module, but it was not declared as a dependency. On a site without Serialization enabled, enabling Tool failed with a "class not found" error for `ComplexDataNormalizer`. Tool now declares the dependency. Sites that already have Tool installed get Serialization enabled automatically when they run database updates.

## Impact

Affects site owners.

- **Database update:** New post update `tool_post_update_install_serialization()` installs the core `serialization` module on existing sites.

## Technical details

`tool.info.yml` lists `drupal:serialization` under `dependencies`. The declaration was already in the repository when this commit landed, and the commit itself adds the follow-up for existing installs. `ContextDefinitionNormalizer` extends core's `Drupal\serialization\Normalizer\ComplexDataNormalizer`, which fails to load when Serialization is disabled. Adding a dependency to `.info.yml` does not affect modules that are already installed, so the commit adds `tool_post_update_install_serialization()` in the new `tool.post_update.php`. It calls `module_installer->install(['serialization'])`. `docs/installation.md` now says the base module depends only on core's Serialization module, which is enabled automatically.

## Upgrade

Run database updates (`drush updb` or `/update.php`) after updating. The post update `tool_post_update_install_serialization` enables the core `serialization` module.
