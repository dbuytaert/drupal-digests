## Summary

The Tool module's typed data adapter alter hook and plugin cache key are now prefixed with the module name. Modules that implement `hook_data_type_adapter_info_alter()` keep working for now but trigger a deprecation notice and should switch to `hook_tool_typed_data_adapter_info_alter()`. The `text` data type ID stays as it is, contrary to the issue's original proposal to rename it to `tool_text`.

## Impact

Affects module maintainers.

- **API change:** `hook_data_type_adapter_info_alter()` is replaced by `hook_tool_typed_data_adapter_info_alter()`, and the adapter plugin cache key is now `tool_typed_data_adapter_plugins`.
- **Deprecation:** `hook_data_type_adapter_info_alter()` is deprecated in tool:1.0.0-beta4 and removed from tool:1.0.0-rc1.

## Technical details

`TypedDataAdapterManager` now calls `alterInfo('tool_typed_data_adapter_info')` and `setCacheBackend($cache_backend, 'tool_typed_data_adapter_plugins')`. It also overrides `alterDefinitions()`. If any module implements the old `data_type_adapter_info_alter`, it triggers an `E_USER_DEPRECATED` error (deprecated in tool:1.0.0-beta4, removed from tool:1.0.0-rc1). It then runs the legacy alter before `parent::alterDefinitions()`, so the prefixed hook runs last and wins on conflict. The hook is documented in a new `tool.api.php`. `TextData` keeps the plugin ID `text`; a docblock now says the generic ID is deliberate because it is a core-aligned name, and other modules such as `typed_data` are expected to mean the same thing by it. A new kernel test, `PrefixedIdentifierTest`, checks that `text` still resolves and that the cache entry `tool_typed_data_adapter_plugins` is created.

## Upgrade

Rename the implementation of the alter hook:

```php
// Before (deprecated, removed in 1.0.0-rc1):
function mymodule_data_type_adapter_info_alter(array &$definitions): void {}

// After:
function mymodule_tool_typed_data_adapter_info_alter(array &$definitions): void {}
```

Code that reads the old `data_type_adapter_plugins` cache entry directly should use `tool_typed_data_adapter_plugins`.
