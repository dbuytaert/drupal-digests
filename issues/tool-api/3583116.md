## Summary

Tools declared with `#[ToolMethod]` can now make their access decision depend on who is invoking them. Before, only `#[Tool]` plugins could see the invoker, so a tool that had to be disabled for certain callers could not be written as a method tool. Existing access callbacks that take two parameters keep working unchanged.

## Impact

Affects module maintainers.

- **New API:** `#[ToolMethod]` `access` callbacks are now called with a third argument, the nullable `?Invoker` set on the tool: `(array $values, AccountInterface $account, ?Invoker $invoker)`.

## Technical details

`MethodTool::checkAccess()` now calls the declared access method as `$this->service->{$method}($values, $account, $this->getInvoker())`. `getInvoker()` returns `NULL` when the tool was created without an invoker, for example from Tool Explorer or `ToolManager::createInstance()` with no invoker. PHP ignores the extra argument for callbacks that declare only two parameters, which is why they are not affected. `ToolRunner::run()` supplies the invoker ID `php` when its caller omits one, and `drush tool:run` supplies `drush` (both per the updated docs).

The docs and the `ToolMethod` attribute docblock describe the new signature. They also note that an ID comparison does not reliably identify remote callers. Caller-kind capabilities are tracked in a separate issue, [#3583130](https://www.drupal.org/node/3583130). The documented example returns `AccessResult::allowedIf(...)->setCacheMaxAge(0)`, because the result depends on the invoker and the runner does not cache access results. The change adds an `InvokerAccessFixture` test fixture and kernel tests covering a set invoker, a different invoker and `NULL`.

## Upgrade

Optional. To use the invoker, add a third parameter to the access callback:

```php
use Drupal\tool\Tool\Invoker;

public function invokerAccess(array $values, AccountInterface $account, ?Invoker $invoker): AccessResultInterface {
  return AccessResult::allowedIf($invoker?->id === 'example_caller')
    ->setCacheMaxAge(0);
}
```
