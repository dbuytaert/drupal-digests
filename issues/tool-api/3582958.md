## Summary

Descriptions of entity-typed tool inputs and outputs are no longer HTML-escaped in the schemas sent to AI models. Before, an apostrophe, quote, ampersand or angle bracket in a description reached the model as `&#039;` and similar entities, through both the AI connector and MCP. The model now receives the text as written.

## Impact

No upgrade or configuration changes required.

## Technical details

`EntityHandleTransformer::transformInputDefinition()` and `::transformOutputDefinition()` built the handle description as a string, then wrapped it in `new TranslatableMarkup('@description', ['@description' => $description])`. The `@` placeholder is escaped with `Html::escape()` on render. The wrapping added no translatability, because the fragments were already translated. Both methods now pass the assembled `$description` as a plain string. A new kernel test, `EntityHandleTransformerTest::testTransformedDescriptionsAreNotHtmlEscaped()`, checks that apostrophes, ampersands and angle brackets survive both transforms.
