# #3583076: Let a string definition say what it contains with contentMediaType

## Summary

Tool input and output definitions can now say what a string holds, such as plain text, HTML or Markdown. Before, a title and an HTML caption produced the same schema, so a front end or a model had to guess from the description which one was markup. Adding a `MediaType` constraint with a `type` such as `text/html` now makes the generated schema carry a `contentMediaType` entry. Existing definitions and schemas are unchanged.

## Impact

Affects module maintainers.

- **New API:** New `MediaType` validation constraint (plugin ID `MediaType`, option `type`) that the normalizer emits as JSON Schema `contentMediaType`.

## Technical details

`MediaTypeConstraint` is registered with the `#[Constraint]` attribute under the ID `MediaType` and requires a non-empty string `type` option. It throws `MissingOptionsException` otherwise. Its validator, `MediaTypeConstraintValidator`, accepts every value. This follows JSON Schema, where `contentMediaType` is descriptive and not an assertion. The constraint is used because the constraints array is where a definition already carries facts beyond its type, and the normalizer already reads `Email` and `Uuid` from there to emit `format`. In `ContextDefinitionNormalizer`, when `MediaType` is present and the schema type is `string`, the `type` option is emitted as `contentMediaType`. The constructor accepts either named arguments or a single options array, so it works on cores with and without named-argument support (Drupal 10). The docblock says the constraint does not make markup safe: consumers must still filter `text/html` values. The issue says it was extracted from [#3518120](https://www.drupal.org/node/3518120), where `media_type:` on attribute-defined tool attributes builds on it. Docs were updated in `docs/developers/input-output-definitions.md`, and tests were added.

## Upgrade

```php
'caption' => new OutputDefinition(
  data_type: 'string',
  label: new TranslatableMarkup('Caption'),
  description: new TranslatableMarkup('The image caption.'),
  constraints: ['MediaType' => ['type' => 'text/html']],
),
// {"type": "string", "contentMediaType": "text/html", ...}
```
