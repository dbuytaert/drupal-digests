## Summary

Cleanup before the AI Context 1.0 release candidate. The default `target_entity_types` setting no longer lists `canvas_page`, since that entity type is only present on some sites. An update on existing sites also removes `canvas_page` from the saved setting, so anyone who relies on it will need to re-enable it after running updates. The menu link for the Context Control Center has a new plugin ID, and an unused site section settings form was deleted.

## Impact

Affects module maintainers and site owners.

- **Config change:** `canvas_page` removed from default `ai_context.scope_settings.target_entity` `target_entity_types`, and removed from existing sites by a post-update.
- **Deprecation:** 

## Technical details

`ai_context.scope_settings.target_entity.yml` install config drops `canvas_page`. A new `ai_context.post_update.php` adds `ai_context_post_update_0001_remove_canvas_page_from_target_entity_types()`, which filters `canvas_page` out of `target_entity_types` in `ai_context.scope_settings.target_entity` for every existing site, whether or not it was added deliberately.

The menu link plugin ID in `ai_context.links.menu.yml` changes from `ai_context.overview` to `ai_context.main_menu_link`, so it no longer shares a name with the `ai_context.overview` route. Any custom menu link using `parent: ai_context.overview` would need updating. A search of the module found no other reference to the old plugin ID.

The orphaned `AiContextScopeSiteSectionForm` (which wrote to `ai_context.scope.site_section`) is deleted. Smaller coding standard fixes: `declare(strict_types=1)` added to `DiffHooks.php` and `AiContextUninstallValidator.php`, and `$childrenService` renamed to `$children_service` in `ai_context.module`. Remaining items from the review are tracked in [#3586192](https://www.drupal.org/node/3586192).

## Upgrade

Run database updates (`drush updb`) to apply the post-update. If you use `canvas_page` as a target entity type, re-add it in the AI Context settings afterwards. Custom menu links that name the old plugin ID as a parent need to change it:

```yaml
parent: ai_context.main_menu_link
```
