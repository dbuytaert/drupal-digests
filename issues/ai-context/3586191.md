## Summary

AI Context items longer than the configured max token limit used to be left out of the prompt entirely. They are now truncated so they still fit within the budget. An item is skipped only when its metadata (id, label, purpose) alone cannot fit in the remaining tokens.

## Impact

No upgrade or configuration changes required.

## Technical details

In `AiContextRenderer`, the token limit was applied to the guidance text before the metadata wrapper (`- id:`, `label:`, `purpose:`, `guidance:`) was added, so the wrapped block could still exceed the budget and be dropped. The metadata prefix is now built first via the new private `buildBlockPrefix()`, and the guidance is truncated to `$maxTokens - $acc - estimateTokens($prefix)`, using `textChunker->chunkText()` when a model ID is set and `truncateByApproxTokens()` otherwise. The block is assembled by `buildBlock()`. If the wrapped block still exceeds the budget, the snippet is shortened in a loop until it fits or is empty. If no tokens remain after the prefix, the item is skipped and added to `truncatedItems`. Items whose guidance was shortened are now also reported in `truncated_items`.

The same commit adds a selector test, `testSelectorCapsAlwaysIncludeItemsAtMaxItems`, asserting that `always_include` items are still capped by `maxItems`. The diff has no selector code change.
