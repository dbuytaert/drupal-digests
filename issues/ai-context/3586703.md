## Summary

When the Diff module was installed, any user who could use published AI context could open Diff comparison pages for context items and read older published revisions. That includes text editors had removed on purpose, and on sites that grant the permission to Anonymous, anonymous visitors. The Diff pages now need the same \"View all AI Context Item revisions\" permission as the revision history pages. Sites on Diff 8.x-1.x, 2.0.0 or 2.1.0 were affected. Diff 2.0.1 and 2.1.1 already require this upstream. After updating, review which roles have the revision permission and rebuild caches so the router picks up the new requirement.

## Impact

Affects site owners.

- **Security:** Access bypass: on Diff 8.x-1.x, 2.0.0 and 2.1.0, users with only "Use Published AI Context in AI Features" (possibly Anonymous) could view older published revisions through Diff comparison pages. Priority major.
- **Permission change:** Diff comparison pages for context items now require "View all AI Context Item revisions" (or Administer AI Context), plus view access to the item.

## Technical details

`AiContextRouteSubscriber::alterRoutes()` now takes the route `entity.ai_context_item.revisions_diff`, if present, and sets `_entity_access` to `ai_context_item.view all revisions`. This is the requirement of the revision history route. Diff's controller still checks `view` access on each of the two revisions. The route also gets the `no_cache` option, because Diff adds no cache metadata for those per-revision checks. The option applies on Diff 2.0.1 and 2.1.1 too, because upstream does not set it there.

A new kernel test, `AiContextItemRevisionDiffAccessTest::testDiffRouteNeedsRevisionPermission`, checks that a user with only `access published ai context` is denied. It also checks that a user with `view all ai context item revisions` is allowed, and it asserts the route requirement and the `no_cache` option. `require-dev` stays on `drupal/diff: ^1.0` so the test runs against a Diff version without the upstream change. Docs were updated in `access-boundaries.md` (a new \"Revision and Diff pages\" section), `configuration.md` and `revisions.md`.

## Upgrade

Rebuild caches after updating (`drush cr`) so the router uses the new requirement. Grant **View all AI Context Item revisions** to any role that should still compare revisions with Diff.
