## Summary

On sites that use language URL prefixes, a Site Section pattern such as `/about/*` now matches the same page in every language, for example `/af/about/team`. Before, the prefixed page did not match, so Site Section context items were never selected there. Patterns that already include a prefix, such as `/af/about/*`, still work but only match that language. To limit an item to one language, add the Language scope.

## Impact

Affects site owners.

- **Config change:** Selections and subscription budget summaries now carry the `config:language.negotiation` cache tag, so changing URL prefixes or `url.source` refreshes them.

## Technical details

`AiContextScopeSiteSection` now builds a list of request paths through a new `getRequestPaths()`: the path from `AiContextRequestInfoResolver::getPath()`, plus the same path with its language prefix removed. `doGetDetectedValue()`, `getMatchingIndexedValues()` and `matchesRequestContext()` all test against both, so the Relevant prefilter and the full check agree.

The prefix removal lives in the new public `AiContextLanguageService::stripLanguagePrefix()`. It does nothing unless `language.negotiation` `url.source` is `path_prefix`, so domain-based sites keep the path as is. Matching is on a whole first path segment (`/afterwards` is not touched), empty prefixes are skipped, and the segment is `rawurldecode()`d before comparison so an encoded prefix such as `/op%C3%A9rations` matches. The segment is split before decoding, so an encoded slash does not split it. `/af` becomes `/`. The old private `extractLanguageFromPath()` was replaced by `findPathPrefix()`, which `detect()` also uses, so language detection now also accepts encoded prefixes.

`AiContextSelector` adds the `language.negotiation` config as a cacheable dependency, and `AiContextSubscriptionBudgetCalculator` adds the `config:language.negotiation` tag, so changes to prefixes or `url.source` invalidate cached results. Kernel tests cover prefixed, encoded, unprefixed, `/afterwards`, domain negotiation and cache invalidation cases. `docs/features/scopes.md` and `docs/features/multilingual.md` and the Site Section form descriptions now say to write patterns without the prefix.
