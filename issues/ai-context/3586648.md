## Summary

New sites that install AI Context now get a default "Max tokens for injection" of 20,000, up from 1,200. The old value fit only one or two typical context items, so most sites had to raise it before the module was useful. Existing sites are not changed, because there is no update hook. Check the value at `/admin/config/ai/context/settings/general`. The budget applies to every pushed AI call, including each turn of an agent loop, so a higher value can raise input costs. Each consumer can override the budget under its own **Advanced** settings, either lower to limit cost or higher for more context.

## Impact

Affects site owners.

- **Config change:** `max_tokens` in `config/install/ai_context.settings.yml` default raised from 1200 to 20000 for new installs; no update hook, existing sites keep their saved value.

## Technical details

The default lives in two places that are set independently: `config/install/ai_context.settings.yml` (read on fresh install) and the `AiContextSelection::DEFAULT_MAX_TOKENS` constant (the code fallback). Both are now 20000. A new unit test, `testShippedMaxTokensMatchesTheConstant()` in `AiContextSelectionTest`, decodes the install YAML and asserts it equals the constant, so the two cannot drift apart.

The docs were updated: the "default: 1200" text in `docs/developers/configuration.md`, the `maxTokens` example in `docs/developers/services.md`, and the consumer docs, which now explain the per-consumer override. The issue notes that the token budget ceiling in [#3586636](https://www.drupal.org/node/3586636) defaults to 32,000, so it stays above the new default.

## Upgrade

Existing sites keep their saved `max_tokens`. No update hook runs. To adopt the new default, raise **Max tokens for injection** at `/admin/config/ai/context/settings/general`. Code that relied on the `AiContextSelection::DEFAULT_MAX_TOKENS` fallback of 1200 now gets 20000.
