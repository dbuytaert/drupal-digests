## Summary

AI Context (CCC) now requires AI 1.4.12 or later on the 1.4 branch, or AI 1.5.2 or later. On AI 1.4.11 and earlier, context that CCC pushed into automator requests and other generic chat requests did not reach OpenAI-based providers, although the debug log and the Usage tab reported the push. Sites on AI 1.4.11 or earlier must update AI before updating CCC.

## Impact

Affects site owners.

- **Requirements:** `drupal/ai` constraint changes from `~1.4.11 || ^1.5.2 || ^2` to `~1.4.12 || ^1.5.2 || ^2`.

## Technical details

AI 1.4.11 `ProviderProxy` did not copy the changed system prompt back to the system role after `PreGenerateResponseEvent`, so context pushed on the generic path was lost while the result status and usage records still said `pushed`. AI 1.4.12 includes `cbe279c6` on the AI 1.4.x branch (project/ai[#3586825](https://www.drupal.org/node/3586825)), which adds the copy-back. The commit changes the `drupal/ai` constraint in `composer.json` and updates the README and docs (`docs/index.md`, `docs/upgrade-policy.md`, `docs/features/consumer_configuration.md`, `docs/developers/consumer_api.md`, `docs/developers/debugging.md`, `docs/developers/events.md`). The "On AI 1.4.x" limits are removed, since every supported AI version now sends the `ai_automator:id:{id}` tag and `entity_context`. The temporary `AiContextAutomatorIdTagSubscriber` is documented as no longer needed, with its removal tracked in [#3586463](https://www.drupal.org/node/3586463). The docs also note a known issue where a multi-value automator field can get earlier context blocks repeated, fixed in [#3586709](https://www.drupal.org/node/3586709).

## Upgrade

Update AI before CCC:

```
composer require drupal/ai:'~1.4.12 || ^1.5.2 || ^2'
```
