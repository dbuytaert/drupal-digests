## Summary

Agents that loop call the LLM several times, and AI Context was appending the same context block to the system prompt on every iteration. There is now a per-agent "Loop-aware context injection" checkbox. When enabled, context is injected only on the first loop (loop 0) and left out of the system prompt on later loops, which saves tokens. It is off by default, so existing sites behave as before. The trade-off is that the LLM only keeps context influence through earlier conversation messages, so the form description says it suits stable directives like tone better than factual data or output-format constraints.

## Impact

Affects module maintainers and site owners.

- **Config change:** New optional boolean `loop_aware` per agent in `ai_context.agents` (default FALSE, missing key treated as FALSE), exposed as a checkbox under an Advanced section of the agent context form.
- **New API:** `AiContextRequestFactory::isLoopAware()` added, and `findAgentConfig()` is now public.

## Technical details

`AiContextSystemPromptSubscriber::onAgentStarted()` now records `$event->getLoopCount()` per agent ID and caches the agent's `loop_aware` flag. `onPreSystemPrompt()` returns early when the stored loop count is above 0 and the flag is set. That early return also skips usage tracking on those loops. If no started event was seen for the agent, the loop count is unset and context is still injected.

The subscriber does not read `ai_context.agents` itself. `AiContextRequestFactory` gained `isLoopAware(string $agentId)`, and `findAgentConfig()` changed from private to public as the canonical per-agent config lookup. The schema in `ai_context.schema.yml` adds `loop_aware: boolean` to the per-agent mapping, and `AiContextAgentForm` saves it from a checkbox in a new collapsed `advanced` details element. No update hook is needed because a missing key is read as FALSE. Kernel tests cover the request factory and the subscriber at loop 0, 1 and 5 with the flag on and off, plus the missing-key and missing-started-event cases.
