## Summary

AI Context now requires a drupal/ai version that shows tooltips as plain text: 1.4.11 or later on the 1.4 branch, or 1.5.2 or later. Older drupal/ai versions (1.4.10 and earlier, 1.5.0, 1.5.1) insert tooltip values as HTML, so HTML stored in a long context item Description or an AI agent description could run as script in an administrator's session when they open the consumer pages. Composer now blocks those versions. Exploiting it needs a privileged permission such as Create AI Context Item or Administer AI Agent.

## Impact

Affects site owners.

- **Security:** Stored XSS in admin consumer pages (context item Description and AI agent description tooltips) when drupal/ai renders `data-ai-tooltip` via `innerHTML`; requires privileged authors, runs in an administrator's session.
- **Requirements:** `drupal/ai` constraint changed from `^1.4 || ^2` to `~1.4.11 || ^1.5.2 || ^2`.

## Technical details

CCC puts text in `data-ai-tooltip` attributes, and the `ai/ai_global.js` behavior from drupal/ai reads it via `dataset.aiTooltip`. Two tooltips are escaped once on the CCC side (`AiContextItem::buildDescriptionRenderArray()` and `AiContextConsumersForm::getTruncatedDescription()`), which is correct only if drupal/ai uses `textContent`. With `innerHTML` the decoded value is parsed as HTML. The commit changes no PHP, Twig or tests: it only changes the `composer.json` constraint and the version text in `README.md`, `docs/index.md`, `docs/upgrade-policy.md` and `docs/features/consumer_configuration.md`. The Automator notes now say 1.5.2 instead of 1.5.0.

The constraint deliberately avoids `^1.4.11`, because that would allow 1.5.0 and 1.5.1. Composer cannot check the commit of a dev branch, so sites on a drupal/ai dev branch (including all drupal/ai 2 sites, as 2.x has no release yet) must update to the current branch head. The docs say this. Until the follow-up [#3586705](https://www.drupal.org/node/3586705) lands, some other tooltips (scope pills, `+N` overflow, Automator description) show HTML entities such as `&amp;` with these drupal/ai versions, as stated in the issue.

## Upgrade

Update drupal/ai together with CCC:

```
composer update drupal/ai_context drupal/ai -W
drush updatedb
```

To stay on AI 1.4:

```
composer update drupal/ai_context drupal/ai -W --with drupal/ai:~1.4.11
```

If you use a drupal/ai dev branch (for example `1.5.x-dev` or `2.x-dev`), update it to the current branch head.
