## Summary

The AI Context overview page (`/admin/ai/context/overview`) requested its external link icon from a wrong path. The result was a 404 and a missing icon. The path is fixed, so the icon loads and the missing asset no longer shows up in the logs.

## Impact

No upgrade or configuration changes required.

## Technical details

In `css/ai_context_overview.css`, the `mask-image` URL for the external link icon used `../../contrib/ai/assets/icons/external.svg`. That resolved to `/modules/contrib/contrib/ai/assets/icons/external.svg`. It now uses `../../../contrib/ai/assets/icons/external.svg`. This still reaches into the `ai` module's `assets/icons/` directory through a relative path, which the issue suggested avoiding, but the shipped change only adds the missing `../`.
