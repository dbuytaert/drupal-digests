## Summary

The Chat Explorer has a new **Render Markdown** checkbox on the Output tab. When it is on, assistant answers are shown as formatted HTML (headings, lists, code blocks, tables, strikethrough, and non-interactive task markers) instead of plain text. It is off by default and is saved with the chat. Copy, export and the history sent to the model keep the original raw text, and user, system and tool messages are displayed as before.

## Impact

Affects site owners.

- **Config change:** New `markdown` boolean in saved Chat Explorer chat settings (default FALSE), included in JSON export and import.

## Technical details

The setting is added as `markdown` to `ChatGenerator::SETTINGS` and the defaults, handled like `stream` and `structured` as an unchecked-checkbox boolean, and validated as a bool on import. `buildMessage()` takes a new `$markdown` argument and, for assistant text without schema errors, calls the new `markdownBlock()` instead of `textBlock()`. `markdownBlock()` converts the text and passes the HTML through `Xss::filterAdmin()` before it is wrapped in a div with the `aie-chat__answer--markdown` class. When the option is on, the chat input also gets `setHostnameFilter(new HostnameFilterDto(markdownMode: TRUE))`.

The converter is a new `ai_api_explorer.chat_markdown_converter` service built by `ChatMarkdownConverterFactory` from `ai.commonmark_converter_factory`, so the shared `ai.commonmark_converter` is unchanged. The factory adds the table, strikethrough and task list extensions. The default task list renderer outputs `<input>` elements, which the XSS filter strips, so `TaskListItemMarkerRenderer` outputs a `span` with `role="img"` and an `aria-label` (Completed task or Incomplete task) containing a ☑ or ☐ character. New CSS in the explorer stylesheet covers `.aie-chat__answer--markdown` (normal whitespace, `pre` kept, table borders, horizontal overflow). The change also adds a README section, functional, FunctionalJavascript and kernel tests, including an XSS test and a streamed answer test.
