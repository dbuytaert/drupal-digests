## Summary

The AI API Explorer now has shared viewers for file results. An audio player draws a waveform and has play/pause, click-to-seek, a speed button, duration and download. Formats browsers cannot play, such as raw PCM, show a note and a download link instead. Images open full size in a dialog with their details and a download link, and transparent images sit on a checkerboard. There is also a before/after image comparison with a slider or side-by-side mode, and a box overlay with a minimum-confidence slider and label toggles. A style guide explorer in the test module shows each viewer with sample files. Explorers such as text to speech, text to image and object detection can use these viewers without writing their own markup.

## Impact

Affects module maintainers and front-end developers.

- **Theme change:** Six new Twig templates (`ai-api-explorer-*.html.twig`) that themes can override.
- **New API:** New theme hooks `ai_api_explorer_audio`, `ai_api_explorer_image`, `ai_api_explorer_compare`, `ai_api_explorer_boxes`, `ai_api_explorer_audio_compare` and `ai_api_explorer_bars`, with templates and an `ai_api_explorer/media` library.

## Technical details

The commit registers the theme hooks in `Hook\AiApiExplorer`, each with an initial preprocess function in `ai_api_explorer.module`. Each has a Twig template, and the audio and image templates take their icons from `ExplorerUi::icon()`. The matching `ExplorerUi` builder methods (`audio()`, `image()`, `audioCompare()`, `compare()`, `boxes()`, `bars()`) already existed in the module. Each one attaches the new `ai_api_explorer/media` library, which depends on `explorer_ui` and adds `css/explorer-media.css` and `js/explorer-media.js`.

The preprocess functions do the computation. For boxes, pixel coordinates become percentages of the image size, and the box labels are counted for the toggle buttons. For bars, values are clamped between 0 and 1 and given CSS classes. Image and compare templates get an `aspect-ratio` from `width` and `height` when both are known.

The behaviors in `explorer-media.js` are `aieAudioPlayer`, `aieCompare` and `aieBoxes`. The audio player fetches the file once and decodes it with the Web Audio API to get waveform peaks. It then plays the same blob through an object URL, which it revokes on detach. If the fetch or decode fails, the `<audio>` element loads the URL itself, and an `error` event or a failed `play()` switches the player to a note plus download. Starting one player pauses the others. The compare slider and the confidence control are native `input[type=range]` elements, so they work with the keyboard. Image preview uses a native `<dialog>` opened through `data-aie-dialog-open`. The dialog handler is not part of this diff.

The test module gets a `styleguide_explorer` plugin with sample SVG, WAV and PNG assets. Functional and kernel tests cover the new markup and theme hooks. A FunctionalJavascript test was also added, but its diff was not available to me.

## Upgrade

To use the viewers, return the `ExplorerUi` render arrays from an explorer plugin, as the style guide plugin does:

```php
'player' => ExplorerUi::audio($assets . 'sample.wav', 'audio/wav', 'sample.wav', $this->t('the sample')),
'compare' => ExplorerUi::compare($assets . 'before.svg', $assets . 'after.svg', ['width' => 640, 'height' => 420]),
'boxes' => ExplorerUi::boxes($assets . 'after.svg', 640, 420, $boxes, 'Shapes with boxes', 0.25),
```
