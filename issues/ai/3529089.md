## Summary

Submitting the AI Content Suggestions settings form at `/admin/config/ai/suggestions` no longer triggers an "Undefined array key" warning for `tone_prompt`. The warning appeared after enabling a suggestion and saving, and was also seen when moving from 1.1.x to 1.2.x. The fix is backported to 1.1.x and 1.2.x and also landed on 2.0.x.

## Impact

No upgrade or configuration changes required.

## Technical details

In `Tone::saveSettingsForm()` (`modules/ai_content_suggestions/src/Plugin/AiContentSuggestions/Tone.php`), the prompt was read with `$value[$this->getPluginId() . '_prompt']`, which is absent from the submitted values in some cases. It now uses `$value[$this->getPluginId() . '_prompt'] ?? $this->defaultPrompt`, so the stored prompt falls back to the plugin's default prompt instead of an undefined value being written to `promptConfig`. The same one-line change was committed to 1.1.x, 1.2.x and 2.0.x.
