## Summary

The Image and Audio to Video explorer in `ai_api_explorer` is rebuilt on the shared explorer layout. Image and audio now come from the shared file picker (upload, recent runs or media library). An Output box shows the video's shape (from the image) and length (from the audio) before you run. Each run is stored as a run card with the video player, the input image and audio, a download button and a generated PHP code example. Provider and model selection now use the `ai_provider_configuration` form element. The old bugs are gone: the model was read from a form key that did not match the form prefix, and the returned `VideoFile` array was passed to a function that expected a single value, which showed as 'Configuration Error'.

## Impact

No upgrade or configuration changes required.

## Technical details

`ImageAndAudioToVideoGenerator` was rewritten around the base-plugin helpers: `buildLayout()`, `providerElement('image_and_audio_to_video', ...)`, `executeRun()`, `buildRunResults()` and `resultsResponse()`. Inputs are two `ai_api_explorer_file` elements (`#media_type` of `image` and `audio`). They are converted with `ExplorerFile::toOperationFile()` and passed to `ImageAndAudioToVideoInput`. The old `AiProviderFormHelper`, `ExplorerOutputFiles` and `FileUrlGeneratorInterface` constructor dependencies are removed.

Every video in the provider response is saved as a file attached to the run. Its MIME type is taken from the response, then the file name extension, then `finfo` sniffing, and falls back to `video/mp4`, so providers that send `application/octet-stream` still work. Run output stores the image size, the audio name and the video list. Errors such as a missing file, a non-image or non-audio file, or an empty provider response are thrown as translated `RuntimeException`s and shown on the run card. The code example is built with `CodeExample` in `buildRunCode()`.

A new `explorer.image_and_audio_to_video` library adds `css/explorers/image_and_audio_to_video.css` and `js/explorers/image_and_audio_to_video.js`. The script has two behaviors. `aieIavPicker` fills the Output shape and length lines from the picker preview. `aieIavVideo` sizes the video box from the loaded video metadata and pauses other media when one starts. The test module gains a `TestImageAndAudioToVideoProvider` provider and a `sample.mp4` asset, plus FunctionalJavascript tests.
