## Summary

The Image Classification Explorer in AI API Explorer has been rebuilt on the shared explorer layout. You can pick the image from recent results instead of re-uploading it, choose between your own labels (edited as chips) or the model's own label set, and see scores as bars ranked best first. A cut-off slider only hides low scores in the display; the full response is kept. Provider and model selection now use the `ai_provider_configuration` form element. Two bugs are fixed: scores no longer print as raw numbers (they show with two decimals), and the generated code example no longer hard-codes `image/jpeg` or pastes labels in unescaped.

## Impact

No upgrade or configuration changes required.

## Technical details

`ImageClassificationGenerator` was rewritten on top of `AiApiExplorerPluginBase`: it builds the shared layout, stores each run through `executeRun()` and renders results from the stored run (`buildRunOutput()`, `runBadge()`, `runMeta()`, `runActions()`). The image field is the `ai_api_explorer_file` element. The provider is chosen with `providerElement('image_classification', ...)` instead of `AiProviderFormHelper::generateAiProvidersForm()`, and the old constructor dependencies (file system, file URL generator, provider helper) are gone.

Labels are parsed one per line, trimmed and de-duplicated case-insensitively. In "My labels" mode they are sent to the provider; in model mode none are sent, though typed labels are kept in the run input so editing a run restores them. Returned items are sorted by score, highest first, with unscored labels last. The result notes when the model used its own labels instead of yours, or which of your labels were not scored. Labels from the model are escaped before rendering. The cut-off is handled client side in the new `js/explorers/image_classification.js` (library `explorer.image_classification`): the server renders every bar and the script hides those below the cut-off, never the best one.

The code example is built per run with the shared `CodeExample` builder. The MIME type comes from the image data, falling back to the type stored with the run or a guess from the file name, and labels are emitted as escaped values. A new `ai_api_explorer_test` provider (`TestImageClassificationProvider`) returns fixed, unsorted scores for functional tests. `ExplorerFile` also casts the choice value to a string to avoid the PHP 8.5 deprecation of NULL array offsets. The docs page for the explorer has its menu path and URL corrected.
