## Summary

Adding a new Milvus or Zilliz vector database server in the AI module's admin UI failed with errors such as "The collection already exists" or a Zilliz "can't find a collection" error. A regression from a recent validation check caused this. New servers can now be created again.

## Impact

No upgrade or configuration changes required.

## Technical details

The `MilvusProvider` backend config validation checks the database via a describe call and sets a form error on `backend_config][database_name` when the response `code` is not 200. That check had been added by [#3480295](https://www.drupal.org/node/3480295) and ran on creation too, where the database or collection does not yet exist. The fix gets the entity from `$form_state->getFormObject()->getEntity()` and only reports the error when `!$entity->isNew()`, so the check applies when editing an existing server and not when creating one.
