## Summary

The AI API Explorer now has an Image to Video Explorer at `/admin/config/ai/explorers/image_to_video_generator`. You upload an image, optionally describe the motion in a prompt, pick a provider and model, and get a playable video with a download button and a code example. It appears in the explorer list when an `image_to_video` provider is configured. Image-only models still work without a prompt, and provider errors are shown in the results area.

## Impact

No upgrade or configuration changes required.

## Technical details

The explorer is a new plugin, `ImageToVideoGenerator` (`#[AiApiExplorer]`, id `image_to_video_generator`, operation type `image_to_video`), registered in the `av` group of `ExplorerHub`. It follows the shared explorer UX of the other explorers: the `ai_api_explorer_file` input element for the image, the shared provider config element (`providerElement('image_to_video', ...)`), run history with "edit and run again" and "use as source" handling, and a generated code example via `CodeExample`.

On submit it builds an `ImageToVideoInput` from the image, calls `setPrompt()` only when a prompt was entered, and calls `imageToVideo()` on the provider. Every `VideoFile` in the normalized output is saved as a file via the run manager, so providers that return several videos are all shown. The video is rendered as a plain `<video>` element sized from the source image, since there is no shared video component. A new `explorer.image_to_video` library adds `css/explorers/image_to_video.css` and `js/explorers/image_to_video.js`. The JS shows the video shape and length once metadata loads, updates the "Output" shape line from the picked image, and pauses other videos when one plays. The diff adds a test class for the explorer.
