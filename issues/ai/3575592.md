## Summary

In the AI API Explorer's Tools Explorer, setting a tool property's limit to "Force value" used only the first character of the configured value as the property's default. The full forced value is now used, so tool tests in the explorer reflect the configured limit. The fix was also cherry-picked to the 1.2.x, 1.3.x and 1.4.x branches.

## Impact

No upgrade or configuration changes required.

## Technical details

In `ToolsExplorer::getResponse()`, the `force_value` case added the `FixedValue` constraint using the parsed `$values[0]`, but set the default with `$limit['values'][0]`. `$limit['values']` is the raw textarea string, so indexing it returned a single character. The default now uses `$values[0]`, the same parsed value as the constraint, so the two agree.
