## Summary

Text in the AI API Explorers is easier to read. In Gin dark mode the muted text (run chips, segmented controls, view switches, task descriptions) was 4.21:1 against its background, below the 4.5:1 WCAG 2.2 asks for. It is now lighter. Status pills, hub filter counts, the Embeddings similarity matrix, and the faded rows in Rerank and the threshold bars were also changed so their text reaches the required contrast in light and dark mode.

## Impact

Affects front-end developers.

- **Theme change:** AI API Explorer CSS tokens changed: `--aie-muted` is lighter in Gin dark, `--aie-primary-text` is now a mix, and new `--aie-danger-text` and `--aie-green-text` tokens exist; custom themes overriding these may need review.

## Technical details

The main fix is in `css/explorer-ui.css`. Inside `.gin--dark-mode .aie`, `--aie-muted` is now `color-mix(in srgb, var(--gin-color-text-light, #545560) 75%, var(--aie-text))`. It is built from Gin's token rather than from itself, which would loop. `--aie-muted-strong` is mixed from it, so it gets lighter too. Gin light is not touched.

Coloured text now uses new tokens mixed towards `--aie-title`: `--aie-primary-text` (65% of the Gin primary), `--aie-danger-text`, `--aie-green-text`, and a stronger `--aie-warning-text` (45% instead of 60%). They are used by `.aie-status--ok` and `.aie-status--error`, `.aie-tools__req`, `.aie-tools__arg` and `.aie-rerank__row--up .aie-rerank__move`. The pressed `.aie-hub__filter .aie-count` swaps its colours (primary text on an `--aie-on-primary` background). `.aie-btn--primary:active` is listed so Gin's `a:active` colour does not override the button text. Selected file, task and size cards switch their secondary text to `--aie-muted-strong` on the tinted selection.

Faded rows no longer use `opacity` on text. `.aie-bar--dim` and `.aie-rerank__row--below` now fade only the bar fill (`.aie-bar__fill`, `.aie-rerank__fill`), and the label, text and value keep `--aie-muted`. In `embeddings.css` the matrix heat is capped at 35% of the accent (`calc(var(--aie-heat, 6%) * 0.35)`), so the title colour stays readable. `.aie-embeddings__hi` no longer switches to `--aie-on-primary` and is only bolder, and the legend gradient was adjusted to match.
