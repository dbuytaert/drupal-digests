## Summary

Translating a node with AI Translate no longer crashes with "Call to a member function hasTranslation() on null" when the node has an entity reference field that is empty. Empty reference fields are now skipped during translation.

## Impact

No upgrade or configuration changes required.

## Technical details

`ReferenceFieldExtractor::setValue()` assumed the field had referenced entities. With an empty field, `referencedEntities()` returned an empty array and the code later called `hasTranslation()` on a null entity. The fix adds an early return at the top of the method when `$entity->get($fieldName)->isEmpty()`, leaving the field untouched. The reporter's patch checked that the `$referencedEntities` array was non-empty. The maintainer instead wrote a different fix (an early empty-field check), saying it matches how the original code handled the same case elsewhere.
