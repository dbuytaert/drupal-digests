## Summary

The AI module and its submodules now declare Drupal 12 compatibility, so Composer can install them on Drupal 12. The minimum supported core is raised to 11.4, so Drupal 10 and earlier Drupal 11 releases are no longer supported by this branch. Custom function call plugins and constraint definitions you maintain may need small updates to work on Drupal 12.

## Impact

Affects module maintainers, front-end developers and site owners.

- **Requirements:** `core_version_requirement` changed from `^10.x || ^11.x` to `^11.4 || ^12` for `ai` and its submodules; Drupal 10 and Drupal 11 before 11.4 are no longer supported.
- **Theme change:** The AI tools iframe templates (`html__admin__config__ai__tools`, `page__admin__config__ai__tools`) now use `initial preprocess` with `ThemePreprocess` instead of `template_preprocess_html`/`template_preprocess_page`.
- **API change:** Function call plugins should declare `execute(?object $object = NULL)`, and `FixedValue` and `Choice` constraints must use named options such as `['value' => 'node']` and `['choices' => [...]]`.

## Technical details

`core_version_requirement` in `ai.info.yml` and the submodule info files is now `^11.4 || ^12`, with matching changes in `composer.json` (`drupal/key` `^1.23`, `drush/drush` `^13 || ^14`, `drupal/toolbar` `^2.0` added) and the README dependency lines.

Code changes follow core API changes. Function call plugins (for example `HelloWorld`, `ListColors`, `AutomatorPluginBase`) now use `execute(?object $object = NULL)`; the parameter is unused, and the docs say Drupal 12 requires it in the signature and that it also works on Drupal 11. Constraint options are passed with explicit names, since the diff's own test comment says Drupal 12 no longer accepts a constraint's default option without its name: `'FixedValue' => ['value' => 'node']` and `'Choice' => ['choices' => [...]]`. This is applied in the docs and in `ToolsExplorer`, both for its limit handling and for the generated code examples. The `ai_assistant_api` `hook_requirements()` implementation moved into a `AiAssistantApiRequirements` class using `#[Hook('runtime_requirements')]` and `RequirementSeverity::Warning`; the procedural `ai_requirements()` and `_ai_built_assets_requirements()` were removed from `ai.install`, and a `Drupal\ai\Hook\AiRequirements` class with a `runtime_requirements` hook exists in the repository.

The tools iframe templates in `ai_theme()` switch to `'initial preprocess'` pointing at `Drupal\Core\Theme\ThemePreprocess:preprocessHtml` and `preprocessPage` with an empty `preprocess functions` list. `ai_post_update_14001()` and an `ai_api_explorer` update no longer pass `TRUE` to `save()`. The `automator_ckeditor` library now lists `core/jquery` and `core/drupal` as dependencies. Tests move to the `default_admin` theme. CI also opts into the next major, drops the previous major jobs, and sets the Drupal 12 jobs to `allow_failure`. The diff returned was partial (74 of 373 files), so other changes may exist.

## Upgrade

If you maintain function call plugins, update the `execute()` signature:

```php
public function execute(?object $object = NULL) {
```

If you define `FixedValue` or `Choice` constraints on context definitions, key the options:

```php
constraints: [
  'FixedValue' => ['value' => 'node'],
  'Choice' => ['choices' => ['article', 'page', 'blog']],
],
```

Sites must be on Drupal 11.4 or later.
