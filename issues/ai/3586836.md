## Summary

The AI CKEditor integration (AI tools button, balloon menu, dialog, prompts) no longer ships inside the AI module. It now lives only in the standalone `drupal/ai_ckeditor` project, which the AI module pulls in through Composer. Sites that update the AI module with Composer should get the standalone module automatically. Sites that copy the AI module without Composer need to download `drupal/ai_ckeditor` themselves. This follows the earlier splits of `ai_content_suggestions`, `ai_logging`, `ai_translate` and `ai_validations`.

## Impact

Affects site owners.

- **Requirements:** `composer.json` of the AI module now requires `drupal/ai_ckeditor` (`^1.4`), so AI CKEditor comes from the standalone project.

## Technical details

The commit deletes the code and assets of `modules/ai_ckeditor` from the AI repository. That covers the PHP classes (plugin manager, attribute, controller, form, hooks, param converter), the CKEditor 5 JS sources and `package.json`, the CSS and icons, the routing, services, permission, libraries, config schema, and the default `ai_prompt` and `ai_prompt_type` config. The `.install` and `.post_update.php` files are also deleted, including the uninstall cleanup and the `ai_ckeditor_post_update_convert_ai_prompt()` conversion. The diff I received was partial (44 of 75 files), so the rest of this list comes from the repo checkout.

What remains of the submodule is `modules/ai_ckeditor/ai_ckeditor.info.yml`, still marked `lifecycle: deprecated`, now with `hidden: true`, plus the README, trimmed to the deprecation notice. The README still says the module will be removed from the AI module in 1.6.0.

`composer.json` adds `"drupal/ai_ckeditor": "^1.4"` to `require`, next to the other split-out modules. `.gitlab-ci.yml` no longer builds the `ai_ckeditor` JS assets in `js_build`. The `phpstan` and `.phpunit-base` jobs now delete any `ai_ckeditor` directory under `modules`, as they already do for the other split-out modules, so CI uses the Composer-installed copy.

## Upgrade

When updating the AI module, use Composer so the new requirement is resolved:

```
composer update drupal/ai --with-dependencies
```

This installs `drupal/ai_ckeditor` (`^1.4` per the AI module's `composer.json`). Sites that do not use Composer must download the standalone project from https://www.drupal.org/project/ai_ckeditor.
