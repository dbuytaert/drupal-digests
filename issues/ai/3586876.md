## Summary

The Chat Explorer in AI API Explorer no longer fails with "Drupal is not defined" on Drupal 12. Its JavaScript library did not declare its dependencies, so the browser could load the script before Drupal's core JavaScript and the explorer's behaviors never attached. The Embeddings explorer had the same gap and is fixed too.

## Impact

No upgrade or configuration changes required.

## Technical details

In `ai_api_explorer.libraries.yml`, `explorer.chat` and `explorer.embeddings` now declare `dependencies: - ai_api_explorer/explorer_ui`, as the other explorer libraries already do. That library pulls in `core/drupal`, `core/drupal.ajax` and `core/once`, which `js/explorers/chat.js` uses (`Drupal.behaviors`, `Drupal.t`, `Drupal.formatPlural`, `once`). Per the issue, Drupal 11 happened to order the scripts correctly, while Drupal 12 put the chat aggregate ahead of `core/drupal`. The commit also adds `core/drupal.announce` to the dependencies of `explorer.decision`.
