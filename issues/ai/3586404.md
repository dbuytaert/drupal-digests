## Summary

The Embeddings explorer in AI API Explorer is rebuilt on the shared explorer layout. It has two modes: One text, and Compare. Compare embeds up to ten texts and shows a similarity matrix, plus a ranked "nearest to" list for any chosen text. Results now show dimensions, token count and a short vector preview instead of printing the whole vector. The full vector or embeddings matrix can be opened, copied or downloaded as JSON. One text can take an optional image, but only for models that say they read images. Models that read text only, or do not say, get an error and the image is not sent. Runs are stored in run history, and the explorer still works when history is off. Two bugs are fixed: `provider_id` and `model_id` from the URL query now select the model, where before they were written to the Text to speech fields. The generated code example no longer calls the non-existent `getRaw()` and uses a valid image MIME type.

## Technical details

`EmbeddingsGenerator` now builds on `buildLayout()` and the run history helpers (`executeRun()`, `buildRunResults()`). Provider and model selection uses the `ai_provider_configuration` element, through `providerElement('embeddings', ...)` and `createProviderFromValue()`, in place of `AiProviderFormHelper::generateAiProvidersForm()`. The `queryProvider()` method turns `provider_id` and `model_id` into a value for that element. `queryTexts()` accepts `input` as a plain string or a JSON list, and a list opens Compare mode.

Compare makes one `embeddings()` call per text and checks that all vectors have the same length. `similarityMatrix()` computes cosine similarity for every pair. The result is saved on the run (`dimensions`, `items`, `matrix`, `vectors`), and the full vectors are also saved as an `embeddings.json` file for download. Token usage is read from the raw output when the provider reports it. The image path calls `readsImages()` and throws unless the model reports image support. A model that does not say is treated as unable to read images, because such providers drop the image and embed the text alone. Per-model facts such as vector size and image support go to the browser as `data-aie-embeddings-models`.

New assets: the `explorer.embeddings` library (`css/explorers/embeddings.css`, `js/explorers/embeddings.js`). The JS behaviors handle adding and removing text rows, switching the image fieldset on and off with the chosen model, and showing the nearest list of the selected text. The commit also adds functional and FunctionalJavascript tests and updates the explorer docs path to `/admin/config/ai/explorers/embeddings_generator`. The diff tool omitted `EmbeddingsGenerator.php`, so this section was read from the file in the repository, where later commits may also have touched it.
