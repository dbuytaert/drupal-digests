## Summary

The base class for vector database (VDB) providers in the core AI module no longer depends on the `ai_search` submodule, so it can be used when `ai_search` is not enabled. VDB provider modules that work with Search API indexing must now extend a new base class in `ai_search`. Without that change they lose the Search API behavior they used to inherit.

## Impact

Affects module maintainers.

- **API change:** Search API methods (`buildSettingsForm()`, `validateSettingsForm()`, `submitSettingsForm()`, `viewIndexSettings()`, `indexItems()`, `deleteIndexItems()`, `deleteAllIndexItems()`) and the `AiVdbProviderSearchApiInterface` implementation were removed from `\Drupal\ai\Base\AiVdbProviderClientBase`.
- **New API:** New abstract class `\Drupal\ai_search\SearchApiAiVdbProviderBase` extends `AiVdbProviderClientBase` and implements `AiVdbProviderSearchApiInterface`.

## Technical details

`\Drupal\ai\Base\AiVdbProviderClientBase` used to implement `AiVdbProviderSearchApiInterface` and use `EmbeddingStrategyInterface`, which live in `ai_search`. The Search API specific code was moved into a new `\Drupal\ai_search\SearchApiAiVdbProviderBase`, which extends `AiVdbProviderClientBase`. The moved code is the settings form methods (database name, collection and similarity metric fields, collection creation on submit), `viewIndexSettings()`, `indexItems()` with its embedding validation and metadata handling, and the `deleteIndexItems()` and `deleteAllIndexItems()` wrappers around `deleteItems()` and `deleteAllItems()`. `AiVdbProviderClientBase` now implements only `AiVdbProviderInterface` and `ContainerFactoryPluginInterface`. The test provider in `test_ai_vdb_provider_mysql` was updated to extend the new class.

The diff does not show whether `AiVdbProviderClientBase` still references `ai_search` anywhere else. It still imports `Drupal\ai_search\Plugin\Exception\EmbeddingStrategyException`, and a `use` statement does not by itself load the class. Treat the base class as fully decoupled only after checking that.

## Upgrade

VDB providers that need Search API indexing must change their parent class. The test provider in the commit shows the change:

```php
use Drupal\ai_search\SearchApiAiVdbProviderBase;

class TestAiVdbProviderBaseMySql extends SearchApiAiVdbProviderBase {
```

Before the change it was `extends AiVdbProviderClientBase implements ContainerFactoryPluginInterface`. Providers that do not use Search API can keep extending `\Drupal\ai\Base\AiVdbProviderClientBase`.
