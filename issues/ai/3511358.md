## Summary

The AI Deepchat chatbot block no longer shows a separate block title on the page. Before, the "Display title" option was on by default, so the title appeared on every page with the block even though the chatbot already shows its own title inside the modal. The "Display title" checkbox is also hidden on the block configuration form for this block.

## Impact

Affects front-end developers.

- **Theme change:** New `block--ai-deepchat-block.html.twig` template for the `ai_deepchat_block` block that omits the block title; the 'Display title' field is hidden via CSS on the block form.

## Technical details

The fix has three parts in `ai_chatbot`. `ai_chatbot_theme()` registers a `block__ai_deepchat_block` theme suggestion (base hook `block`) that points to a new `templates/block/block--ai-deepchat-block.html.twig`. That template renders only the block content wrapper and leaves out the title. `ai_chatbot_form_block_form_alter()` attaches a new `ai_chatbot/ai_chatbot` library when the edited block's plugin ID is `ai_deepchat_block`. The library loads `css/ai_chatbot.css`, which hides `.form-item--settings-label-display`. The checkbox is hidden with CSS only. The setting still exists, and the title is suppressed by the template, not by the setting. The issue started with the older `ai_chatbot` block, but the committed change targets only `ai_deepchat_block`, because the older block was being phased out in favour of Deepchat.

## Upgrade

If you override block templates in a custom theme, a theme-level `block--ai-deepchat-block.html.twig` takes precedence over the module's template. Clear caches after updating so the new theme suggestion is picked up.
