## Summary

The AI chatbot's dropdown chevron no longer uses the generic `rotate` class, which could collide with theme or framework CSS. The chatbot's `deep-chat` element is also now explicitly styled as a block, so it fills the available width instead of behaving like an inline element. No functional logic changed. The fix was committed to 1.2.x, 1.3.x and 2.0.x.

## Impact

Affects front-end developers.

- **Theme change:** The `ai_chatbot` chevron toggle class `rotate` is now `chevron-icon--rotate`, and `.deepchat-element` now gets `display: block`.

## Technical details

The chatbot stylesheet replaces `.chevron-icon.rotate` with `.chevron-icon--rotate` (the `transform: rotate(-180deg)` rule is unchanged). The matching `classList.toggle()` call in the chatbot's dropdown JS now toggles `chevron-icon--rotate`. A new `.deepchat-element { display: block; }` rule is added, so the layout no longer depends on how a theme styles unknown custom elements. The same diff landed on all three branches.

## Upgrade

If a custom theme targets the old chevron state class, update the selector:

```css
/* before */
.chevron-icon.rotate { ... }
/* after */
.chevron-icon--rotate { ... }
```

If a theme sets its own `display` on `.deepchat-element`, check that it still produces the layout you want.
