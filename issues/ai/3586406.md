## Summary

The Summarize Text Explorer in AI API Explorer has been rebuilt on the shared explorer layout. It now has instruction presets (One sentence, 3 bullet points, For a newsletter) next to the free-text instructions field. Each summary shows how much shorter (or longer) it is than the source, as bars and a percentage. Every run stays in the Results region with its instructions, newest first, and failures show next to their run. Each run also gets a generated code example.

## Impact

No upgrade or configuration changes required.

## Technical details

`SummarizationGenerator` now builds on `buildLayout()` and replaces `AiProviderFormHelper::generateAiProvidersForm()` with the `ai_provider_configuration` element via `providerElement('summarize', ...)`. Submission goes through `executeRun()`, which stores the text, instructions and provider value as the run input and the summary as output. The provider is created with `createProviderFromValue()`. An empty summary is stored as an error with the message 'The provider returned no summary.' Results are rendered from stored runs by `buildRunResults()` and the `runTitle()`, `runBadge()`, `runActions()` and `buildRunOutput()` overrides. The summary text is escaped with `Html::escape()`.

The length comparison in `buildLength()` counts words, or characters when the source averages more than 20 characters per word (text without spaces, such as Chinese). The code example per run comes from `buildRunCode()` using the `CodeExample` builder. The presets are filled in by a new `explorer.summarize` library (`css/explorers/summarize.css`, `js/explorers/summarize.js`). The preset buttons are rendered `hidden` and shown by JavaScript, since they only fill the instructions textarea, and they carry `aria-pressed` state.

The change adds a test-only module plugin, `TestSummarizeProvider` (`ai_api_explorer_test`), and a functional test `SummarizeExplorerTest`. The provider returns the first sentence, or bullets when the instructions mention them, and the texts `empty` and `fail` trigger the empty and exception paths.
