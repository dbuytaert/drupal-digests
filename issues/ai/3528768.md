## Summary

The MR proposes a way to get the AI balloon menu without the "AI Assistant" button taking up CKEditor toolbar space. The AI CKEditor plugin settings would get a "Toolbar options" section with two checkboxes, "Show AI toolbar button" and "Show AI balloon menu". Unchecking the toolbar button hides the AI Assistant button while the balloon menu on text selection stays available. The separate "AI Balloon Menu" toolbar item would be removed. No commits have landed, and the thread says the MR needs work. A tester reported that after applying it the text format toolbar configuration UI rendered broken, and a pipeline failure was also reported.

## Impact

Affects module maintainers and site owners.

- **Config change:** `ckeditor5.plugin.ai_ckeditor_ai` schema gains boolean `show_ai_toolbar_button` and `show_ai_balloon_menu` settings.
- **API change:** The `ai_ckeditor_balloon_menu` CKEditor 5 plugin definition and the `ai_ckeditor/ai_balloon_menu` library are removed in the MR; the balloon JS now loads from the `ai_ckeditor/ai_ckeditor` library.

## Technical details

In `ai_ckeditor.ckeditor5.yml`, `ai_balloon_menu.AiBalloonMenu` moves into the `ai_ckeditor_ai` plugin definition, and the standalone `ai_ckeditor_balloon_menu` definition (with its `ai_balloon_menu` toolbar item) is deleted. In `ai_ckeditor.libraries.yml`, `ai_balloon_menu.js` is folded into the `ai_ckeditor` library. `AiCKEditor` adds a `toolbar_options` details element, persists `show_ai_toolbar_button` (default `TRUE`) and `show_ai_balloon_menu`, and passes them to JS as `showAiToolbarButton` and `showAiBalloonMenu`. It also tries to filter `aickeditor` out of `$static_plugin_config['toolbar']` when the button is off. The MR also fixes the `defaultConfiguration()['dialog'][...]` lookups for dialog height, width and class.

The front end does the hiding client-side. When `showAiToolbarButton` is false, `Aiui` injects a `<style>` element with `.ck.ck-dropdown .ai-dropdown { display: none; }` into the document head. When `showAiBalloonMenu` is false, `AiBalloonMenu` hides the `ContextualBalloon` element. The diff also regenerates the built JS files. This client-side approach was questioned in the thread. The reporter expected the button not to be added to the editor config at all, and the MR author said she found no solution other than JS changes. Because the style rule is global and matches any `.ai-dropdown`, it affects every editor on the page. Because the balloon plugin is now bundled with the main plugin, sites that had placed the old balloon toolbar item would need to revisit their text format configuration. I did not check for an update hook in this MR.
