## Summary

The AI API Explorer sub-module gets a shared look and feel: a "Set up" panel beside a "Results" panel that turns into two tabs on narrow screens, and reusable pieces such as run cards, status pills, score bars, code panels with copy, empty states, error cards, progress with cancel, dialogs and toasts. Colours follow Gin (including dark mode) and fall back to Claro-like colours. The same commit adds an optional per-user history of explorer runs, with a settings page at `/admin/config/ai/explorers/settings`. It also adds a "Create with AI" button for JSON schema fields, which is covered by the `ai` module's new `use ai json schema generator` permission. A follow-up commit fixes Cancel so the run button works again afterwards, rounds durations correctly and removes a Drupal 11.3 deprecation. The issue text says no explorer is migrated yet, so existing explorers should look and behave as before until their own issues land.

## Technical details

The layout is in `css/explorer-ui.css` and `js/explorer-ui.js`, attached through the new `ai_api_explorer/explorer_ui` library, with `label_chips` as a second library. The workspace uses CSS grid and responds to its own container width (`container-type: inline-size`, `@container` rules), not the viewport. Under 640px it becomes Set up and Results tabs with 44px touch targets. `--aie-*` custom properties map to `--gin-*` variables with fallbacks. With core Navigation, the sticky offset is reset to zero. Markup comes from `ExplorerUi` helpers and the theme hooks `ai_api_explorer_form`, `_panel`, `_run`, `_code`, `_empty` and `_notice`. Each hook has a `template_preprocess_*` function in the `.module` file. The plugin manager's `createInstance()` now passes the run manager, date formatter and time service to every `AiApiExplorerPluginBase` through `setExplorerServices()`. This avoids changing the `create()` signatures of explorers in other modules. A kernel test covers the theme hooks. The issue's task to replace `getFormTemplate()` with region helpers lives in `AiApiExplorerPluginBase`, which was among the files not returned by the diff tool, so it is not described here.

Run history is the `ai_api_explorer_run` content entity (`ExplorerRunInterface`). Its fields include explorer, status, provider, model, input, output, usage, error, duration, files and a source run. Access is limited to the owner, who also needs `access ai prompt`. `administer ai api explorer` additionally allows delete. `hook_file_download()` serves files under `ai_api_explorer/` only to the run's owner or an administrator. Only images, audio, video, plain text, VTT, JSON, PDF and SubRip are served inline, and everything else is sent as an attachment. Cron, `hook_user_predelete()` and `hook_user_cancel()` handlers were added to `Hook\AiApiExplorer`. Their bodies were not in the diff returned by the tool.

The follow-up commit has three fixes. Cancel in `explorer-ui.js` now runs the Ajax error clean-up, because an aborted jQuery request would otherwise leave Drupal's Ajax object "in progress" and ignore later presses. The running-timer interval is also cleared on detach. Each preprocess function is named as `'initial preprocess'` in `hook_theme()`, because Drupal 11.3 deprecates finding `template_preprocess_HOOK()` by name. `ExplorerUi::duration()` now rounds before choosing the format, so 59.96 s reads `1 min 0 s` and 9.999 s reads `10.0 s`.

The `ai` module part adds `AiJsonSchemaGenerateForm` at `/admin/config/ai/json-schema/generate` and the `ai.json_schema_generator` service. `ai_json_schema` form elements opt in with `#ai_generate => TRUE`, and the button is off by default.

## Upgrade

Run `drush updb` so `ai_api_explorer_update_16001()` installs the `ai_api_explorer_run` entity type. Where `ai_api_explorer.settings` does not exist yet, the update creates it with history enabled (`max_runs: 50`, `max_age: 30`). Fresh installs default to history off. To change it, go to `/admin/config/ai/explorers/settings`, or `/admin/config/ai/explorers/settings/delete-runs` to delete all stored runs. Grant `administer ai api explorer` only to trusted roles.

To offer the JSON schema generator on a field, set `#ai_generate`:

```php
$form['json_schema'] = [
  '#type' => 'ai_json_schema',
  '#title' => $this->t('JSON Schema'),
  '#ai_generate' => TRUE,
];
```

The button shows only to users with `use ai json schema generator`.
