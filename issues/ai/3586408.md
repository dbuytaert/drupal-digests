## Summary

The Rerank Explorer in the AI API Explorer module has been rebuilt on the shared explorer layout. Documents are edited as numbered rows, and a document can now span several lines (separated by a blank line, where before it was one per line). Results show each document's rank, a score bar and how many places it moved. When Top N is set, the documents below it stay visible, dimmed, under a cut line. Provider and model selection now use the `ai_provider_configuration` form element, runs are stored with run history, and each run gets a generated code example. Several bugs in the old explorer are fixed, including provider-specific guessing of the result shape.

## Impact

Affects module maintainers.

- **New API:** `ReRankOutput` constructor takes an optional fourth argument `$rawOutput`; `getRawOutput()` returns it, falling back to the normalized results when it is NULL.

## Technical details

`RerankGenerator` now extends the run-based explorer flow: `submitForm()` calls `executeRun()`, builds a `ReRankInput`, and stores a `ranking` (index and score per result) and the normalized `response` in the run output. `readRanking()` reads the normalized output as described by `ReRankInterface`: each result is an array or object with an `index` and a `relevance_score` or `score`. It drops results with an invalid or repeated index, and the document text always comes from the documents that were sent, not from the provider's result. This replaces the per-provider shape guessing. If no result points to a document, the run fails with an error.

`rankRows()` appends documents the provider did not return as unranked rows under the cut. A Top N equal to or greater than the document count is sent as 0, meaning all. Score bars use the raw score when it is within 0 to 1; otherwise they span the run's lowest to highest score, with a hint shown. Documents are parsed by `parseDocuments()`, which splits on blank lines. The textarea stays the real form value, so the form works without JavaScript. The new `js/explorers/rerank.js` shows numbered, growing rows (add, remove, paste splitting, screen reader announcements) and keeps the textarea in sync, and `explorer.rerank` in the libraries file loads it with `css/explorers/rerank.css`.

The code example is built per run with the shared `CodeExample` builder, so the query is no longer HTML-escaped into the PHP. `ReRankOutput::getRawOutput()` used to return the normalized results. It now returns a new optional constructor argument `$rawOutput` when a provider passes it, and falls back to the results otherwise, so existing providers behave as before.
