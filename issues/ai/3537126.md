## Summary

Creating a Search API server with the AI Search backend when no Vector Database Provider is installed or configured no longer produces a PHP error and a half-configured server. The form now fails validation with a message telling the user to install and configure a provider first.

## Impact

No upgrade or configuration changes required.

## Technical details

`SearchApiAiSearchBackend::validateConfigurationForm()` now checks `$this->vdbProviderManager->getSearchApiProviders(TRUE)` at the start. If it returns an empty result, it calls `$form_state->setError()` on the whole form. The message links to `system.modules_list` (install) and `ai.admin_vdb_providers` (configure). The existing embeddings engine dimension validation is unchanged and still runs after this check.
