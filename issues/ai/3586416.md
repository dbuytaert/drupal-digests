## Summary

The Speech to Speech Explorer in the AI API Explorer module is rebuilt on the shared explorer layout. It now offers two tasks, Change voice and Translate speech, and takes the recording through the shared file picker. Results are stored as runs, with the original shown next to the result. The explorer previously could not run because provider and model always came through as NULL. That is fixed. Saved result files now get an extension and MIME type that match the actual audio format.

## Impact

No upgrade or configuration changes required.

## Technical details

`SpeechToSpeechGenerator` is rewritten on `AiApiExplorerPluginBase::buildLayout()`. Provider and model selection moves to the `ai_provider_configuration` element via `providerElement()`, replacing `AiProviderFormHelper::generateAiProvidersForm()`. The old bug came from a form prefix `sts` while submit read `speech_to_speech` keys. Submit now reads the `provider` element value and resolves it with `resolveProviderValue()`.

The operation takes only the recording, so voice, target language and output format are provider configuration. `processOptions()` fills the voice, language and format fields from the selected model's configuration, looking for keys such as `voice`/`voice_id`, `target_language`/`target_lang`/`language` and `output_format`/`response_format`/`format`. `runConfiguration()` passes only the setting of the chosen task: a voice change sends no language, a translation sends no voice (covered by the new unit test `SpeechToSpeechConfigurationTest`). A new `explorer.speech_to_speech` library holds `speech_to_speech.css` and `speech_to_speech.js`. The script shows the settings and run button of the picked task, because `#states` does not apply to AJAX-replaced content.

The saved file type is now chosen by `audioType()`. It checks the sniffed bytes first, then the requested format, then the reported MIME type, then the file name. Its comment notes that ElevenLabs reports every result as `audio/mpeg`. The run is stored through `executeRun()` with the original and result file details, plus transcript, translation and source/target language when the provider reports them in output metadata. A failed run keeps its error next to its card. The `speech_to_speech_generator` plugin ID is unchanged, and the title is now 'Speech to Speech Explorer'. The developer docs example now uses `audio/mpeg` and `getNormalized()[0]`, and the explorer path in the docs is updated.
