## Summary

The Embeddings, Extractive Question Answering, Moderation, Rerank, Summarization, Text Classification, Tools and Translation explorers now have Export JSON and Import JSON, as Chat and Decision already did. Each run card gets an Export JSON button, and an Import JSON button opens a dialog where you pick a file or paste JSON. Importing fills in the form fields and, if you leave the checkbox ticked, the saved provider and model. Export works even when run history is off, which is the default. A file made for another explorer, a file with a newer version, or invalid JSON is rejected with a message saying so.

## Impact

Affects module maintainers.

- **New API:** `AiApiExplorerPluginBase` gains opt-in JSON export/import hooks (`supportsJsonExport()`, `exportInput()`, `importInput()`, `importFormKeys()`, `importIntro()`) and a new `ExplorerRunExport` reader class.

## Technical details

The shared part now lives in `AiApiExplorerPluginBase`. An explorer opts in by overriding `supportsJsonExport()` to return `TRUE`, which adds the import button and dialog to the intro and the export action to each run card. Subclasses shape the data with `exportInput()` (what leaves the file) and `importInput()` (which keys and types are kept; the JSON can come from anyone, so everything unknown is dropped). `importFormKeys()` lists fields to reset on import; Rerank adds `return_all` because its checkbox is derived from `top_n`. `getEditedRunInput()` now takes the `FormStateInterface` so an imported run wins over the `?run=` query parameter, and the eight explorers pass `$form_state` to it.

The new final class `ExplorerRunExport` names formats (the `_generator` or `_explorer` plugin ID suffix is dropped, so `decision_generator` is `ai_api_explorer_decision`) and parses files in `read()`, which throws `\InvalidArgumentException` for non-object JSON, another explorer's format, a `version` above `ExplorerRunExport::VERSION` (1), or missing input. A file with no `format` key is treated as the bare input. The exported layout is `format`, `version`, `title`, `input`, `settings.provider`, and `response` only for successful runs. Embeddings does not export the image file ID; it writes the file's `filename` and `mime_type` under `files`, and import leaves the image out (archives for media explorers are tracked in [#3586881](https://www.drupal.org/node/3586881)). Tools import normalizes arguments and `limits` (`only_allow` or `force_value`).

Chat and Decision were moved onto the shared JS and PHP. A new `explorer.export` library (`js/explorer-export.js`, `css/explorer-export.css`) handles download and file reading. The Chat and Decision run export buttons now use the `data-aie-export` and `data-aie-export-name` attributes instead of `data-aie-chat-export` and `data-aie-decision-export`, and the old per-explorer click handlers were removed.
