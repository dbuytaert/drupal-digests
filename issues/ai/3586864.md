## Summary

On a multilingual site, the AI API Explorers showed some failed-run messages in English even when the rest of the run card was translated, for example "The provider returned no audio." These messages the explorers write themselves are now passed through the translation system before they are stored and shown, so they can be translated like other interface text. English wording is unchanged.

## Impact

No upgrade or configuration changes required.

## Technical details

Each explorer builds the message first, then throws it: `$message = (string) $this->t('...'); throw new \RuntimeException($message);`. The intermediate variable avoids the DrupalPractice "Exceptions should not be translated" phpcs warning. The run stores `$exception->getMessage()` as its error, so the stored error is in the language of the user who ran it. Covered: `AiApiExplorerPluginBase` ("Choose a provider and model."), Audio to Audio, Decision, Embeddings, Image Classification, Image to Image, Object Detection, Rerank, Text Classification, Text to Image, Text to Speech and `ToolsExplorer` (the "Access denied." fallback, the limits message, "You cannot run tools as this role."). Static methods (`TextToSpeechGenerator::sample()`, `DecisionGenerator::parseQuestions()`) use `new TranslatableMarkup()` instead of `$this->t()`.

`sprintf()` messages became `@placeholder` strings. Because the exception message is plain text and escaped later when displayed, messages with placeholders are wrapped in `Html::decodeEntities()` so values such as `a&b` are not double-escaped (a `DecisionGeneratorTest` assertion covers this). Messages that were built from fragments became whole sentences: in `EmbeddingsGenerator::toVector()` the " for text N" suffix is now two separate strings per message, and in Text to Speech "Every voice failed." is translated and followed by the first error, which is already a translated sentence. The JSON parse error in `parseQuestions()` still comes from `json_last_error_msg()` and is not translated. The `LogicException` for developers is untouched. Tests `testErrorIsTranslated` were added for Audio to Audio and Tools, using `locale_custom_strings_en` overrides.

## Upgrade

Custom explorer plugins that throw their own run errors can follow the same pattern:
```php
// The run card shows this message to the user, so it is translated.
$message = (string) $this->t('The provider returned no audio.');
throw new \RuntimeException($message);
```
