## Summary

The Text to Speech explorer in the AI API Explorer module has been rebuilt on the shared explorer layout and now uses the AI provider configuration element for provider and model selection. Voices appear as a grid with a play button for a short sample of each. A "Compare voices" switch lets one run generate up to three versions side by side, each with its own player and code example. Voices the selected model rejects are disabled, and the format hint says PCM cannot play in a browser. Audio is now saved and played in the format you picked instead of always as MP3, and the generated code example no longer calls a non-existent method.

No upgrade or configuration changes required.

## Technical details

`TextToSpeechGenerator` (plugin ID `text_to_speech_generator`, so the explorer path is now `/admin/config/ai/explorers/text_to_speech_generator`) builds its form with the `ai_provider_configuration` element in place of `AiProviderFormHelper::generateAiProvidersForm()`. Voice and format are no longer repeated in the provider config; they come from the model's configuration schema through `processVoices()` and `processFormat()`. Rejected voices are disabled in the form, and `validateVoices()` refuses a submission whose voice the submitted model rejects, or more than three voices when comparing.

Each run is stored through the shared run history, with a version per voice. A voice that fails does not fail the run unless every voice fails, and failed runs are kept with the error and a Retry button. Files get the extension and MIME type of the chosen format (for example `speech-nova.opus` as `audio/ogg`), also when saved as media. The per-run code example now uses `$output->getRawOutput()` instead of `getRaw()`. PCM versions get a download link instead of a playable preview.

Voice samples are made on demand by the static `ajaxSample()` callback, which returns an `aieTtsSample` AJAX command. A sample is generated once per model and voice and the file is reused, and is regenerated if its file is gone. The new library `explorer.text_to_speech` in `ai_api_explorer.libraries.yml` adds `css/explorers/text_to_speech.css` and `js/explorers/text_to_speech.js`. A test provider (`ai_api_explorer_test_text_to_speech`) and functional and kernel tests were added. The developer docs were updated for the new path.
