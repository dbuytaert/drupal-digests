## Summary

The `image_to_video` operation type can now carry an optional text prompt. Prompt-guided image-to-video models (the issue names CogVideoX-I2V, LTX-Video, Kling, Runway Gen-3) need a prompt to direct motion, and there was previously no way to pass one. Image-only models are unaffected because the prompt defaults to empty.

## Impact

Affects module maintainers.

- **New API:** `ImageToVideoInput::getPrompt()` and `setPrompt()` added; `toArray()` now returns a `prompt` key.

## Technical details

`ImageToVideoInput` gains a nullable private `$prompt` (default `NULL`) with `getPrompt(): ?string` and `setPrompt(?string): void`, mirroring `ImageToImageInput`. `toArray()` now includes a `prompt` key alongside `file`. The constructor is unchanged (`__construct(ImageFile $file)`), so existing callers keep working. Providers that support prompts should read `$input->getPrompt()` and handle `NULL`.

The same commit fixes copy-pasted audio-to-audio docblocks in `ImageToVideoInput` and `ImageToVideoOutput`, and corrects the `@param` namespace in `ImageToVideoInterface` to `\Drupal\ai\OperationType\ImageToVideo\ImageToVideoInput`. `ImageToVideoInputTest` gets a `testPrompt()` case.

## Upgrade

Providers implementing `image_to_video` can pass the prompt to the model:

```php
$prompt = $input->getPrompt();
```

Callers can set it with `$input->setPrompt('a cat playing the piano');`.
