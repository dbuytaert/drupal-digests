## Summary

When an AI Automator was deleted or disabled on a field but a Field Widget Action (for example "Automator Text Suggestion") still pointed to it, clicking the action's button on the edit form failed with "Oops, something went wrong" and a PHP fatal error. Now, deleting an automator also removes the Field Widget Actions that reference it from your form displays, so the broken button no longer appears.

## Impact

Affects module maintainers.

- **New API:** New `ai_automators.cleanup` service (`AiAutomatorCleanupService::cleanupActionsForAutomator()`) and an `ai_automators_entity_predelete()` hook in `ai_automators`.

## Technical details

The error came from `AutomatorBaseAction::populateAutomatorValues()` calling `get()` on a `NULL` automator after the referenced `ai_automator` entity was gone. The maintainer said Field Widget Actions must not depend on AI Automators, because Automators build on Field Widget Actions. So the cleanup lives in `ai_automators`. A new `ai_automators_entity_predelete()` hook calls the `ai_automators.cleanup` service for `AiAutomatorInterface` entities. `AiAutomatorCleanupService::cleanupActionsForAutomator()` loads all `entity_form_display` entities and removes entries under each component's `third_party_settings.field_widget_actions` whose `settings.automator_id` matches the deleted automator. It saves the changed displays and logs each removal.

The MR also adds a guard in `AutomatorBaseAction::populateAutomatorValues()`. If the configured `automator_id` no longer loads, it logs a warning and returns the existing form element instead of failing. I could not confirm this guard in the current repo, because that code has since moved to `AutomatorFieldWidgetActionTrait`. MR !917 also carried a parallel `field_widget_actions` predelete hook and a stub `Autowire` attribute class. The maintainer called that code unnecessary, and it is not present in the current repo. The cleanup runs only on automator deletion. Disabling the automator on a field, as in the reproduction steps, is not covered by it.
