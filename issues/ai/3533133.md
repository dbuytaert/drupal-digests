## Summary

The Vector DB Explorer in the AI module's API Explorer now shows every field returned by the vector database as its own table column, next to the Score. Before, it showed only Score and a single Chunk column, so metadata such as the Drupal node ID was hidden. Chunk content that is Markdown is now rendered as HTML instead of showing raw tags and long unformatted strings, provided the CommonMark library is available.

## Impact

No upgrade or configuration changes required.

## Technical details

The change is in `VectorDBGenerator` (the Vector DB Explorer plugin). The fixed `Chunk` column and the `getExtraData('content')` call are gone. Each result row now loops over `$row->getAllExtraData()`. Each key becomes a column, and the header is added the first time the key is seen, using `ucfirst($key)`. Each value is converted with `League\CommonMark\CommonMarkConverter` and output as `#markup`. The converter is only created if `class_exists('League\CommonMark\CommonMarkConverter')`. Without the library, values are output unconverted as `#markup`. The Score cell is built as a render array with `#markup`.
