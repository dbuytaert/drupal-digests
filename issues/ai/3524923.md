## Summary

Running the RAG/Vector Search tool from the "test this tool" form in the AI agent UI showed a "min_score is not a valid number" error, even when the value was valid and results came back. Number and integer inputs in the tool explorer now accept the value without that error.

## Impact

No upgrade or configuration changes required.

## Technical details

`PropertyFormBuilder` built `number` and `integer` tool properties as `#type => 'number'`. Per the maintainer, this sent the value through Drupal's form validation for number elements, which rejected `min_score` as not a valid number. The fix in the `number`/`integer` case changes the element to `#type => 'textfield'`. The code comment says type casting already happens elsewhere, so core's number validation is not wanted. The placeholder from the property's example value is kept. One side effect: these inputs are now plain text fields, so browsers no longer apply number input constraints. The issue does not discuss this.
