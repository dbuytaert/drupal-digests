## Summary

Clicking Generate in the AI CKEditor "Generate with AI" modal could fail with `LogicException: Settings cannot be serialized`, reported on Acquia Cloud and also on a self-hosted Kubernetes cluster. The AI CKEditor plugins no longer hold a logger channel object, so the error is gone. Error logging in the plugins still works, as the maintainer confirmed in testing.

## Impact

Affects module maintainers.

- **API change:** Protected property `AiCKEditorPluginBase::$logger` (`LoggerChannelInterface`) removed and replaced by `$loggerFactory` (`LoggerChannelFactoryInterface`); subclasses must call `$this->loggerFactory->get('ai_ckeditor')`.

## Technical details

`AiCKEditorPluginBase` stored a `LoggerChannelInterface` obtained from `$logger_factory->get('ai_ckeditor')` in its constructor. The plugin object is serialized during the modal form's AJAX handling. The logger channel indirectly references the `Settings` object, which refuses serialization. The base class now stores the `LoggerChannelFactoryInterface` in a protected `$loggerFactory` property, and the `$logger` property is removed. Each plugin's `catch` block (`ModifyPrompt`, `ReformatHtml`, `SpellFix`, `Summarize`, `Tone`, `Translate`) now calls `$this->loggerFactory->get('ai_ckeditor')->error(...)` at the point of logging. The log channel and messages are unchanged apart from a small quote tweak in the `ModifyPrompt` message.

## Upgrade

Custom plugins extending `AiCKEditorPluginBase` that use `$this->logger` need to change it:

```php
// Before
$this->logger->error('Something failed.');

// After
$this->loggerFactory->get('ai_ckeditor')->error('Something failed.');
```
